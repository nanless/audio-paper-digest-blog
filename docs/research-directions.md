# 研究方向浏览与多级筛选

`/tags/` 只展示受控研究方向与多级分类，不再展示精确标签索引、扁平标签清单或按页面计数的筛选区域。概念入口使用
`/papers/?concept=method.peft`，不依赖父概念是否存在 Hugo 原生标签页。
方向名称进入论文库，箭头只展开；无 JavaScript 时目录可原生展开阅读。

## 分类与查询

- 九个分面是并列视角；父子关系只发生在同一分面内。当前快照为单语义父级。
- 重复 `concept` 参数在同分面内满足任意一个，不同分面同时满足。
- `scope=subtree`（默认）包含全部后代；`scope=direct` 只匹配直接标注。
- `role=primary` 在任务、方法、科学主题、研究重点与研究产物分面使用显式主角色；其余分面匹配相关标注。
- 主角色来自明确字段且必须属于当前有效分类，不能从标签顺序推断。
- 一篇导读必须独立满足关键词、年份及全部方向条件，再按论文身份合并。
  不同导读不能各贡献部分条件拼成一次命中。卡片选择实际命中的导读，
  同一论文的其他导读仍可展开查看。
- 手机面板先修改草稿，应用后写入 URL；取消不改变已有筛选。返回、刷新可恢复。

## 身份与统计

已核 arXiv base ID 或显式会议论文 ID 合并为一个论文记录。推测身份和未知身份
按页面保留，不通过标题相似度合并。论文身份与页面类型独立；日报、会议汇总
不计入论文方向统计。

父方向的计数为自身及全部后代命中身份的并集，不能把孩子数量相加。
列表、方向计数和角色筛选共用 `assets/js/taxonomy-core.js`；Hugo 的全站统计
用同样的分类验证和身份边界，并有真实页面 fixture 与完整语料对照。

普通关键词检索包含历史文章；选择方向后只使用已确认的受控分类。

已有 `/tags/<名称>/` 地址继续响应历史外链，目录不再提供这套索引入口。
这些旧地址的页面收录数不能与按论文身份去重的方向数量相加。

## 快照兼容

现行目录使用 386 个概念；历史页面继续按各自 registry SHA 解析签发快照。
签发快照用于重放原分类证据，不可通过修改旧快照伪造分类迁移。
原标签、主角色及证据先按签发快照严格核验；通过后按稳定概念 ID 投影到当前目录，
父级筛选、目录计数、路径显示及关键词中的父概念名称共用当前父链。
原签发祖先链仍保留在分类对象中，不用于现行目录的后代归档。
同一论文的不同导读仍须各自完整满足全部条件，不能借投影拼接分类。
此导航修复不修改论文正文、分析证明、历史标签或旧标签 URL，
也不代表所有论文的科学语义分类已经重新审核通过。

## 模板与资源

`taxonomy_valid_records.html` 严格验证合同、ID、分面、首选名称及有效状态。
`taxonomy_navigation_records.html` 仅在上述验证后返回当前目录节点，不改变签发证明。
`taxonomy_registry_index.html` 提供缓存查表，避免每篇遍历完整词表。
服务器统计按论文分组后一次累积直接节点与祖先集合，避免反复复制大字典。

目录脚本由 terms 模板按 core → browser 顺序加载，不能放进按 Kind 缓存的主题
footer 后再按 Type 判断，否则 tags 与 categories 可能误用同一份脚本结果。
论文库按 core → search-index-loader → library 顺序加载。资源均有内容指纹。

搜索索引保留中英文检索字段，但省略重复原题，祖先和别名从共享快照解析。
历史首选名称仍可作为检索词；父概念与当前目录一致。方向检索没有结果时目录仍可浏览。
无 JavaScript 时可用原生展开控件阅读目录，论文库筛选与全文关键词搜索需 JavaScript；
时间归档和论文原链接仍可阅读。
链接保留站点 base path。完整构建把索引分成每片最多 1 MiB 的 JSON 数组；入口清单
与每片内容哈希、字节数、记录数绑定，最多 128 片、总量上限 64 MiB。浏览器最多
并发读取四片，并核验全部分片后才接受结果，保留完整检索记录。旧数组入口继续兼容。
入口文件仍受原 8 MiB 限制；新增分片有更小的单文件限制及独立完整性门禁。

## 验证

在沙箱外运行 `npm test` 与 `npm run build:verify`。回归包括层级闭合、别名路径、
OR/AND、主角色、跨导读隔离、父集合计数、未知身份、原标签回退和脚本加载顺序。
浏览器验收覆盖实际文章、390 像素手机、选择/展开、应用/取消、刷新恢复和无页面溢出。
