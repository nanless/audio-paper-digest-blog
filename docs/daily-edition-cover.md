# 每日论文选读封面

网站正常构建 `npm run build` 会先运行 `scripts/select-edition-feature.js`，再由 Hugo 生成网页。新一期日更推送到 `main` 后，既有 Pages 流程会自动完成选择和展示，不需要另建定时任务或手填日期。

选择只使用最新一期完整「论文列表」中的正式成员。先优先选择方法总览、架构、流程等关键图，再按本站论文评分排序；结果图、消融图和旧方法结构不获得方法图优先级，同分顺序固定。没有方法图时选择有原图的高分论文，完全没有合格图时保留日期封面和全量日报入口，不沿用昨日选读。

候选必须匹配当期日期、论文身份、arXiv 版本和正文里实际出现的图片。已有本地 PNG 核对完整分块、CRC、尺寸和 SHA；已有官方图片映射优先复用同论文的本地 PNG 或 SVG，并保留原官方 URL。没有本地映射时，官方外链只允许同一版本的 `https://arxiv.org/html/...` 图片，直接复用已审正文 URL。构建不下载图片、不需要代理凭据，也不将远程 URL 描述成本地封存字节；其可用性与正文的同一官方图片相同。

选择结果原子写入忽略文件 `data/edition-features-auto.json`，每次构建只保留当期结果。该文件不提交；Hugo 在展示前重新核对日报和文章原字节及精确图片语法，过期清单不能给新日报套上旧图。旧 `data/edition-features.json` 仅保留同日期手工选读的兼容回退。

`npm run build:verify` 还会验收实际首页、日报和论文页：日期、选中成员、图片、完整解读、原图入口必须一致，完整日报主入口必须位于选读之前。选择成功却未渲染会直接阻断部署。`hugo` 裸命令不重新选择；本地完整预览也应先执行正常构建。
