### 💡 毒舌点评

亮点：这是一篇工程实践扎实、目标明确的应用论文，为生态声学社区提供了一个“烹饪”可靠声景分类模型的系统化流程，并发布了可用的模型和代码。其价值在于将多种现有技术（多标签分类、预训练模型、数据混合、后处理）组合并实证其在真实PAM场景下的有效性，对领域内其他研究者有直接的参考价值。短板：核心贡献是系统性的经验总结而非算法或理论创新。最大的方法论瑕疵在于评估策略（PDA, CST, CBT）的优化是在测试集（BEsound）上进行的，这导致报告的最终性能（0.799）是针对该特定测试集的过拟合上界，而非对真正未见数据的泛化性能，严重削弱了结果的学术可信度。此外，论文未与领域内其他声景分类模型进行直接对比，其“提升”的结论缺乏有力的参照系。

### 📌 核心摘要

本文旨在解决被动声监测（PAM）录音中自动区分生物声（Biophony）、地理声（Geophony）和人为声（Anthropophony）这一声景生态学的核心问题。论文提出并发布了一个名为CoarseSoundNet的深度学习模型，其主要贡献不在于提出全新的网络架构，而在于系统性地验证了一套从模型构建到评估优化的可复现流程。论文的核心方法是进行一系列设计选择与消融研究：1) 在多种CNN和Transformer模型中，基于跨域性能选择基础架构；2) 提出并论证了在训练中引入显式“静默”类别的有效性；3) 研究了整合多种真实PAM数据集（而非仅用合成数据）对提升目标域（BEsound）性能的关键作用；4) 在测试集上探索并组合使用类特定阈值（CST）和基于比例持续时间的注释（PDA）等后处理策略以优化性能。主要实验表明，跨域性能下降显著，而引入静默类、添加领域相似的PAM数据以及应用PDA+CST策略的组合，能将BEsound测试集上的宏观F1分数从基线0.683提升至0.799（但需注意此优化过程在测试集上进行）。生态案例研究显示，使用CoarseSoundNet预过滤录音后计算的声学指数，其与鸟类α多样性的相关性趋势与人工过滤相似，但相关系数整体偏弱（最高ρ=0.36）。论文明确承认的局限包括：昆虫声音因高频衰减和数据不足识别困难、合成数据PublicMix未能提升性能、标注存在噪声，以及在测试集上优化评估策略。

### 🏗️ 方法概述和架构

本文的方法是一个多阶段、系统化的深度学习模型构建与优化框架，旨在为生态声景分类任务（区分人为声、生物声、地理声）构建一个可靠且可复现的模型。整体流程可分为四个主要阶段：

1.  数据准备与构建：
    *   核心数据集：Edansa-2019（公开，10秒，48kHz）作为主要的训练与验证集。作者对其进行了重定义：将“静默”严格定义为人为声、生物声、地理声均不出现的片段。
    *   目标域测试集：BEsound（作者标注，60秒，48kHz，森林/草地录音）作为跨域测试集，仅用于评估，不参与训练。此数据集的引入旨在评估模型在与训练数据不同域的真实PAM场景下的泛化能力。
    *   补充数据集：包括BrPAM（德国，10秒）、BE-Ambient（德国BE地区，5秒）、HTS-Forest（德国BE地区，5秒）和PublicMix（合成，5秒，32kHz）。这些用于后续跨域数据扩充实验。PublicMix由AudioSet、xeno-canto、FSD50K等多个公开数据源通过混合脚本合成，旨在增加数据多样性。
    *   任务定义：采用多标签分类设定，因为真实声景中多种声音常同时存在（如图7所示）。每个音频片段可同时标注有A、B、G中的一个或多个标签。损失函数为二元交叉熵损失，以适应多标签任务。
    *   音频表示：对于需要频谱图输入的模型，统一使用log-Mel频谱图（采样率32kHz，窗口1024，跳频320，64个mel频带），示例如图1所示。

2.  基准模型架构搜索（图2）：
    *   组件：对比了CNN系列（CNN10, CNN14, ResNet-50, EfficientNet-B7, BirdNET）和Transformer系列（AST, SSAST, PaSST, AVES, W2V2, Whisper, CLAP-HTSAST, Qwen2-Audio）共13种模型。
    *   功能与实现：目的是在源域（Edansa-2019）性能好且在目标域（BEsound）表现相对稳健的基线架构。所有模型均使用预训练权重（如来自AudioSet、ImageNet等）进行微调。
    *   输入输出：输入为log-Mel频谱图（或模型特定的波形），输出为每个片段在A、B、G三个类别的置信度分数（0-1）。
    *   设计选择与超参数：进行小规模网格搜索（学习率：1e-3, 1e-4, 1e-5；批次大小：4, 16, 32, 64；优化器：Adam, AdamW），但非穷尽搜索（表2）。训练30个epoch，保留验证集上最佳模型。对于BEsound的60秒音频，采用滑动窗口（窗口10秒，步长10秒）推理，将6个窗口中每个类别的最大预测分数作为整个片段的预测置信度。此阶段未使用数据增强。根据在两个测试集上的综合性能和推理速度，选择了CNN10、AST、CLAP-HTSAST进行后续实验。

3.  模型优化与分析：
    *   3.1 “静默”类别的引入：这是对核心模型（CNN10, AST, CLAP）的进一步优化。在训练和验证中加入第四类“静默（S）”（定义为A、B、G均无），但在测试评估中忽略其预测，仅评估A、B、G三类。此做法旨在为模型提供关于“无事件”状态的显式监督信号，迫使模型更鲁棒地表征其他三类声音。实验对比了三种数据增强策略（无增强、SpecAugment、自定义混合流水线），并采用平衡采样（表3）。
    *   3.2 跨域数据扩充：使用最佳模型（来自上一步的CLAP），研究将不同补充数据集添加到基础训练集Edansa-2019中，对目标域BEsound性能的影响。这本质上是一种朴素的领域适应（Domain Adaptation）方法。实验设置了多种数据组合（如单独添加、添加BE地区数据、添加所有PAM数据、添加所有数据含PublicMix），每种组合使用两个学习率（1e-4, 1e-5）进行重训。
    *   3.3 评估策略后处理优化：在模型权重固定后（使用结合了“静默”类别和PAM数据扩充的CLAP模型），探索多种后处理策略以提升在BEsound测试集上的性能。作者明确承认这是在测试集上进行调优，目的是展示性能上界和提供优化路径。
        *   比例持续时间注释（PDA）：对人为声和地理声，忽略持续时间过短（如<5%、10%、25%录音时长）的预测或标签，因为这些短事件可能是噪声或错误标注。
        *   类特定阈值（CST）：为A、B、G三类分别确定最优的置信度阈值（而非统一的0.5），以最大化各自的F1分数。
        *   基于计数的阈值（CBT）：要求某个类别的活跃预测窗口数超过一定比例（如5%-25%）才判定该类存在，以增加预测的稳定性。

4.  应用与评估（生态案例研究）：
    *   组件：声学指数与生物多样性相关性分析流程。
    *   功能：验证CoarseSoundNet作为预处理工具的实际效用。在BEsound子集（852段录音）上，人工标注鸟类物种并计算α多样性。然后计算三种传统声学指数（ACI， ADI， NDSI），并分析它们与鸟类α多样性的皮尔逊相关系数（ρ）。对比三种数据过滤情况：1）使用所有数据；2）仅使用生物声（B）过滤后的数据；3）使用生物声+人为声（A∪B）或生物声+地理声（B∪G）过滤后的数据。同时对比使用人工地面真值过滤和使用CoarseSoundNet预测过滤的结果。

组件间数据流：数据流是单向的线性流水线。音频 → 特征提取（log-Mel频谱图） → 选定的深度学习模型（如CLAP）进行预测，得到A、B、G的原始置信度分数 → 在训练阶段，可加入“静默”类进行联合学习 → 对于BEsound的60秒长音频，进行滑动窗口推理并聚合分数（取最大值） → 应用PDA、CST或CBT等后处理策略，得到最终的、优化后的片段级预测结果 → 用于生态案例研究中的数据过滤和声学指数计算。

关键设计选择及动机（依据原文Section 1, 3.3, 5.2-5.4）：
*   多标签分类与二元交叉熵损失：因为真实声景中多种声音常同时存在（如图7所示），这是处理标签共存的合适方式。
*   系统化构建与跨域评估：动机是解决现有生态声学ML模型“依赖特定数据”、“泛化能力差”的痛点（Section 2）。通过系统评估架构、数据、评估策略，旨在提供一套可复现的最佳实践。
*   引入显式“静默”类别：动机是为模型提供关于“无事件”状态的显式监督，防止其将背景噪声或低能量片段错误地归类为某种声音事件，从而“锚定”特征空间，鼓励更鲁棒的特征学习（Section 5.2）。
*   后处理评估策略：动机是承认并利用目标域（BEsound）的特定属性（如事件持续时间模式），通过简单的阈值调整在不重新训练模型的情况下显著提升性能，这在特定部署场景中非常实用（Section 3.3.3）。论文明确指出这是为了展示上界。

### 💡 核心创新点

1.  构建流程的系统化与透明化：为生态声景分类模型提供了一个清晰、可复现的“菜谱”，系统评估了从架构选择、数据混合到后处理优化的全过程，解决了领域内构建方式不统一、复现困难的问题。
2.  对“静默”训练类别的系统研究与验证：系统地实验证明了引入显式“静默”类别（定义为三类声音均无）能有效提升主分类任务（A/B/G）在目标域（BEsound）上的性能，为处理“无事件”数据提供了实证依据和最佳实践。
3.  跨域真实PAM数据影响的实证分析：通过混合多种真实PAM数据集（BE-Ambient, HTS-Forest, BrPAM）进行训练，实证研究了不同来源、不同相似度的数据对缩小域差距、提升模型在目标域性能的作用，强调了领域相似的真实PAM数据的价值，并指出合成数据（PublicMix）在此任务上效果不佳。
4.  后处理评估策略的组合与比较：系统地提出并比较了PDA、CST、CBT等多种后处理策略，证明了“PDA + CST”组合在提升性能和计算效率之间的良好平衡，为针对特定领域的部署优化提供了明确的路径和实证参考。

### 📊 实验结果

论文在两个主要数据集上进行了评估：Edansa-2019（内部测试集）和BEsound（跨域测试集，主要评估目标）。主要指标是宏平均F1分数（Macro F1），以及各类别的F1分数。

1. 模型架构基准比较 (表4， 表5)
在Edansa-2019测试集上，CNN10表现最佳（Macro F1: 0.925）。但在跨域的BEsound测试集上，性能普遍大幅下降，大型预训练模型如Qwen2-Audio表现最好（Macro F1: 0.708），其次是CLAP (0.684)，揭示了显著的领域差距。BirdNET在两个数据集上表现均显著落后。

| 模型 | Edansa-2019 Test | BEsound (默认阈值0.5) |
| :--- | :--- | :--- |
| | Macro F1 | Macro F1 |
| CNN10 | 0.925 | 0.571 |
| CNN14 | 0.921 | 0.589 |
| AST | 0.921 | 0.651 |
| Qwen2-Audio | 0.908 | 0.708 |
| CLAP-HTSAST | 0.897 | 0.684 |

2. “静默”类别的影响 (表6， 表7)
在BEsound上，为所有三个选定模型（CNN10， AST， CLAP）增加“静默”训练类别后，性能均有提升。例如，CLAP模型从0.629提升到0.683。

| 模型 (训练设置) | Edansa Test | BEsound |
| :--- | :--- | :--- |
| | Macro F1 | Macro F1 |
| CLAP (无静默) | 0.923 | 0.629 |
| CLAP (有静默) | 0.907 | 0.683 |

3. 额外训练数据的影响 (表9)
在BEsound上，向Edansa-2019添加领域相似的BE数据集（BE-Ambient， HTS-Forest）或所有PAM数据集，能显著提升性能。最佳结果来自“PAM-data”（Macro F1: 0.758），而添加合成的PublicMix数据效果最差（0.655）。

| 添加数据集组合 | BEsound Macro F1 |
| :--- | :--- |
| 基线 (仅Edansa-2019) | 0.683 |
| BE-Ambient | 0.740 |
| BE-data (BE-Ambient + HTS-Forest) | 0.753 |
| PAM-data (以上三者) | 0.758 |
| All-data (含PublicMix) | 0.747 |

4. 评估策略优化 (表10)
在BEsound上，使用CLAP模型（结合了“静默”类别和PAM数据扩充）后，应用不同的后处理策略。PDA + CST组合取得了次优性能（Macro F1: 0.797），且计算高效。加入计数的CBT策略仅微弱提升至0.799，但计算成本增加。

| 阈值策略 | Anth | Bio | Geo | Macro F1 |
| :--- | :--- | :--- | :--- | :--- |
| 基线 (全局阈值0.5) | .649 | .909 | .717 | .758 |
| PDA | .649 | .909 | .740 | .766 |
| CST | .659 | .937 | .719 | .772 |
| PDA + CST | .678 | .937 | .776 | .797 |
| PDA + CST + CBT | .678 | .936 | .782 | .799 |

5. 生态案例研究 (图6)
相关性分析显示，传统声学指数（如ADI， NDSI）与鸟类α多样性的相关性较弱（最高ρ=0.36，过滤后）。使用CoarseSoundNet过滤数据后的相关性趋势与使用地面真值过滤非常相似，但未能显著提升相关系数。

![图6：声学指数与鸟类多样性的相关性对比](https://arxiv.org/html/2605.21143v1/x16.png)
图6比较了使用人工标注过滤（上行）和CoarseSoundNet预测过滤（下行）后，声学指数（ACI， ADI， NDSI）与鸟类α多样性的皮尔逊相关系数。关键结论是：1）过滤后（尤其是仅保留生物声时，绿线）相关性有所提高；2）CoarseSoundNet的过滤效果与人工过滤效果高度相似，证明了其作为预处理工具的有效性；3）但即使过滤后，相关性整体仍然偏弱。

### 🔬 细节详述

- 训练数据：
    - 核心数据集：Edansa-2019（公开），10秒音频，48kHz，包含A、B、G、S标签。作者重新定义了“静默”为A、B、G均无。原文提到该数据集存在“clipping”问题和部分静默与地理声共标的模糊性。
    - 目标域测试集：BEsound（作者标注），60秒音频，48kHz，森林/草地录音，仅用于测试，不参与训练。
    - 补充数据集：BE-Ambient（5秒，48kHz），BrPAM（10秒，48kHz），HTS-Forest（5秒，48kHz），均为真实PAM录音；PublicMix（5秒，32kHz），通过混合AudioSet等公开音频片段合成，脚本公开。
    - 数据增强：在静默实验中对比了三种策略：1）无增强；2）SpecAugment；3）自定义流水线（70%概率SpecAugment， 30%高斯噪声，所选增强以80%概率应用）。在跨域数据实验中未提及额外增强。
- 损失函数：二元交叉熵损失（Binary Cross-Entropy Loss），因为这是多标签分类任务，每个类别的预测独立（可同时为真）。
- 训练策略：
    - 优化器：Adam或AdamW。
    - 学习率：在网格搜索中探索，如1e-3， 1e-4， 1e-5等。对于最终CLAP模型，在BEsound上的最佳配置使用学习率1e-5。
    - 批次大小：根据模型大小在4至64之间选择，例如Qwen2-Audio最大为4。
    - 训练轮数：所有模型训练30个epoch。
    - 调度策略：未明确说明具体的学习率调度器（如warmup或衰减），可能为固定学习率。
- 关键超参数：
    - 模型架构：论文未提供所选模型（如CLAP-HTSAST）的具体层数、隐藏维度等参数，因其为已有架构的微调。
    - 网格搜索范围：见表2和表3。
- 训练硬件：使用NVIDIA A40和RTX3090 GPU进行训练和推理。
- 推理细节：
    - 对于10秒输入模型（如CNN10），处理10秒片段。
    - 对于60秒的BEsound录音，采用滑动窗口：窗口大小10秒，步长10秒（产生6个窗口）或1秒（产生51个窗口，用于CBT评估）。
    - 预测聚合：默认采用“最大置信度得分”策略，即某个类别的预测分数取所有窗口中的最大值。若超过阈值（默认0.5或优化后的类特定阈值），则判定该类别存在。
- 正则化/稳定训练技巧：未明确提及Dropout、权重衰减等具体设置，可能依赖所使用的预训练模型的默认配置。
- Model Soups：论文在附录中评估了“模型汤”集成策略（平均所有网格搜索运行的权重），但在Edansa-2019-test上效果不佳（表13）。

评审意见：论文的主要贡献在于系统性的工程实践和经验总结，而非算法或理论创新。它没有提出新的神经网络架构或损失函数。其“新意”在于为生态声景分类这一具体任务提供了完整的、可复现的模型构建方案，并对几个关键设计选择（如静默类、数据混合、后处理）进行了深入的实证研究，这些结果对该领域的其他研究者具有直接的指导价值。但就方法论本身而言，属于对现有技术（预训练模型、多标签分类、数据混合、后处理）的组合与应用，缺乏本质突破。

技术严谨性：1.0/2
评审意见：实验设计整体系统，对多种模型、数据源和评估策略进行了消融实验。错误分析深入（如图4），并进行了标注质量审查。主要瑕疵在于评估策略优化部分：作者在测试集（BEsound）上通过搜索阈值和PDA百分比来获得最佳结果（Section 3.3.3明确承认），这属于在测试集上调参，使得报告的最终性能（如0.799）是针对该特定测试集的过拟合上界，而非对真正未见数据的泛化能力，严重损害了结果的泛化可信度和学术贡献。此外，对BirdNET的评估可能不够公平（未进行全参数微调，使用固定窗口）。

实验充分性：1.2/2
评审意见：实验非常充分。覆盖了多种基线模型（CNN和Transformer）、多个数据集（公开与私有）、全面的消融研究（静默类、数据组合、评估策略）。生态案例研究将模型输出与传统方法关联，增加了实用性论证。不足之处：对于PublicMix数据效果不佳的解释（混合伪影、短时长）缺乏进一步验证实验。最终模型（CLAP）的选择可能并非全局最优（如Qwen2-Audio初始跨域性能更好），但论文未展示在最佳数据扩充下与更强基线对比的完整结果。

### 🚨 局限与问题

1. 论文明确承认的局限：
- 昆虫声音处理不足：部分昆虫声音（高频）在特征提取中被严重衰减，导致模型在生物声类别上出现假阴性错误（Section 4.5， 5.5）。
- 合成数据效果不佳：精心构建的PublicMix数据集并未提升，甚至降低了模型性能，作者推测可能是混合引入了不真实的伪影或样本过短（Section 5.3）。
- 标注质量存在噪声：对BEsound数据的抽样审查发现标注不一致，尤其是人为声（9.4%）和地理声（7.4%），这引入了训练噪声并可能影响模型性能上限（Section 5.5）。
- 评估策略在测试集调优：作者承认在BEsound上优化阈值是为了展示性能上界，而非测试泛化能力（Section 3.3.3）。

2. 审稿人发现的潜在问题：
- 核心方法论缺陷：测试集调参：这是论文最严重的问题。报告的0.799分是在BEsound上搜索得到的，它不能代表模型在真正新数据上的泛化性能。这使得“PDA+CST”策略的价值停留在“针对特定部署点的后处理”，而非一个泛化的算法贡献。
- 缺乏与领域SOTA的明确对比：论文虽然对比了多种通用模型，但未与文献中专门为声景分类设计的模型（如Challéat et al., 2024; Quinn et al., 2022等）进行直接性能对比，使得“CoarseSoundNet性能提升”的结论缺乏最强有力的参照系。
- 生态案例研究结论较弱：案例研究（Section 4.7）中，即使过滤后，声学指数与鸟类多样性的相关性仍然很弱（ρ<0.4）。这间接说明CoarseSoundNet作为预处理工具，在此特定应用中并未能显著提升关键生态学指标的相关性，其实际效用有待更强证据支持。
- 最终模型选择可能次优：论文在静默实验后选择了CLAP-HTSAST作为基础模型。但在后续跨域数据扩充实验（表9）中，使用CLAP得到的最佳Macro F1是0.758，而初始基准测试中Qwen2-Audio在BEsound上得分为0.708。论文未展示在CLAP基础上，使用“PAM-data”扩充后，其性能与使用最优数据扩充后的Qwen2-Audio模型相比的详细对比，因此无法确定CLAP是否是最佳选择。
- 对“静默”类别的定义有生态学上的争议：将“静默”严格定义为A、B、G均无，在生态学上可能过于简化。例如，仅包含极低能量背景噪声的片段是否应该被视为与“完全静音”相同的“静默”类？这可能导致模型学习到一个边界不稳定的类别，尤其是在地理声（如风声）与静默本身在频谱上相似的情况下。
