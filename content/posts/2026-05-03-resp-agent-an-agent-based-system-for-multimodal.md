### 📌 核心摘要

1.  解决的问题：当前基于深度学习的呼吸音分析面临两大挑战：一是单模态表示（如仅用频谱图）造成的信息损失，无法同时捕捉瞬态声学事件和临床文本上下文；二是缺乏大规模、高质量且类别不平衡的多模态数据集。
2.  方法核心：提出 Resp-Agent，一个由新颖的“主动对抗性课程智能体”（Thinker-A2CA）协调的闭环多模态系统。该系统包含一个可控的“生成器”和一个鲁棒的“诊断器”。生成器通过模态注入改造一个纯文本LLM，并利用流匹配解码器合成指定病理内容的呼吸音；诊断器则采用“模态编织”策略，将临床文本与音频token在输入层交织，并通过战略全局注意力（利用音频锚点）进行融合推理。
3.  新意所在：不同于静态流水线，Thinker-A2CA 作为中央控制器，主动识别诊断弱点并调度针对性合成，形成“诊断-生成”闭环。首次构建了包含22.9万条记录、配有LLM生成临床叙述的 Resp-229k 大规模基准。设计了内容-风格解耦的可控生成器与基于音频锚点的多模态诊断器。
4.  主要实验结果：在 ICBHI 四分类任务上，Resp-Agent 达到 72.7% 的分数（Sp=79.3%, Se=66.1%），显著超越此前最优音频模型。在 Resp-229k 的严格跨域测试集（Test-CD）上，完整系统在平衡数据后达到 0.8870 准确率和 0.5980 Macro-F1，远优于无合成基线（0.849/0.212）。消融实验验证了生成器内容-风格解耦能力（Style-Sim >0.9）以及诊断器中模态编织与音频锚点（≈80ms分辨率）的关键作用。
5.  实际意义：为医疗音频领域（特别是呼吸音）提供了一个将可控生成与鲁棒诊断相统一的系统化框架，推动了从被动分析到主动生成-诊断协同设计的范式转变，对医学教育、数据增强和模型可解释性研究有潜在价值。
6.  主要局限：系统依赖一个强大的中央LLM（DeepSeek-V3.2-Exp）进行规划，计算成本与可控性需权衡。评估严重依赖合成数据和严格的源离域协议，缺乏在真实、混杂临床场景中的前瞻性验证。生成器的质量依赖上游LLM生成的文本和风格参考，引入了额外的误差传播链。

### 🏗️ 模型架构

Resp-Agent 是一个由中央控制器协调的闭环多智能体系统，包含三个核心组件：Thinker（思考者）、Generator（生成器）和 Diagnoser（诊断器），整体架构如下图所示：

![图1：Resp-Agent 系统概览](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/ZkoojtEm3W-0.png)

1.  Thinker-A2CA（智能体控制器）：
    *   功能：作为系统的“大脑”，负责语义意图解析和任务规划-执行-路由。它基于 DeepSeek-V3.2-Exp 大语言模型实现。
    *   工作流：接收临床任务（如诊断特定疾病、合成稀有病例），解析其语义意图。它利用从诊断器反馈的回收的推理链、错误档案和校准后的置信度，主动识别模型的弱点，并据此动态地调度和分配任务给生成器（例如“为某难诊断类别生成50k样本”）或诊断器。
    *   设计动机：解决静态流水线无法自适应、无法针对弱点进行增强的问题，将数据生成和模型训练置于一个由智能体驱动的闭环中。

2.  Generator（可控呼吸音合成器）：
    *   目标：合成能精确控制病理内容（生什么病）和声学风格（什么录音设备/音色）的高保真呼吸音。它包含两个阶段，其核心组件 Resp-MLLM 架构如下图：
    ![图2：Resp-MLLM（生成器第一阶段）详细架构](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/ZkoojtEm3W-1.png)
    *   第一阶段：风格条件化单元生成（Resp-MLLM）：
        *   模态注入：将一个纯文本LLM（Qwen3-0.6B-Base）改造为多模态生成器。对于输入，使用疾病语义（如 `[DIAGNOSIS] Pneumonia`）作为内容提示，同时插入K个音频占位符 `[AUDIO_0]...[AUDIO_K-1]`。
        *   风格投影：用预训练的 BEATs 编码器从参考音频提取特征，经时序池化后通过一个可训练的MLP（风格投影器）映射为K个风格嵌入向量，替换音频占位符的原始嵌入。
        *   自回归生成：LLM在“[诊断内容] + [风格表示]”的混合提示下，自回归预测一个离散的声学单元序列（来自BEATs码本，大小V）。
        *   防泄漏训练：在训练时，对约10%的目标位置（M）进行随机掩码，用专用的 `[BEATs MASK]` 向量替换前一个token的嵌入，防止模型在自回归时“偷看”真实的前一单元，确保训练稳定性。
    *   第二阶段：条件流匹配（CFM）波形重建：
        *   输入：第一阶段预测的离散单元序列作为内容条件，BEATs特征的时序平均值作为全局音色条件。
        *   过程：CFM解码器（基于Diffusion Transformer）学习一个速度场，将噪声先验（高斯噪声）沿着一条直线路径变换为梅尔频谱图。训练目标是最小化预测速度与真实速度（x1 - x0）的均方误差。
        *   输出：重建的梅尔频谱图经过 Vocos 神经声码器转换为最终波形。该设计确保了对呼吸音中瞬态事件（如哮鸣音、爆裂音）的相位感知重建。

3.  Diagnoser（多模态呼吸音诊断器）：
    *   目标：融合临床文本（EHR摘要）和音频特征，对16类呼吸疾病进行分类。其核心架构如下图：
    ![图3：Diagnoser架构：模态编织与战略全局注意力](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/ZkoojtEm3W-2.png)
    *   输入层模态编织：将EHR文本token化后，在序列中插入一个连续的、包含T=496个占位符的音频块。使用预训练BEATs提取音频特征，经对齐（裁剪/填充到T步）和一个可学习投影层W后，原地替换这些音频占位符。这样，文本和音频在第一个输入层就形成了一个单一的、token对齐的序列，实现原生跨模态交互。应用了轻度的token/帧dropout以增强鲁棒性。
    *   战略全局注意力：基于 Longformer 骨干网络。其注意力模式结合了高效的滑动窗口（局部）注意力和稀疏的全局注意力。全局注意力被分配给三类token：(i) 分类器 `[CLS]`；(ii) 临床描述 `[DESCRIPTION]`；(iii) 音频“锚点”。
       音频锚点机制：在T=496的音频块中，以步长s=4进行采样，形成全局音频锚点集合A。相邻锚点间距约为80.6ms（s  Δt，Δt≈20.16ms）。这些锚点与整个序列（包括文本）互相关注，充当跨模态枢纽。这使得远处的文本症状（如“夜间干咳”）能够直接查询瞬态的声学事件（如哮鸣音），在避免二次复杂度的同时，提供了约80ms的时间分辨率来定位瞬态事件。

### 💡 核心创新点

1.  闭环主动课程学习框架（Thinker-A2CA）：
    *   局限：传统方法中，数据增强/生成与模型训练是分离的、静态的，无法针对性解决模型弱点。
    *   创新：提出由LLM驱动的智能体作为中央规划器，主动分析诊断器的失败案例（错误档案）和不确定性，并据此调度生成器进行“对抗性”或“课程式”样本合成。这将数据增强从被动补救转变为精准的、自我修正的训练课程。
    *   收益：在相同合成预算下（B=50k），Thinker-A2CA 策略比随机、类别先验和静态不确定性采样策略，在 Macro-F1 上取得了显著提升（0.598 vs 0.421/0.512/0.546），证明了其规划的有效性和样本效率。

2.  大规模跨域多模态基准（Resp-229k）：
    *   局限：现有公共数据集规模小、类别少、缺乏标准化的多模态标注，且评估协议多为同分布，无法充分测试泛化能力。
    *   创新：聚合5个公开数据库，构建包含22.9万条录音、16个诊断类别、约408小时的数据集。为每个样本配对一个由LLM（DeepSeek-R1-Distill-Qwen-7B）从元数据生成的标准化临床叙述，并经过两阶段质量审计。建立了严格的源离域（Source-Disjoint）评估协议：训练/验证来自3个源，测试仅在未见过的2个源上进行。
    *   收益：为领域提供了迄今最大、最具挑战性的多模态评估基准，强制模型学习跨机构、跨设备、跨协议的泛化能力。

3.  可控多模态生成器与内容-风格解耦（Resp-MLLM）：
    *   局限：现有生成模型（如 c-WaveGAN）通常只以类别标签为条件，无法独立控制病理内容和录音风格（设备、环境），且保真度有限。
    *   创新：通过模态注入将纯文本LLM改造为多模态单元生成器。设计双条件：疾病语义（文本）控制病理内容，BEATs风格嵌入（参考音频）控制录音风格。采用流匹配解码器进行高质量重建。
    *   收益：实验验证了优秀的解耦能力（风格交换时 Style-Sim=0.91, 病理准确率=97.9%；内容交换时 Style-Sim=0.93, 病理准确率=96.1%）。生成的数据用于平衡训练集后，大幅提升了诊断器的 Macro-F1（从0.212到0.598），证明了其下游价值。

4.  模态编织与锚点增强的多模态诊断器：
    *   局限：传统晚期融合（分别编码再融合）对齐弱；仅用[CLS] token进行全局注意力对细粒度声学事件不敏感。
    *   创新：在输入层进行“模态编织”，使跨模态交互从第一层就开始。提出“战略全局注意力”，以音频锚点作为额外的全局token，形成稀疏但高效的跨模态路由网络，专门针对呼吸音的瞬态特性（约80ms分辨率）。
    *   收益：消融实验（Table 4）显示，移除锚点导致准确率从0.849大幅下降至0.650，而移除锚点后准确率虽降至0.640但更不稳定，证实了锚点对于稳定多模态推理和捕捉瞬态事件至关重要。

### 🔬 细节详述

*   训练数据：
    *   主数据集：Resp-229k，包含229,101个样本，来自UK COVID-19、ICBHI、SPRSound、COUGHVID、KAUH五个公开数据库。训练集196,654样本，验证集16,931，测试集15,516。
    *   预处理：丢弃损坏或过短的录音。将原始20类标签统一为16类。为每个样本生成LLM临床叙述，并经过启发式和LLM审核（重写率0.7451%）。
    *   数据增强：核心增强由系统的生成器（Generator）在Thinker-A2CA指导下完成，生成指定类别和风格的样本用于平衡训练集。论文也对比了传统的朴素增强（复制、音高/时间扰动、加噪），发现其会导致跨域性能下降。
*   损失函数：
    *   诊断器（分类任务）：使用标准的交叉熵损失（Cross-Entropy Loss）。在预训练阶段（HF Lung V1和SPRSound）使用了Focal Loss（γ=2）以强调少数类别。
    *   生成器：
        *   单元生成（Resp-MLLM）：负对数似然损失（公式2），即自回归交叉熵损失。
        *   波形解码（CFM）：条件流匹配损失（公式5），即预测速度与真实速度的均方误差（MSE）。
*   训练策略：
    *   优化器：所有模型均使用AdamW优化器（β1=0.9, β2=0.999, weight decay=0.01）。
    *   学习率调度：
        *   LSTM/Conformer基线：余弦退火调度，峰值LR=1e-4。
        *   长上下文模型（Longformer等）：使用OneCycleLR调度，最大LR=1e-5。
    *   训练轮数：所有模型训练10个epoch。
    *   批次大小：LSTM/Conformer基线批大小为32；长上下文模型未明确说明，但使用了DeepSpeed。
    *   正则化：长上下文模型训练时应用了token dropout（文本 p=0.2，音频帧 p=0.1）和梯度检查点（gradient checkpointing）以节省内存。
    *   预训练：诊断器的Longformer骨干网络使用HF Lung V1和SPRSound数据集进行预训练。
*   关键超参数：
    *   Diagnoser：基于`longformer-base-4096`模型。音频块长度T=496（对应10秒16kHz音频）。全局锚点采样步长s=4（锚点间距≈80.6ms）。
    *   Generator：
        *   LLM骨干：Qwen3-0.6B-Base。
        *   风格投影器：两层MLP。
        *   风格token数K：默认8（消融实验表13显示K=8时性能最佳）。
        *   BEATs码本大小V：未明确说明具体数值，但来自预训练的BEATs模型��
        *   流匹配解码器：基于Diffusion Transformer (DiT)，训练目标为梅尔频谱图。
*   训练硬件：论文中未说明具体的GPU型号、数量和总训练时长。
*   推理细节：
    *   诊断器：标准前向传播，输出分类概率和校准置信度。
    *   生成器：
        *   单元生成：使用修改后的贪心或束搜索解码（自回归）。
        *   波形解码：CFM解码器在推理时使用32步（对比DDPM的32步，CFM延迟约低40%）。生成10秒16kHz音频。
        *   声码器：使用Vocos将梅尔频谱图转换为波形。

### 📊 实验结果

主要基准性能对比：
1.  ICBHI 四分类任务（官方60-40%划分）：
    | 方法 | 骨干 | 预训练数据 | Sp (%) | Se (%) | Score (%) |
    | :--- | :--- | :--- | :--- | :--- | :--- |
    | Dong et al.(2025) | AST | IN+AS | 85.99 | 49.11 | 67.55* |
    | Resp-Agent [Ours] | LLM+Longformer | HF+SPR | 79.29 | 66.10 | 72.70 |
    *   结论：Resp-Agent在敏感性(Se)上取得显著优势（66.10% vs 49.11%），总分高出5个百分点以上，表明其跨模态推理能更有效地识别阳性病例。

2.  Resp-229k 跨域测试集（Test-CD）16分类任务：
    | 模型 | 训练数据策略 | 准确率 (Acc) | Macro-F1 | Macro-F1 (尾部8类) |
    | :--- | :--- | :--- | :--- | :--- |
    | Conformer (音频) | 原始不平衡 | 0.720 | 0.1935 | - |
    | Resp-Agent Diagnoser | 原始不平衡 | 0.849 | 0.2118 | - |
    | Resp-Agent Diagnoser | Thinker-A2CA平衡 (B=50k) | 0.887 | 0.598 | 0.421 |
    | 基线：无合成 (CE) | 无 | 0.849 | 0.212 | 0.074 |
    *   结论：仅引入模态编织诊断器（不平衡数据），准确率已从0.720大幅提升至0.849。在Thinker指导的生成数据平衡后，Macro-F1从0.212跃升至0.598，尾部类别Macro-F1从0.074升至0.421，证明了闭环生成策略对解决长尾不平衡问题的决定性作用。

关键消融实验结果：
1.  诊断器架构消融（Table 4）：
    | 配置 | 准确率 | Macro-F1 |
    | :--- | :--- | :--- |
    | 晚期融合，原始元数据，无锚点 | 0.780 | 0.145 |
    | 模态编织，原始元数据，无锚点 | 0.640 | 0.175 |
    | 模态编织，原始元数据，有锚点 | 0.835 | 0.195 |
    | 完整Resp-Agent (LLM EHR + 锚点) | 0.849 | 0.212 |
    *   结论：1) 引入LLM生成的临床叙述带来稳定增益；2) 模态编织本身若不结合锚点，会导致模型不稳定（准确率骤降）；3) 音频锚点是稳定多模态编织并发挥其潜力的关键。

2.  生成器规划策略消融（Table 3 部分数据）：
    *   在匹配预算（B=30k）下，对比不同策略：
        *   仅针对稀有类别 (Rare-only): Macro-F1 = 0.489
        *   针对困难病例 (Hard-Case-only): Macro-F1 = 0.512
        *   针对困难域 (Hard-Domain-only): Macro-F1 = 0.506

    *   结论：Thinker-A2CA的综合多因素规划优于任何单一启发式策略，证明了其智能调度的价值。
