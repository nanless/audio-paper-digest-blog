### 💡 毒舌点评

本文最大的亮点是构建了一个从模型架构（JavisDiT）、训练范式、评估基准（JavisBench）到评估指标（JavisScore）的“全套解决方案”，这种工程系统完整性在音视频生成领域难得一见，为后续研究提供了坚实的基线。然而，其核心的时空先验估计器性能严重依赖于冻结的ImageBind编码器和合成的异步负样本，这在一定程度上削弱了模型自身从原始数据中学习精细时空对齐的潜力，更像是一个精巧的“插件”而非根本性的架构突破。

### 📌 核心摘要

1.  问题：现有的联合音视频生成（JAVG）方法在确保生成内容的高质量与精确同步方面存在不足，特别是缺乏对细粒度时空对齐（即“什么声音在哪里、何时发生”）的有效建模。
2.  方法核心：提出JavisDiT，一个基于扩散Transformer（DiT）的端到端生成框架。核心创新是设计了层级时空同步先验估计器（HiST-Sypo），该估计器通过对比学习从文本中提取全局语义先验和细粒度的时空先验（空间位置与时间戳），并通过跨注意力机制注入到DiT的各个块中，以引导音视频的时空同步生成。
3.  新在哪里：与简单参数共享或特征对齐的方法不同，本文首次提出显式地从条件中估计并注入层级化的时空先验来指导同步生成。此外，构建了更大规模、更多样化、更关注多事件场景的新基准JavisBench（10,140条数据），并提出了更鲁棒的同步评估指标JavisScore。
4.  主要实验结果：在自有基准JavisBench和已有基准（Landscape, AIST++）上，JavisDiT在生成质量（FVD, FAD）、语义一致性（CLIP, CLAP）和音视频同步性（JavisScore, AVHScore）等多项指标上均优于或持平现有方法。例如，在JavisBench上，JavisDiT的JavisScore达到0.154，优于最强基线FoleyCrafter（0.151）。消融实验证明HiST-Sypo估计器和精细时空注意力机制对同步性有显著贡献。
5.  实际意义：该工作为高质量的联合音视频生成提供了先进的系统方案，有望应用于短视频创作、电影音效合成等AIGC领域。其提出的基准和指标为未来的研究提供了更全面的评估标准。
6.  主要局限性：
    - 生成效率：基于扩散Transformer的模型推理速度较慢，生成一段4秒的240P视频需30秒（H100）。
    - 数据规模：训练数据（610K三元组）相对于视频生成的基础模型（如OpenSora）仍显有限，可能限制泛化能力。
    - 评估指标：JavisScore的准确率（~75%）仍有提升空间，无法完全替代人工评估。

### 🏗️ 模型架构

JavisDiT是一个端到端的联合音视频生成系统，整体架构如图2所示。

![JavisDiT整体架构与DiT块内部结构](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/y7HV7KT3Bd-1.png)
（图2：JavisDiT整体架构（a）及核心DiT块内部结构（b）。系统包含视频生成分支、音频生成分支、HiST-Sypo先验估计器和跨模态双向注意力模块（MM-BiCrossAttn）。）

整体流程：
1.  输入：文本提示。
2.  条件提取：
    - 粗粒度语义先验：由T5文本编码器提取。
    - 细粒度时空先验：由HiST-Sypo估计器（图3）从ImageBind的文本特征中提取，输出可学习的空间令牌 `ps` 和时间令牌 `pt`。
3.  生成过程：
    - 初始化噪声视频潜变量 `v_T` 和音频梅尔谱图潜变量 `a_T`。
    - 在DiT的每个去噪步骤中，视频和音频潜变量并行通过N=28个相同的AV-DiT块进行处理。
4.  DiT块内部结构（图2(b)）：每个块对视频和音频流进行如下操作：
    - 时空自注意力（ST-SelfAttn）：沿空间维度和时间维度依次进行多头自注意力，高效地对每个模态内进行时空建模。
    - 粗粒度跨注意力（CrossAttn）：通过标准的交叉注意力将T5文本特征注入视频/音频表示。
    - 细粒度时空跨注意力（Fine-Grained ST-CrossAttn）：将HiST-Sypo估计器输出的空间和时间先验分别沿空间和时间维度通过交叉注意力注入，这是实现细粒度同步的关键。
    - 跨模态双向注意力（MM-BiCrossAttn）：计算视频和音频之间的双向交叉注意力，促进两个模态间直接的信息交互与对齐。
    - 前馈网络（FFN）：进行特征变换。
    - 上述模块在空间和时间维度上各执行一次，然后重复N次。
5.  输出：最终生成的视频帧和音频梅尔谱图，分别通过预训练的视频和音频解码器重建。

HiST-Sypo估计器（图3）：这是一个基于4层Transformer编码器-解码器的模块。它以ImageBind文本编码器的77个隐藏状态作为输入，通过32个可学习的空间查询和32个时间查询，以变分采样的方式生成空间和时间先验令牌 `(ps, pt)`。这种采��设计允许同一段文本对应多种可能的时空布局，增加了生成的多样性。其训练目标是使估计的先验接近同步音视频对提取的特征，远离异步对的特征。

![HiST-Sypo先验估计器框架](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/y7HV7KT3Bd-2.png)
（图3：Spatio-temporal先验估计器框架。通过对比学习训练，使文本生成的时空先验接近同步音视频对的特征。）

#

### 💡 核心创新点

1.  层级时空同步先验估计器（HiST-Sypo）：
    - 是什么：一个从文本中估计全局语义先验和细粒度时空先验（位置与时间）的模块，用于指导生成过程。
    - 之前局限：先前方法多采用简单的参数共享、特征对齐或单向适配器，缺乏对“何时、何地”发生同步事件的显式建模。
    - 如何起作用：通过对比学习，使估计的先验对齐同步音视频的时空特征。先验通过跨注意力注入DiT，引导网络在正确的位置和时间生成对应的声音和画面。
    - 收益：显著提升了生成内容的音视频同步性，尤其是在多事件复杂场景下。

2.  基于DiT的统一联合生成架构：
    - 是什么：采用强大的Diffusion Transformer作为骨干，为视频和音频提供统一的建模框架。
    - 之前局限：先前JAVG模型多基于UNet（如MM-Diffusion），其时空建模能力有上限。部分DiT方法（如Uniform）仅简单拼接令牌，缺乏精细的跨模态交互设计。
    - 如何起作用：利用DiT的强表征能力，并精心设计了ST-SelfAttn、ST-CrossAttn和Bi-CrossAttn三种注意力模块，分别处理模态内聚合、条件注入和模态间交互。
    - 收益：在生成质量（视频FVD，音频FAD）上达到了新的水平。

3.  JavisBench：一个新的、更具挑战性的基准：
    - 是什么：一个包含10,140条高质量、带文本标注的发声视频的数据集，覆盖5个维度19个类别，特别强调多事件场景。
    - 之前局限：现有基准（AIST++， Landscape）场景单一、数据量少，无法全面评估模型在复杂真实场景下的表现。
    - 如何起作用：提供更多样化的测试数据，并定义了多维度的评估体系。
    - 收益：揭示了现有模型（包括本模型）在复杂时空组合场景下的不足，指明了未来研究方向。

4.  JavisScore：一种更鲁棒的同步评估指标：
    - 是什么：一种基于ImageBind、通过滑动窗口分段计算并选择最差帧相似度来衡量音视频同步性的指标。
    - 之前局限：常用指标AV-Align依赖光流，对微小运动和复杂多事件场景不敏感。
    - 如何起作用：通过分段评估和关注最不同步的帧，提高了对局部失同步的敏感性。
    - 收益：经人工标注数据验证，其评估准确性和鲁棒性优于现有指标。

### 🔬 细节详述

- 训练数据：
    - 阶段一（音频预训练）：0.8M音频-文本对，来自AudioSet、VGGSound等9个公开数据集。
    - 阶段二（ST-Prior训练）与阶段三（JAVG训练）：共610K视频-音频-文本三元组，主要来自MMTrail（136K）和TAVGBench（475K）两个新数据集，并过滤了大量人声视频。用于对比学习的负样本由同步负样本（异步音视频对）和异步负样本（通过时空增强合成）构成。
- 损失函数：
    - DiT训练：使用Rectified Flow目标。
    - HiST-Sypo估计器训练：使用四种损失函数的组合（公式A2）：令牌级铰链损失、辅助判别损失、音视频嵌入差异损失、L2正则化损失，旨在拉近先验与正样本嵌入，推远负样本嵌入。
- 训练策略：
    - 三阶段训练：1）音频分支预训练（冻结视频分支）；2）训练HiST-Sypo估计器；3）冻结ST-SelfAttn和CrossAttn，仅训练ST-CrossAttn和Bi-CrossAttn模块。
    - 优化器与超参数：学习率分别为1e-5（估计器）和1e-4（DiT），使用EMA，权重衰减0，Dropout 0。总训练约328个GPU天（H100）。
- 关键超参数：
    - 模型大小：总参数3.14B。每个DiT块有16个注意力头，隐藏维度1152。视频/音频分支各有28个DiT块。
    - 时空先验：Ns=Nt=32个令牌。
    - 推理：30步采样，分类器指导尺度为7.0。
- 训练硬件：未在正文中明确说明GPU型号和数量，但在附录表A2中提及了“GPU days (H100)”。
- 推理细节：生成4秒、240P（24fps）视频和16kHz音频。

### 📊 实验结果

主要结果对比（JavisBench）：
论文在提出的JavisBench上与多种基线方法进行了全面对比（表1）。方法分为级联式（T2A+A2V或T2V+V2A）和联合生成式（T2AV）。

| 方法 | 类型 | AV-Quality (FVD↓/KVD↓/FAD↓) | Text-Consistency (TV-IB↑/TA-IB↑/CLIP↑/CLAP↑) | AV-Consistency (AV-IB↑/CAVP↑/AVHScore↑) | AV-Synchrony (JavisScore↑) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| TempoTkn | T2A+A2V | 539.8 / 7.2 / - | 0.084 / - / 0.205 / - | 0.137 / 0.787 / 0.122 | 0.103 |
| See&Hear | T2V+V2A | - / - / 7.6 | - / 0.129 / - / 0.263 | 0.160 / 0.798 / 0.143 | 0.112 |
| FoleyCftr | T2V+V2A | - / - / 9.1 | - / 0.149 / - / 0.383 | 0.193 / 0.800 / 0.186 | 0.151 |
| MM-Diff | T2AV | 2311.9 / 12.2 / 27.5 | 0.080 / 0.014 / 0.181 / 0.079 | 0.119 / 0.783 / 0.109 | 0.070 |
| UniVerse-1 | T2AV | 194.2 / 0.5 / 8.7 | 0.272 / 0.111 / 0.309 / 0.245 | 0.104 / 0.793 / 0.098 | 0.077 |
| JavisDiT (Ours) | T2AV | 204.1 / 1.4 / 7.2 | 0.263 / 0.143 / 0.302 / 0.391 | 0.197 / 0.801 / 0.179 | 0.154 |

结论：JavisDiT在音视频质量（FVD, FAD）、文本一致性（CLIP, CLAP）和音视频一致性（AVHScore）上达到或接近最优。在音视频同步性（JavisScore）上，以0.154超过了最强的级联方法FoleyCrafter（0.151）和所有联合生成方法。

在已有基准上的性能（表2）：
| 方法 | Landscape (FVD↓/KVD↓/FAD↓) | AIST++ (FVD↓/KVD↓/FAD↓) |
| :--- | :--- | :--- |
| MM-Diff | 332.1 / 26.6 / 9.9 | 219.6 / 49.1 / 12.3 |
| AV-DiT | 172.7 / 15.4 / 11.2 | 68.8 / 21.0 / 10.2 |
| MM-LDM | 105.0 / 8.3 / 9.1 | 105.0 / 27.9 / 10.2 |
| JavisDiT (Ours) | 94.2 / 7.8 / 8.5 | 86.7 / 19.8 / 9.6 |

结论：在标准基准上，JavisDiT同样取得了SOTA结果。

| √ | √ | × | 6.127 | 1.191 | 0.150 |
