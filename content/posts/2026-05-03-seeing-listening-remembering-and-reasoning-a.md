### 📌 核心摘要

1.  要解决的问题：现有的多模态智能体缺乏像人类一样通过持续感知来构建和利用长期记忆的能力，难以在长时程任务中保持一致性并积累世界知识。
2.  方法核心：提出M3-Agent框架，包含记忆化和控制两个并行流程。记忆化过程实时处理视频流，通过面部/语音识别等工具，以实体为中心增量式构建情节记忆（具体事件）和语义记忆（抽象知识）。控制过程基于用户指令，利用强化学习训练的策略模型，在长期记忆上进行多轮推理和迭代检索以完成任务。
3.  与已有方法相比新在哪里：超越了传统在线视频理解方法（如仅压缩视觉Token）或简单的检索增强生成（RAG）。其创新在于：(1) 构建了跨模态（视觉、听觉、文本）且以实体为中心的长期记忆图；(2) 将强化学习应用于控制过程，实现自主、多轮的记忆检索与推理。
4.  主要实验结果：在自建的M3-Bench-robot/M3-Bench-web和公开的VideoMME-long三个基准上，M3-Agent显著优于所有基线。与最强基线相比，准确率提升如下表所示：

| 基准测试       | 强基线                 | M3-Agent | 准确率提升 |
|----------------|------------------------|----------|------------|
| M3-Bench-robot | Gemini-GPT4o-Hybrid    | 30.7%    | +6.7%      |
| M3-Bench-web   | Gemini-GPT4o-Hybrid    | 48.9%    | +7.7%      |
| VideoMME-long  | Gemini-GPT4o-Hybrid    | 61.8%    | +5.3%      |
5.  实际意义：为构建具备长期记忆和推理能力的多模态智能体（如家用机器人）提供了可行框架和评估标准，推动了智能体从“瞬时反应”向“经验积累与利用”的发展。
6.  主要局限性：记忆化模型对动态、长视频流中实体关系的处理仍有优化空间；当前评估基于模拟的机器人视角视频或网络视频，与真实物理世界交互场景仍有差距；训练依赖大量合成数据和强监督信号。

### 🏗️ 模型架构

M3-Agent是一个由多模态大语言模型（MLLM）和多模态长期记忆数据库组成的智能体框架，其整体架构如图1所示，包含记忆化和控制两个核心工作流。

![M3-Agent架构图](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/PMz29A7Muq-0.png)
图1：M3-Agent架构。智能体通过记忆化工作流持续感知环境并构建长期记忆，通过控制工作流接收指令、推理并检索记忆以完成任务。长期记忆以实体为中心的多模态图形式组织。

1.  输入与感知：智能体通过传感器（模拟为视频/音频流）持续接收实时多模态输入。
2.  记忆化工作流：
    *   工具调用：对输入的视频片段（通常30秒）调用面部识别、说话人分离等工具，提取特征（面部ID、语音ID、转录文本）。
    *   记忆生成：将提取的特征与上下文一起输入记忆化策略模型（`memory-7b-sft`）。模型生成两类记忆：
        *   情节记忆：描述具体事件（如“Alice接过咖啡说…”）。
        *   语义记忆：提炼抽象知识（如“Alice喜欢喝咖啡”、“<face1>和<voice3>是同一个人”）。生成过程中，模型会引用已有的实体ID以确保一致性。
    *   记忆存储与更新：生成的记忆条目（文本、图像、音频片段）作为节点存入长期记忆图。新记忆会与已有节点进行匹配（基于内容相似度）：若匹配则更新节点权重（增加激活频率）；若不匹配则创建新节点。节点之间通过表示关系（如属于同一实体、因果关系等）的边连接。该图支持基于时间顺序和基于实体关联的检索。
3.  控制工作流：
    *   多轮推理循环：当接收用户问题`q`时，控制策略模型（`control-32b-rl`）开始工作。在每一轮（最多H轮），模型分析当前上下文（包括问题、历史交互），生成一个包含推理、动作和参数的响应。
    *   迭代检索：若动作为`[Search]`，则使用参数（如查询文本）调用长期记忆的搜索工具（`search node`或`search clip`），检索相关记忆片段（如人物信息、事件片段）。检索结果被追加到上下文，进入下一轮推理。
    *   最终回答：若动作为`[Answer]`，则输出最终答案并结束循环。此过程允许模型进行多步规划，例如先搜索人物背景，再搜索相关事件，最后综合推理。
4.  关键设计选择：
    *   实体中心记忆：通过全局维护的面部/语音ID及关联，解决了长视频中人物身份一致性这一核心挑战。
    *   权重投票机制：处理记忆构建中可能出现的冲突信息，依赖更频繁激活（更可靠）的信息。
    *   RL驱动的控制：使智能体能够学习更优的多轮检索策略，而非简单的单次RAG注入。

### 💡 核心创新点

1.  模仿人类认知的多模态长期记忆框架：创新性地将“记忆化”与“控制”解耦并行，模仿人类“边感知边记忆”和“按需检索推理”的认知过程，使智能体能增量构建并利用世界知识。
2.  实体中心的多模态记忆图：提出以实体（人物、物体）为核心节点，组织跨模态（脸、声、文本）记忆信息。该结构不仅支持事件检索，更支持围绕实体的关联知识检索，增强了记忆的一致性和推理深度。
3.  强化学习训练的多轮推理控制器：不同于传统的单次检索生成，将控制过程建模为序列决策问题，利用DAPO强化学习算法训练策略模型，使其能自主决定何时检索、检索何内容，实现更精准、更灵活的上下文感知推理。
4.  面向智能体记忆推理的新基准M3-Bench：构建了首个专门评估多模态智能体长期记忆效能和基于记忆的推理能力的基准。包含机器人视角和多样化网络视频，并设计了五类需要复杂记忆推理的问题（如表1所示），填补了现有长视频问答基准的空白。
5.  高质量记忆的合成训练流程：提出了一套结合GPT-4o和Gemini-1.5-Pro优势的记忆合成方法，以及通过“元剪辑”算法自动构建跨模态身份等价关系的标注流程，为训练强大的记忆化模型提供了高质量监督数据。

### 🔬 细节详述

*   训练数据：
    *   记忆化模型：使用内部视频数据集，共500个长视频（26,943个30秒片段），并通过合成流程为每个片段生成情节记忆、身份等价关系和其他语义记忆，共10,952个训练样本，200个验证样本。
    *   控制模型：训练环境由`memory-7b-sft`为上述训练视频生成的长期记忆构建。QA对来自同一内部数据集，共2,736对。
*   损失函数：
    *   记忆化模型：标准监督微调（SFT）损失，最小化生成记忆与合成示范数据之间的交叉熵。
    *   控制模型：使用DAPO算法进行强化学习优化。奖励函数为二值奖励（1：GPT-4o评估答案正确；0：否则）。优化目标是最大化带惩罚的策略梯度，鼓励生成高奖励轨迹。
*   训练策略：
    *   记忆化模型：在Qwen2.5-Omni-7b上进行SFT，3个epoch，学习率1e-5，批量大小16，使用16块80GB GPU。
    *   控制模型：在Qwen3-32b（`control-32b-prompt`）基础上进行DAPO训练。对于每个问题，生成G条轨迹，根据GPT-4o评分计算奖励和优势。超参数见附录H.1。
*   关键超参数：记忆化模型为7B参数。控制模型为32B参数。最大推理轮数`H=5`。记忆搜索返回Top-2片段（`k=2`，相似度阈值`t=0.5`）。
*   训练硬件：论文未明确说明DAPO训练的硬件配置，但SFT使用了16×80GB GPU。
*   推理细节：控制过程采用自回归解码，温度等参数未说明。通过`[Search]`和`[Answer]`动作进行交互式检索与生成。
*   正则化：DAPO算法包含裁剪机制（clip ratio ϵlow, ϵhigh）和归一化优势估计，用于稳定训练。

### 📊 实验结果

主要对比实验（表4）：M3-Agent在所有测试集上达到最优。

| 方法 | M3-Bench-robot | M3-Bench-web | VideoMME-long |
| :--- | :---: | :---: | :---: |
| Socratic模型 | | | |
| Qwen2.5-VL-7b | 3.4 | 14.9 | 46.9 |
| Gemini-1.5-Pro | 8.0 | 23.2 | 38.0 |
| GPT-4o | 8.5 | 28.7 | 38.8 |
| 在线视频理解方法 | | | |
| MovieChat | 11.2 | 12.6 | 19.5 |
| MA-LMM | 24.4 | 24.3 | 17.3 |
| Flash-VStream | 19.4 | 23.6 | 25.0 |
| 智能体方法 | | | |
| Gemini-Agent | 16.9 | 34.1 | 55.1 |
| Gemini-GPT4o-Hybrid | 24.0 | 41.2 | 56.5 |
| M3-Agent | 30.7 | 48.9 | 61.8 |

分类型结果：M3-Agent在“人物理解”(PU)和“跨模态推理”(CM)上优势尤为明显。例如在M3-Bench-robot上，其PU得分为43.3%，比最强基线MA-LMM（39.1%）高4.2个百分点；在M3-Bench-web上，其CM得分为44.3%，比最强基线Gemini-GPT4o-Hybrid（37.6%）高6.7个百分点。

记忆化消融实验（表5，固定控制模型为`control-32b-rl`）：
| 记忆化模型 | M3-Bench-robot | M3-Bench-web | VideoMME-Long |
| :--- | :---: | :---: | :---: |
| memory-gemini-prompt | 28.7 | 46.3 | 52.7 |
| memory-7b-prompt | 25.3 | 39.9 | 50.8 |
| memory-7b-sft (M3-Agent) | 30.7 | 48.9 | 61.8 |
| w/o 等价关系 | 19.5 | 39.7 | 52.1 |
| w/o 语义记忆 | 13.6 | 29.7 | 48.7 |
关键结论：(1) SFT训练的专用模型（memory-7b-sft）优于直接提示的通用模型（memory-gemini-prompt）；(2) 身份等价关系和语义记忆对性能至关重要，移除后性能大幅下降。

控制消融实验（表6，固定记忆化模型为`memory-7b-sft`）：
| 控制模型 | M3-Bench-robot | M3-Bench-web | VideoMME-Long |
| :--- | :---: | :---: | :---: |
| control-32b-grpo | 30.0 | 47.7 | 58.7 |
| control-32b-prompt | 20.7 | 40.9 | 52.5 |
| control-32b-rl (M3-Agent) | 30.7 | 48.9 | 61.8 |
| w/o 轮间指令 | 12.8 | 32.3 | 48.3 |
| w/o 推理 | 19.0 | 40.1 | 52.3 |
关键结论：(1) DAPO训练优于GRPO；(2) RL训练比提示方法带来巨大提升；(3) 移除多轮推理（轮间指令和显式推理）会导致性能显著下降，证明了多轮迭代检索的重要性。

自动评估验证：使用GPT-4o作为评判器，与人工标注的多数投票结果有96%的一致性。
