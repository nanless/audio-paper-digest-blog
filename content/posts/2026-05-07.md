📌 **核心摘要**

1.  **要解决的问题**：随着生成式音频模型的发展，自动评估方法落后。传统客观指标领域适用性窄，通用多模态大语言模型（MLLM）评估性能不稳定，专用LLM评估框架泛化能力和指令灵活性不足。
2.  **方法核心**：提出JASTIN，一个通用的、指令驱动的音频评估框架。它将音频评估表述为自指令推理任务，通过一个可训练的音频适配器，将冻结的高性能音频编码器与微调的大语言模型（LLM）主干网络桥接起来。
3.  **新在何处**：相较于已有方法，JASTIN的新颖之处在于：（1）**统一泛化**：单一模型无需任务特定重训即可评估语音、音乐和音效；（2）**综合数据准备**：采用包含多源、多任务、多校准、多描述的数据准备流水线；（3）**指令鲁棒性**：通过自指令训练范式，平衡了语义敏感性和词汇鲁棒性；（4）**人类对齐**：旨在实现与人类主观评分的高相关性。
4.  **主要实验结果**：在QualiSpeech、SpeechEval、AES等多个数据集上，JASTIN在皮尔逊（PCC）和斯皮尔曼（SRCC）相关系数上均达到了SOTA水平。例如，在QualiSpeech的Distortion指标上，JASTin的PCC为0.561，显著优于通用MLLM（如Gemini-3-Pro的0.560）和专用指标（如AES-PQ的0.404）。在AudioMOS2025的SynMOS任务上，PCC为0.496，优于最强基线UTMOS的0.610？（注：此处数据依据表格III，Jastin为0.496，UTMOS为0.610，UTMOS更优，但论文结论认为Jastin在跨域零样本任务上更具优势和一致性）。消融研究证实了多源数据和LLM驱动数据增强的有效性。

5.  **实际意义**：为音频/语音生成模型的开发和迭代提供了一个更通用、灵活、与人类评价对齐的自动化评估工具，有望降低对昂贵且耗时的人工听力测试的依赖。
6.  **主要局限性**：对时序敏感的细粒度特征（如语速）评估能力较弱；对某些特殊音频领域（如ASMR）的美学判别存在困难，容易将其误判为质量缺陷。

📌 **核心摘要**

1.  **解决的问题**：高质量歌唱注释（歌词、音符、对齐）获取成本高昂，现有自动转录系统依赖复杂多级流水线，易出错、难以扩展，且对分布外（OOD）歌唱数据泛化能力差。
2.  **方法核心**：基于大型音频语言模型Qwen3-ASR构建VocalParse，将歌唱转录重构为一个统一的自回归序列生成问题。核心是设计“交错提示”格式（歌词-音符交错）来显式编码词-音符对应关系，并引入“链式思考”策略——先生成纯歌词序列作为语义骨架，再生成交错序列，以解决语义连贯性问题。
3.  **与已有方法相比新在哪里**：将传统多阶段流水线（ASR+对齐+旋律转录）统一到一个端到端的自回归模型中；通过交错提示和链式思考，在保留LALM语义理解能力的同时，实现了歌词、旋律及精细对齐的联合建模；无需额外后处理或复杂解码结构。
4.  **主要实验结果**：在多个歌唱数据集上达到SOTA。在Opencpop数据集上：
    *   **自动歌词转录 (ALT)**：WER为3.79%，显著优于LyricWhiz (9.68%) 和Whisper-adapted (8.67%)。
    *   **自动旋律转录 (AMT)**：在音频-歌词条件下，MAE_pitch为0.35，MAE_note为0.43，MAE_dur为0.33，均优于ROSVOT、MusicYOLO和STARS。消融实验表明，去除链式思考会使WER从3.79%上升至7.18%，去除SingCrawl数据会使MAE_pitch从0.56上升至0.94。
    *   下游歌唱语音合成（SVS）实验证明，使用VocalParse自动标注的大规模数据（2000小时）能显著提升节奏相似性（IOU从0.46提升至0.59）和旋律相似性（RPA从0.39提升至0.74）。
5.  **实际意义**：为构建大规模、高质量歌唱数据集提供可扩展的自动标注方案，有望降低歌唱语音合成等下游任务的门槛；展示了LALM通过适当提示策略可有效迁移到复杂音乐信息检索任务。
6.  **主要局限性**：BPM估计假设全局恒定速度，对含速度变化的音乐不友好；自回归生成无法绝对保证两阶段生成的歌词一致性；性能上限受教师模型（自动标注流水线）质量制约；实验仅在普通话数据上进行。

4.  **实验结果**：构建了四个新的Fed-LDL基准（FER-LDL， FI-LDL， KADID-LDL， PIPAL-LDL）。在这些基准上，FedQual全面超越了包括FedAvg、FedProx、MOON等在内的各类基线方法。例如，在FER-LDL上，FedQual的KL散度为0.2528（最低），余弦相似度为0.8739（最高）。消融实验证实了客户端校准（+A）和服务端重加权（+A+B）模块的有效性。框架在不同的标注噪声强度、噪声客户端比例、标签分布偏移等条件下均表现出强鲁棒性。
5.  **实际意义**：为医疗、情绪识别等隐私敏感且标签模糊的跨机构协作学习场景提供了新的解决方案。同时，发布的四个带有可控标注质量差异的基准，为未来评估此类方法提供了标准化的测试平台。
6.  **主要局限性**：质量指标（q_m）的计算目前依赖于外部元数据（如标注者数量），在无法获取此类元数据的真实场景中应用受限；框架假设客户端能诚实报告质量信息，未考虑对抗性场景；实验主要在视觉任务（人脸情绪识别、图像质量评估）上进行，在音频、文本等领域的泛化性有待验证。

1.  **要解决什么问题**：在音视频深伪内容泛滥的背景下，研究非专业人群（众包工人）通过在线任务判断视频真实性及识别篡改类型的能力边界与可靠性，为人机协同检测系统提供设计依据。
2.  **方法核心**：采用匹配的众包实验设计，在Prolific平台上招募工人，对来自AV-Deepfake1M和TMC两个音视频深伪数据集的96个视频（每个数据集48个，平衡采样真、纯音频篡改、纯视频篡改、音视频联合篡改四类）进行独立判断（每个视频10次）。评估维度包括真实性判断的准确性与一致性，以及操作类型识别准确性和时间戳一致性。分析了“多数投票”和“Dempster-Shafer”两种聚合策略的权衡。
3.  **与已有方法相比新在哪里**：已有研究多关注人类个体或小样本在深伪检测上的表现，或提出新的自动检测模型。本文的创新在于：1）使用统一、匹配的实验协议对比两个主流数据集上众包的系统性表现；2）同时分析真实性判断、操作类型归因、时间戳报告三个层次；3）量化了不同聚合策略带来的“漏检率”与“误报率”之间的权衡。
4.  **主要实验结果**：

    -   **聚合策略权衡**：Dempster-Shafer聚合相比多数投票能提高对篡改视频的召回率（例如在TMC上从0.556提升至0.667），但同时会增加对真实视频的误报率（从0.083提升至0.167）。

6.  **主要局限性**：1）实验样本有限（每数据集48视频），可能无法完全代表现实多样性；2）众包工人主要来自美国，结论的跨文化性未知；3）未与当前最先进的自动深伪检测器进行性能对比，无法定位众包方法在技术栈中的精确位置；4）实验中未明确指导工人开启音频，可能影响对音频篡改的敏感性。

📌 **核心摘要**

1.  **要解决的问题**：在参数规模极小（0.1B）的约束下，如何设计一个能够接受文本、语音、图像输入，并输出文本和流式语音的完整多模态交互模型，同时保证其完全可复现和可审查。
2.  **方法核心**：采用“Thinker-Talker”分离架构。Thinker是MiniMind语言模型主体，处理文本和注入的感知特征；Talker是一个独立的四层模块，从Thinker的中间层获取语义状态，并结合自回归的八层Mimi码本历史来生成语音码本。语音条件（参考音色、说话人嵌入）直接嵌入到Talker的音频码本上下文中。
3.  **新在何处**：核心创新在于针对小规模模型提出的三项关键设计：1）**中间层语义桥接**，避免从最后一层提取过于偏向文本的特征；2）**参数高效的八码本接口**，使用共享嵌入/头部加低秩适配器，而非八份独立参数；3）**完全开源的多模态序列格式与数据集**，固定了训练布局。
4.  **主要实验结果**：
    - **内部一致性（CER）**：Dense和MoE变体在自生成文本转录一致性测试中，平均字符错误率（CER）分别达到0.0897和0.0900。
    - **语音克隆相似度（余弦相似度）**：Dense模型在已见/未见音色上的平均相似度为0.5995，MoE为0.5937，相比仅用参考码本的基线（0.6150/0.5310）有提升。
    - **跨模型对比（T2A一致性）**：在简短英文问答中，minimind-3o（0.1B）的平均CER（0.0964）和WER（0.0973）高于Mini-Omni（0.5B， CER:0.0101）和Mini-Omni2（0.5B， CER:0.0371），尤其在中等长度回答上差距显著。
    - **关键消融**：Talker隐藏维度消融（表2）显示768维是性能与参数量的最佳平衡点；码本接口低秩消融（图8）证明中等秩（如256）已能恢复大部分性能，且输出头的秩比嵌入层的秩更重要。
5.  **实际意义**：提供了一个极低门槛的、端到端可复现的多模态语音交互研究平台。它证明在0.1B参数下，一个完整的多模态循环是可行的，并明确了在该规模下必要的组件和设计权衡，为社区提供了可直接分析和改进的基线。
6.  **主要局限性**：语音自然度和长句稳定性受限于模型规模，是其最明显的短板；视觉路径较弱，仅作为紧凑的视觉到语音通道；评估指标主要关注文本转录一致性，而非人类偏好的自然度或端到端任务完成度。
