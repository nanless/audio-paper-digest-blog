### 📌 核心摘要

1. 问题：现有的语音大模型（SpeechLLM）评估基准主要关注语义理解，忽视了语音中丰富的副语言特征（情感、语调）和音韵特征（重音、韵律），且多依赖合成语音，无法全面评估模型在真实、细粒度语音理解与推理上的能力。
2. 方法核心：提出MMSU基准测试，包含5000个精心标注的音频-问题-答案三元组，覆盖47个任务。其设计基于语言学理论（音韵学、修辞学、句法学等），并主要使用真实世界录音和专业录制的音频。
3. 新意：这是首个系统性整合语言学原理的语音理解基准；任务覆盖远超现有基准，包含大量独特的音韵感知和推理任务（如双关语解释、讽刺检测、基于停顿/重音的推理）；数据以真实音频为主，保证了声学真实性。
4. 实验结果：对22个模型进行评估。最强的Gemini-1.5-Pro平均准确率为60.68%，而人类基线为89.72%，差距显著。模型普遍在音韵相关任务（如近音词感知、音节感知）上表现不佳。开源模型Qwen2.5-Omni-7B（60.57%）与最强闭源模型性能接近。

| 模型 | 参数量 | 感知-语义 | 感知-音韵 | 感知-副语言 | 推理-语义 | 推理-音韵 | 推理-副语言 | 平均准确率 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Human | - | 87.10% | 94.32% | 92.88% | 82.16% | 87.60% | 89.12% | 89.72% |
| Gemini-1.5-Pro | - | 57.06% | 53.60% | 31.23% | 79.47% | 83.46% | 46.33% | 60.68% |
| Qwen2.5-Omni-7B | 7B | 55.12% | 37.33% | 39.35% | 88.00% | 81.37% | 48.36% | 60.57% |
| Kimi-Audio | 7B | 57.64% | 42.30% | 35.74% | 81.77% | 76.65% | 55.22% | 59.28% |
| GPT-4o-Audio | - | 59.70% | 41.56% | 21.44% | 80.83% | 78.74% | 26.25% | 56.38% |
5. 实际意义：为评估和推动更全面、更接近人类水平的语音交互AI提供了新的标准和方向，明确指出了当前模型在音韵理解和复杂推理上的不足。
6. 主要局限性：作为基准测试，其自身不提出解决模型缺陷的方法；数据集规模（5000条）相对有限，可能无法覆盖所有语音现象；评估仅采用多选题形式，可能无法完全反映模型的生成或开放式理解能力。

### 🏗️ 模型架构

本文为基准测试论文，未提出新的模型架构。其核心“架构”是其设计的评测框架，如图2所示。该框架采用三层分类体系：
- 第一层：区分感知（Perception）和推理（Reasoning）能力，类似人类认知的低阶与高阶处理。
- 第二层：将每种能力分为语言学（Linguistics）和副语言学（Paralinguistics）两大类。
- 第三层：进一步细分。语言学类下分语义（Semantics）和音韵（Phonology）；副语言学类下分说话人特征（Speaker Traits）和说话风格（Speaking Style）。
此分层体系确保了评估维度的系统性和理论性，47个具体任务均被映射到该体系的不同节点上。

### 💡 核心创新点

1. 基于语言学理论的任务体系设计：系统性地将语音学、音韵学、修辞学、句法学、语义学和副语言学理论融入47个任务的设计中，使评估具备坚实的理论基础，能够全面考察模型对语音多维信息的理解能力。
2. 以真实世界音频为主的数据构建策略：摒弃了多数基准测试对合成语音的依赖，优先使用开源真实语料库和专业录音室录制的音频，确保了评估所用数据的声学真实性和生态效度。
3. 覆盖音韵和副语言特征的全面评估框架：首次在SLU评估中全面引入对语调、重音、停顿、延长音、近音词、口音等底层音韵特征以及讽刺、情感上下文等复杂副语言现象的考察，填补了关键评估盲区。

### 📊 实验结果

论文对22个模型（12个专用SpeechLLM和10个全模态OmniLLM）进行了系统评估。

主要基准测试结果（基于准确率%）：

| 类别 | 模型 | 感知平均 | 推理平均 | 总平均 |
| :--- | :--- | :--- | :--- | :--- |
| 基线 | 人类评估者 | 91.24 | 86.77 | 89.72 |
| | 随机猜测 | 24.90 | 25.02 | 25.37 |
| SpeechLLM | Kimi-Audio (7B) | 43.52 | 76.03 | 59.28 |
| | MERaLiON (10B) | 35.74 | 73.68 | 54.10 |
| | Qwen2-Audio-Instruct (8.4B) | 39.02 | 68.90 | 53.27 |
| OmniLLM | Gemini-1.5-Pro | 46.10 | 76.16 | 60.68 |
| | Qwen2.5-Omni-7B | 42.50 | 79.83 | 60.57 |
| | GPT-4o-Audio | 39.67 | 71.96 | 56.38 |
| | MiniCPM-O (8.6B) | 40.54 | 73.57 | 56.53 |

关键发现：
1. 模型与人类差距显著：最强模型（Gemini-1.5-Pro）准确率仅约60.7%，远低于人类基线（89.7%）。
2. 感知能力是主要瓶颈：与人类“推理难于感知”相反，模型“感知”平均分普遍低于“推理”平均分，表明模型在提取基础声学特征（尤其是音韵和副语言）上存在根本缺陷。
3. 音韵能力普遍薄弱：模型在音韵相关任务（如近音词感知、音节感知、重音感知）上表现最差，最佳模型（Gemini-1.5-Pro）在音韵感知任务上准确率仅53.6%。
4. 开源模型竞争力强：开源模型Qwen2.5-Omni-7B和Kimi-Audio表现接近或达到最强闭源模型水平。

噪声鲁棒性实验：
- 向音频中添加不同强度的高斯噪声后，模型性能仅有小幅下降，表明模型确实在利用音频信号而非仅依赖文本偏差。Gemini-1.5-Pro和Qwen2.5-Omni表现出最强的鲁棒性。

![模型噪声鲁棒性实验结果](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/yHzCDP1tXw-4.png)

错误分析：
- 对五个代表性模型的错误样本进行分析，感知错误（Perceptual Errors） 是最主要的错误来源（占比约47%-59.5%），其次是推理错误和知识缺乏。
