# 📄 同音词的语义何时会留下声学痕迹？

> 英文题目：*[Letters hide the truth from our eyes: English homophones have meaningfully different phonetic realizations](https://arxiv.org/abs/2608.26749)*
>
> 一句话：**新闻语料中的异形同音词 token 可由时间归一化声谱区分，并与上下文化嵌入线性对齐；时长消融削弱而未消除这种关联。**

### 💬 毒舌点评

价值在于提出可被后续受控实验推翻的对齐命题，而非宣告语义单独决定发音。

### 📌 核心摘要

本文以时间归一化频谱、分类、GAM、LDL 和 PLS 组成证据链，说明英语异形同音词的发音细节在该语料中可区分、与语境嵌入对齐且不全由时长解释。

把 *wait* 与 *weight* 念给人听,字典会把它们归到同一读音;这很容易诱导 1 个更强的假设:只要音位序列相同,词在真实话语里的声学实现也应相同。本文把这个直觉变成可检验的问题:在自然语境中、同属 1 个异形同音词对的 2 个词,能否仅凭目标词那一小段语音被区分?如果能,区别又是否与它在句中表达的意义有关?作者从美国电视新闻中取 35 对异形同音词、70 个正字词,每个词抽取 200 个 token,总计 14,000 个 token。这里的 token 是 1 次具体说出某个词的实例,不是词典里的词条。

这不是「机器能不能猜对拼写」的演示。输入是经过时间归一化的目标词声谱表示,输出可以是词对身份、70 个词的身份,或与语境向量的对应;因此任何结论都首先是关于这套新闻语料中的声学表示。论文没有把 1 个分类准确率当成终点,而是依次追问:声谱有无可分线索、这些线索位于何种时频位置、它们能否与语境语义线性对齐、去掉时长后还留下什么。

传统抽象音位路线擅长说明 *wait* 和 *weight* 共享哪些离散单位,却倾向于把同一音位串视为同一种形式;它很难直接描述 1 个元音何时进入、某段擦音在哪些频带更强。另 1 条路线研究词频、可预测性、词类或形态如何影响时长与韵律,已经显示同音词不必等长,但「持续时间不同」还不足以说明整段频谱内部是否不同。

本文借鉴 2 类相关工作。Gahl(2008)讨论英语异形同音词的时长与频率/语境相关,给出必须控制时长的动机;Baayen 等人(2019)的判别词典思路把形式与意义看成可学习的关联,而非先验不可穿透的符号墙。作者并没有证明后者取代音位理论,而是用它提供 1 条可失败的计算路径:若语境表示与语音表示的对应只来自偶然配对或词标签,置换配对应产生同样的表现;若对应保留结构,真实配对应胜过置换。

论文的窄主张是:在所选新闻 token 上,异形同音词成员的时间归一化频谱存在系统差异;这些差异与由前文上下文得到的向量表示存在可预测的线性对应。它不主张人类听者一定能可靠察觉这些差异,也不主张语义是唯一原因,更没有给出端到端语音合成器。

要推翻这条主张,至少有 3 种观察会很有力:第一,真实配对与置换配对在留出 token 上无差;第二,把时长相关方向从声谱中剔除后,词成员判别和语义对齐一同回到机会水平;第三,按节目、说话人或词对留出后效果消失。本文前 2 类检查给出支持,第三类没有报告。因此更准确的表述是「新闻语料中的形式—意义关联已被多种统计检验捕获」,而不是「意义直接造成了某个音段」。

### 🧭 深度解读

#### 当「同音」不等于「同样发音」:一个能在新闻语料里被测出的反例

#### 从原始波形到可比较的「词形状」

不同 token 的真实时长不同,直接逐帧比较会把「谁更长」误当成「谁的内部形状不同」。作者把每个目标词变成 21 个 Mel 频带、50 个时间步的图像,再展平成 1,050 维语音向量。图中的 470 ms *wait* 例子展示了这项变换:上方是原始声谱,下方是固定大小的表示;横向虚线标出频带,纵向虚线标出 50 个时间位置。

相邻分析窗的步长写作 \(h=\left\lfloor (N-w)/(T-1)\right\rfloor\):\(N\) 是该 token 可用的采样长度,\(w\) 是窗长,\(T=50\) 是目标时间帧数。这个式子不把每个词裁成相同毫秒数,而是让 50 个位置覆盖各自的完整发音进程。它解决的是「位置可比」;时长仍可能通过辅音、元音的相对压缩留在频谱里,所以后文还需要单独的 PLS 消融。读图时应先看两层图表示同一个 token、再看哪些细节被压缩到固定坐标,不能把图一当作已经证明语义效应的结果。

公式的教学作用是把「词内进程的位置」对齐到同一坐标,而不是把不同 token 强行裁成同样毫秒数;它只说明如何构造可比较的表示,不能代替时长消融或语义对齐检验。

式中的 T-1 是 50 个时间帧之间的间隔数,因而决定相邻分析窗怎样覆盖一个 token 的完整进程。

#### 语义路径不是词典向量,而是五词窗口中的 GPT-2 状态

语义侧使用 GPT-2 从目标词前最多五个词计算的上下文化嵌入(contextualized embedding,CE)。CE 不是给 *wait* 永远分配一个固定词典向量:相同拼写进入不同前文时,向量也可变化。作者先将高维 CE 经主成分分析(PCA)压缩,再与声谱向量建立映射。这样,语音与语义两端都以 token 为单位,问题变成「同一次说出某词时的语境状态,是否与该次发音的声学形状一致」。

图四用 t-SNE 把 14,000 个 CE 投到二维,仅用于观察而非训练结论。各正字词簇明显分开,与 CE 上约 95% 的词分类准确率一致;同一屈折范式的词也可能相邻。这个事实同时提示风险:CE 本身包含词类、拼写相关的文本统计以及语境语义,因而后续的对齐不能自动分解出「纯意义」成分。它提供的是可操作的语境表示,而非心智内容的完整测量。

#### 线性 LDL 把理解和产生拆成两个可检验方向

线性判别词典学习(LDL)在这里没有隐层。它估计两条最小二乘映射:理解方向从声谱向量预测 CE,产生方向从 CE 预测声谱向量。若某一方向在留出 token 上能找到正确的近邻,说明两种表示共享可预测结构;若随机打乱声谱与 CE 的配对也同样成功,原结论就站不住。

这一区分避免了一个常见跳跃。声谱到 CE 的成功并不等于大脑由声音恢复意义;CE 到声谱的成功也不等于模型会说话。它们都只是同一数据集上的线性对齐检验。作者分别用完整置换与词内置换建立基线:前者主要检验词型级关联是否超过随机关联,后者把同一词内 token 的对应打乱,因而更接近「同一词在不同语境里为何发得不同」的问题。

若把这两条路线画成一个最小实验图,左边是同一 token 的 1,050 维声谱,右边是它的 CE;训练只在训练折估计线性矩阵,测试折再做最近邻比较。完整置换把左右边的配对整体破坏,词内置换则保留每个词属于哪个类别,却破坏该词不同 token 的一一对应。因而两种基线回答的不是同一个问题:前者更接近「词的形式与语义空间是否整体对应」,后者更接近「词内语境变化能否解释词内发音变化」。这也是为何不能只报一个总体准确率而省去置换协议。

#### 数据如何避免把重复口播当作意义效应

样本来自 Red Hen 2016 美国电视新闻数据,含视频、字幕和强制对齐得到的词级时间戳。每个词至少出现 200 次;超过 200 次时下采样到 200 次。每个 token 的前文最多十词必须唯一,意在排除跨节目反复出现的广告口播。35 对词、每对 400 个 token 的设计让每一对都能有独立的二分类检查,GAM 例子中一对词的数据框可达到 420,000 行,因为 1,050 个声谱格被视为对时间步和频带有标记的观测。

但「前文唯一」不是独立留出。十折交叉验证以 token 为单位,相关节目片段、同一说话人或同一词对的模式仍可能同时落入训练与测试折。本文因此展示的是语料内留出 token 的可预测性,不能等价为跨新闻节目、跨说话人、跨语言或人类感知的泛化。复现者还应检查强制对齐误差、字幕质量、说话速度和节目的话题分布,因为这些因素可能与词的语境共同变化。

这里还有一个容易被数字遮住的采样含义。每个正字词固定取 200 个 token,使高频词不会仅因样本量占优;但它也把研究对象限定为在这套资料中足够常见、可稳定对齐的词。词对不是随机抽自全部英语同音词,电视新闻也不是会话、朗读或儿童语言。即使每一对有 400 个随机样本,随机性只在既定池内成立,不能替代对新说话人、新节目和新词对的外部测试。作者的「可泛化」应理解为对同一抽样机制下未见 token 的统计规律,而非无条件的语言普遍规律。

#### 第一关:声谱图本身确实保留了词对与词成员的线索

第一项 LDA(线性判别分析)把 35 个同音词对作为类别:50 维语音向量的十折准确率为 79.30%,随机置换数据为 2.82%。第二项更严格地在 70 个正字词之间分类,平均为 51.13%,置换基线为 1.43%。两者不是同一任务:前者表明不同词对总体有可区分的发音线索,后者要求在更多类别中辨认具体词成员。

在 35 个同音词对的 Experiment 1 中,vectorized time-normalized spectrograms 的 accuracy 为 79.3%,高于 2.8% permutation baseline;这里百分比越高越好,但这仍是 token 随机折内的比较。在 70 个 individual words 的 Experiment 2 中,LDA 的 accuracy 为 51.1%,高于 1.4% permutation baseline;它更严格,却同样不能替代按说话人或节目留出。

图二进一步逐对报告二分类;每对的机会线是 50%,而不是 1/70。许多词对远高于此线,但 *seen/sea*、*wait/way*、*plane/planes* 等近似发音的对更容易混淆。应把这些分数读成「该表示在当前 token 划分下含有可判别线索」,不能读成某个单词在任意录音中都可被拼写识别。统计显著或超过置换,只排除这里定义的随机配对;它不会替作者控制未留出的说话人和节目结构。

#### GAM 把「可分」还原成哪些时频区域不同

仅有分类分数无法说明差异在哪里。作者以广义加性模型(GAM)对时间步与频带拟合张量平滑项,并把时长、语速、前后停顿纳入控制;再比较含与不含词别差异面的模型。35 个词对中,加入差异面后的 AIC 平均下降 3,114。AIC 是拟合比较准则,下降表示在这组模型/数据中允许词别时频模式能显著改善拟合,不是人类听觉差异的百分比。

在 35 个 GAM models 中,including a difference spectrogram 的 AIC 平均下降 3114,相对不含 difference spectrogram 的模型拟合改善;AIC 越低越好,但该同主干比较不能把所有共同原因实验性隔离。

图三给出 *weight–wait*:两词的平均声谱、归一化时间上的音段对齐概率和差异面并列。作者观察到 *wait* 的元音起始更晚;另一个例子中 *sun* 的 /s/ 在高频有更强能量。这样的局部描述比「模型成功」更可审计,因为它明确到时间—频率区域。然而词类、拼写、重音、韵律、话题和说话人都可能共同变化;GAM 的协变量控制缩小了时长、语速、停顿的解释空间,并没有把所有共同原因实验性隔离。

#### 从「词型分开」到「语境意义也对得上」

LDL 的完整置换检验先问词型级结构。真实声谱—CE 映射在按词最近邻评测上明显优于把整张 CE 矩阵完全打乱的基线;图五分别画出声谱→语义与语义→声谱两方向。这个比较支持两空间的关系不是任意配对,却仍可能部分利用词身份及其与语境的稳定相关。

更尖锐的词内置换检验把每个词内部的 CE—声谱对应打乱。图六的 \(R_{\mathrm{L2}}\) 比较显示,产生方向中所有词对的真实分数都高于置换基线,除两例外均落在置换 95% 区间之外。这里的 \(R_{\mathrm{L2}}\) 可直观理解为预测向量的长度结构相对观测向量的保留程度;它不是因果效应量。证据因此支持 token 级语境变化与细粒度语音变化相关,却不能告诉我们是语义驱动韵律、语法同时驱动二者,还是还有未建模的说话状态。

L2 指向量长度的欧几里得二范数;在这里它服务于表示对齐的比较,不是人类听觉差异的量尺。

#### 用语义中心预测原型声谱,检查对应是否具有结构

作者再把每个词成员的 CE 求中心,输入学到的产生映射,得到预测的原型声谱;同时也可把原型声谱映回语义空间。图七比较预测的词间声谱差与 GAM 从观测数据估出的差异面。若线性映射只在数值上碰巧工作,这两种差异的空间结构未必相像;论文报告它们在 *wait/weight*、*sell/cell*、*sun/son*、*counsel/counsil* 等例子中相当接近。

特别有教育意义的是 *sell/cell*:时间对齐几乎没有显示音段时序差,但作者仍在擦音和元音频带内观察到能量差。这使「一切只是词更长或更短」的解释不够充分。相反,原型中心是对 token 的聚合,不能替代每个 token 的机制说明;原型图证明的是所学对应有可解释结构,而非逐次发音的完整重建,更不是拼写本身的直接声学作用。

#### 时长控制是必要的消融:去掉它之后还剩什么

声谱经时间归一化后仍可能保留时长痕迹。作者先预测时长:由 GPT-2 CE 预测的平均 \(R^2\) 为 24.15%,置换基线为 12%;由声谱预测时升至 52.90%。随后用偏最小二乘(PLS)找出同时与声谱变化和时长最相关的线性方向并剔除。去时长声谱预测时长的 \(R^2\) 降至 13.00%,接近置换声谱的 12.74%。这一连串数字首先说明 PLS 确实把大部分可由该表示预测的时长信息拿走了。

消融后的判别并未塌陷:用去时长声谱做词成员分类的平均准确率为 62.50%(标准误 1.24%),只用时长为 58.1%(标准误 0.01%);去时长声谱映射到 CE 的平均结果为 58.39%(标准误 1.23%),而仅时长映射为 51.79%(标准误 1.12%)。因此时长是贡献者而非全部解释。PLS 不是随机对照:它只能移除与该目标共变的线性成分,无法区分拼写、词类、强调、情绪、说话人及语法语境等剩余共同变化。这正是下一轮研究应做分组留出和受控产出实验的理由。

在 Figure 9 的 homophone discrimination 中,PLS-deflated spectrogram 的 prediction accuracy 为 62.50%,高于 duration only 的 58.1%;accuracy 越高越好,但这个消融只说明时长不是唯一通道,不能把剩余差异直接归因于语义。

[![五种表示预测时长的 R2 分布](https://arxiv.org/html/2608.26749v1/figs/30.10-emb-spec-defl-r2-boxplot.png)](https://arxiv.org/html/2608.26749v1/figs/30.10-emb-spec-defl-r2-boxplot.png)

[![原声谱、去时长声谱与仅时长的留出表现](https://arxiv.org/html/2608.26749v1/figs/30.10-emb-spec-defl-acc-boxplot.png)](https://arxiv.org/html/2608.26749v1/figs/30.10-emb-spec-defl-acc-boxplot.png)

把该消融读成一张因果图会出错。PLS 的输入是已经构造好的声谱向量,目标是实测时长;它通过线性投影删去最有助于预测时长的方向。若某个词类差异既影响时长也影响频谱,投影可能删去它的一部分,也可能保留其与别的频谱特征纠缠的部分。因此「去时长后仍可分」只排除了“现有可预测时长信息是唯一通道”这一解释。要说清拼写是否独立作用,需要同拼写多义词、异拼同音词与匹配词类/韵律的受控设计;要说清听者能否使用该线索,需要听辨或反应时实验。这些不是本文缺少一项简单附加分析就能补齐的结论层级差异。

#### 这组证据改变的是理论假设,不是立刻造出一个说话系统

从理论上看,结果给抽象、完全离散的同音形式观施加压力:若同一音位串的词成员在真实话语中有稳定的时频差,音位转写不足以耗尽其实现信息。论文也提出一种信息量解释:更具区分性的上下文可能与还原程度相关,CE 可被视为文本预测状态而非单一 surprisal 标量。这个框架适合提出可检验预测,例如控制词类与拼写后,语境向量是否仍与声谱差异对齐。

从工程上看,证据远未到可部署模型。论文没有报告端到端合成质量、识别错误率、实时成本、鲁棒性、跨语言测试或感知实验;线性 CE→声谱映射只能作为概念验证。更重要的是,35 对词不足以拆开形态结构和词类效应,作者自己也承认同音词的异拼拼写可能参与发音差异。把「在新闻语料中存在相关结构」升级为「语义决定发音」会越过现有设计。

#### 对复现者、研究者和部署者各意味着什么

复现的最小路线是:从同一 Red Hen 新闻来源重建词级字幕和对齐;按每词 200 token、前文唯一的规则抽取 35 对;将每个 token 转为 21×50 的时间归一化 Mel 表示,以 GPT-2 前五词上下文构造 CE;随后按原定义重跑 LDA、含协变量的 GAM、双向 LDL、完整/词内置换及 PLS 去时长。最应先补齐的不是更复杂的网络,而是按节目、说话人和词对的留出方案,以及公开的抽样清单、对齐版本、随机种子和完整参数。

研究者可以把拼写、词类、信息量、重音和语速设计成可分开的因素,并加入人类辨别任务,检验模型可见的频谱差是否可听。部署者应把本文当作表示诊断的启发,而非语音产品的性能声明:没有代码、许可证、模型权重、数据获取步骤或完整运行环境,也没有延迟和失败率,当前没有可直接接入的实现。最稳妥的外推是方法论层面的——不要因两词「同音」就预先抹掉其 token 级语音变异。

三个读者的行动并不相同。做语言建模的人应优先改变评测划分:报告 token 随机折之外的 speaker/program/word-pair 留出,并把完整置换、词内置换和去时长消融同时保留。做语料或实验语音学的人应先保存可核对的抽样与对齐链,再用平衡的词类、拼写和重音条件测试相互竞争的解释。做产品的人若希望利用这种细粒度变异,首先需要独立的任务指标,例如识别或合成在新说话人上的错误率、延迟和主观听感;在这些指标出现前,本文不能支持任何性能、成本或鲁棒性承诺。

#### 读完后应留下的八个判断

第一,异形同音词在这批新闻 token 中并非声学上完全等价。第二,固定 21×50 的时间归一化声谱让不同持续时间的词可在相同坐标中比较,但不自动消除时长信息。第三,79.30% 对词分类与 51.13% 的 70 词分类都超过置换基线,说明表示含线索而非证明普遍拼写识别。第四,GAM 的差异面把线索落到可检查的时频区域,并同时控制了部分协变量。

第五,LDL 的双向映射与置换比较支持形式—语境表示存在可预测对应;词内置换尤其把问题推进到 token 级。第六,原型 CE 映射出的差异面与观测差异相像,说明关联具有结构,而不是只有一个黑箱分数。第七,PLS 消融后仍有 62.50% 的词成员判别和 58.39% 的语义映射表现,所以时长不是全部。第八,真正尚待检验的是按说话人/节目/词对留出后的泛化、拼写和词类的独立贡献、人类可感知性与可复跑实现;这些缺口决定了本文应被读作严谨的相关性证据链,而不是已经完成的因果或工程方案。

换言之,最应带走的不是一句「同音词其实不同音」,而是一套读证据的次序。先确认表示能否在严格的随机基线外区分,再查看差异是否落在可解释的时频区域;随后问语境表示的配对是否超越完整与词内置换,最后才用时长消融排除最直接的替代说明。每一层都增加约束,也都留下了下一层必须补的缺口。这样读,既不会把细粒度语音变异误写成神秘的语义因果,也不会因为尚有混杂因素而忽略一条已经由分类、差异面、映射和消融共同支撑的经验规律。

这种阅读顺序也便于复核:每遇到一个漂亮数字,先回到它的比较对象、抽样单位和留出边界,再决定它能支持哪一级结论。只有把可重复的测量、竞争解释与外推范围同时写清,相关性证据才不会在转述中被悄悄扩大。
