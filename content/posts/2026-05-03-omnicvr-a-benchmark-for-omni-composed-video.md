### 📌 核心摘要

本文旨在解决现有组合视频检索（CVR）基准普遍忽略音频模态，无法评估模型在涉及声音（如对白、音乐、音效）变换的复杂检索场景下能力的问题。为此，论文提出了首个专注于全模态（视觉、音频、文本）组合检索的大规模基准OmniCVR。其核心方法是构建一个可扩展的自动化数据生成管道（包含视频分割、多模态标注、三元组挖掘），并在此基础上提出了一个名为AudioVLM2Vec的模型，该模型通过利用Qwen2-Audio为视频音频轨道生成精细文本描述，并将其注入查询中，从而增强检索模型的音频感知能力。与主要关注视觉修改的现有基准（如WebVid-CoVR, EgoCVR）相比，OmniCVR是首个将音频作为一等模态的基准，且其数据集中“集成”（同时修改视觉和音频）类查询占比超过57%，更能反映真实世界的多模态复杂性。主要实验结果表明，现有的强大基线模型（如VLM2Vec）在音频中心查询上性能严重下降（R@1仅12.4），而AudioVLM2Vec则大幅领先（R@1达77.2），证明了显式建模音频语义的必要性。该基准和模型为推动音视频联合理解与检索研究提供了重要的测试平台。其主要局限在于为注入音频语义而引入的音频转文本步骤显著增加了推理延迟（约为VLM2Vec的2.77倍）。

### 🏗️ 模型架构

论文提出的模型架构为AudioVLM2Vec，旨在将音频语义显式地注入到基于视觉语言模型（VLM）的检索框架中。其整体架构是对VLM2Vec框架的扩展。

![模型架构图](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/KxxR7emO5K-4.png)
（图5：AudioVLM2Vec框架图）

输入输出流程：
1.  输入：一段源视频、一段目标视频以及一条文本修改指令。
2.  处理流程：
    *   视觉分支：输入的视频帧经过一个预训练的图像编码器（如CLIP视觉编码器）提取视觉特征，然后通过一个轻量级的投影层映射到与语言模型兼容的表示空间，得到视觉令牌（Visual Tokens）。
    *   音频分支：输入的视频的音频轨道被送入一个音频理解模型（Qwen2-Audio-7B-Instruct）。该模型会为音频内容生成一个精细的自然语言描述（例如，“一段带有悲伤钢琴旋律的独白，说话者情绪低落”）。
    *   融合与对齐：将生成的音频文本描述与用户的修改文本指令拼接在一起，形成一个新的增强查询文本。这个文本连同视觉令牌一起被送入大型语言模型（LLM）骨干网络（如Qwen2-VL）。
    *   LLM处理：LLM利用其多头自注意力机制，联合处理来自视觉和文本（包含音频描述）的令牌，学习它们之间的协同和因果关系，从而在共享的语义空间中对齐多模态信息。
3.  输出：LLM的最终隐藏状态输出作为源视频的多模态嵌入向量。对目标视频进行相同的处理，得到目标嵌入向量。通过计算查询（源视频嵌入+修改指令）与候选目标视频嵌入之间的相似度进行排序，完成检索任务。

核心设计与动机：
*   动机：现有模型（如VLM2Vec）主要关注视觉，对音频处理能力薄弱。ImageBind等模型虽能处理音频，但其通用的跨模态对齐方式无法有效捕捉语音的语义内容和精细的音频特征。
*   设计：本架构采用“音频转文本”的显式桥接策略。它绕过了弱化的音频令牌表示问题，将非结构化的音频信号（尤其是语音）转换为LLM能够理解的丰富语义文本描述，再利用LLM强大的推理能力进行多模态融合。这是一种将专用音频模型的能力“迁移”到通用多模态检索框架的实用方案。

### 💡 核心创新点

1.  提出首个全模态组合视频检索基准（OmniCVR）：这是本文最核心的贡献。之前所有CVR基准（如WebVid-CoVR, EgoCVR, Dense-WebVid-CoVR）均只关注视觉模态的修改。OmniCVR首次将音频提升为一等模态，系统性地评估模型在理解并执行涉及视觉、音频或两者同时变化的检索指令的能力，填补了关键的评估空白。
2.  设计了一套可扩展的自动化基准构建管道：该管道包括基于内容的视频分割、利用多模态大模型（Qwen2.5-Omni）进行包含精细音频描述的标注、以及基于多模态相似度（CLIP, CLAP）的三元组挖掘。结合了大语言模型（Gemini 2.5 Pro）和人工专家的“与门”双重验证，确保了数据集在规模和质量上的平衡。
3.  提出AudioVLM2Vec模型，揭示了当前模型的音频推理缺陷：在VLM2Vec基础上，通过引入一个专门的音频到文本的模块来增强模型对音频语义的理解。实验表明，该模型在音频中心和集成查询上远超所有基线，尤其是与原VLM2Vec相比，在音频中心查询上R@1提升了64.8个百分点，强有力地证明了显式音频语义注入的有效性和必要性。

### 🔬 细节详述

*   训练数据：
    *   源视频数据：从HowTo100M, MSR-VTT, VATEX, YouTube8m-MusicTextClips, YouCook2, VALOR等公开数据集收集长视频，通过PySceneDetect分割为5-15秒的短片段，最终筛选出160k+个片段。
    *   训练集：利用上述管道从中挖掘生成了50k+个“源视频-修改指令-目标视频”三元组，其中45k+用于训练。
    *   测试集：人工双重验证的5k条金标测试集。
    *   数据增强：未在论文中明确说明针对训练数据的增强策略。
*   损失函数：论文未在正文给出训练AudioVLM2Vec的具体损失函数公式。根据描述，其优化目标是用于检索的对比学习损失，即拉近匹配对（查询，正目标）的嵌入，推远不匹配对（查询，负目标）的嵌入。具体损失函数名称未说明。
*   训练策略：论文未提供训练学习率、warmup、batch size、优化器、训练轮数/步数、调度策略等具体信息。仅提到在Tevatron 2.0框架下进行训练。
*   关键超参数：
    *   模型骨干：Qwen2-Audio-7B-Instruct（用于音频描述），Qwen2-VL（作为VLM2Vec的骨干）。
    *   视频帧采样：为公平比较，对所有基线（包括AudioVLM2Vec）均匀采样15帧。
    *   其他超参数未说明。
*   训练硬件：未说明。
*   推理细节：
    *   推理延迟：处理10秒视频，VLM2Vec为1.72秒，AudioVLM2Vec为4.77秒（实时因子RTF约为0.5）。
    *   候选集评估：每个查询打乱候选池5次并报告平均指标。
*   正则化或稳定训练技巧：未说明。

### 📊 实验结果

论文在OmniCVR基准上全面评估了多种基线模型，主要结果如下：

表4：OmniCVR整体性能比较（Recall@K）
| 模型 | 骨干 | R@1 | R@3 | R@5 | R@10 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 轻量级/任务特定模型 | | | | | |
| CLIP | CLIP | 27.54 | 50.46 | 56.70 | 62.62 |
| CoVR | BLIP2 | 11.46 | 22.88 | 28.08 | 35.18 |
| BLIP | BLIP | 6.30 | 11.84 | 14.12 | 17.00 |
| IMAGEBIND | CLIP | 17.28 | 29.55 | 43.34 | 45.33 |
| 大型多模态嵌入模型 | | | | | |
| OmniEmbed-v0.1-multivent | Qwen2.5-Omni | 31.90 | 51.50 | 57.04 | 64.00 |
| VLM2Vec | Qwen2-VL | 38.44 | 55.48 | 60.44 | 66.60 |
| AudioVLM2Vec (Ours) | Qwen2-Audio + Qwen2-VL | 66.98 | 77.84 | 80.86 | 84.40 |
结论：大型嵌入模型整体优于轻量级模型。AudioVLM2Vec在所有指标上取得最佳成绩，大幅领先次优的VLM2Vec（R@1高出28.54）。

表5：音频中心查询性能比较
| 模型 | 骨干 | R@1 | R@3 | R@5 | R@10 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| OmniEmbed-v0.1-multivent | Qwen2.5-Omni | 13.6 | 28.5 | 35.8 | 47.0 |
| VLM2Vec | Qwen2-VL | 12.4 | 23.3 | 30.4 | 42.3 |
| AudioVLM2Vec (Ours) | Qwen2-Audio + Qwen2-VL | 77.2 | 87.3 | 90.7 | 94.2 |
结论：音频中心查询暴露了现有模型的严重缺陷。AudioVLM2Vec在此类别上性能远超其他模型，R@1是VLM2Vec的6倍多。

表6：音频中心检索性能按目标音频类别细分（R@1）
| 目标音频类别 | VLM2Vec | AudioVLM2Vec (Ours) | 绝对增益 |
| :--- | :--- | :--- | :--- |
| 人类语音 | 11.36 | 96.59 | +85.23 |
| 音乐 | 16.07 | 86.43 | +70.36 |
| 声音 | 10.75 | 60.31 | +49.56 |
结论：AudioVLM2Vec在所有音频类别上均取得巨大提升，对语音和音乐的提升尤为显著。

表7：源视频重要性消融实验（音频中心查询，R@K）
| 指标 | VLM2Vec (有源视频) | 盲检/仅文本 (无源视频) | 性能下降 (∆) |
| :--- | :--- | :--- | :--- |
| R@1 | 77.20% | 28.10% | -49.10% |
| R@3 | 87.30% | 33.20% | -54.10% |
| R@5 | 90.70% | 42.50% | -48.20% |
| R@10 | 94.20% | 57.80% | -36.40% |
结论：移除源视频导致性能灾难性下降，证明修改指令是相对指令，需要源视频提供关键上下文。

表8：音频表示方式对比消融（在OmniEmbed骨干上）
| 模型设置 | 音频机制 | R@1 | R@3 | R@5 | R@10 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| OmniEmbed (原始) | 原生音频令牌 | 13.6 | 28.5 | 35.8 | 47.0 |
| OmniEmbed (修改版) | 音频转文本 (Ours) | 32.7 | 48.0 | 58.9 | 69.1 |
结论：在相同骨干和数据下，仅将原生音频令牌替换为Qwen2-Audio生成的文本描述，性能就获得巨大提升。

### ⚖️ 评分理由

*   学术质量：6.0/7
    *   创新性：提出首个全模态CVR基准是领域空白的重要填补，具有明确的创新贡献。提出的AudioVLM2Vec模型虽然架构简单，但通过实验证明了“音频转文本”这一策略在检索任务上的有效性，为模型设计提供了新思路。
    *   技术正确性：基准构建流程设计合理，包含自动化分割、多模态标注、基于相似度的三元组挖掘和双重验证。模型评估协议（打乱候选池、设置对照）较为严谨。
    *   实验充分性：实验部分非常扎实。在自有基准上评估了7个涵盖不同类型的基线；进行了关键的消融实验（源视频重要性、音频表示方式对比）；提供了按查询类型和音频类别的细粒度结果分析。表格数据清晰，支撑了主要结论。
    *   证据可信度：结论（现有模型音频处理能力弱，显式注入音频语义有效）得到多角度实验数据的强力支持。主要结论可信。
*   选题价值：1.8/2
    *   前沿性：将多模态大模型的能力评估从图文、视频-文本，推向包含音频的“全模态组合理解”，符合当前多模态智能向更真实感知发展的趋势。
    *   潜在影响：为视频搜索、视频编辑辅助、内容审核等需要理解音视频复杂交互的应用场景提供了更贴近现实的评估基准，有望推动相关研究。
    *   应用空间：基准可用于训练和评估面向真实世界视频的多模态检索与理解系统。
    *   读者相关性：对于从事多模态学习、音视频检索、跨模态对齐的研究者和工程师，该基准和模型评估结论有直接参考价值。
*   开源与复现加成：+0.8/1
    *   论文承诺将开源数据集（160k+片段，50k+三元组，5k测试集）、代码和模型权重。附录G提供了生成数据所用的关键提示词，增加了透明度。
    *   复现信息在基准构建流程上描述较详细，但在AudioVLM2Vec模型的具体训练细节（损失函数、超参数等）上有所缺失。
    *   整体而言，开源承诺有力，但细节略有不足，给予中上等加成。
