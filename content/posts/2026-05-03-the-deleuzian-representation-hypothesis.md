### 📌 核心摘要

本文旨在解决从神经网络黑盒中无监督提取可解释“概念”的挑战，以替代当前主流的稀疏自编码器（SAE）方法。作者基于德勒兹“概念即差异”的哲学观，提出了一种新方法：通过采样成对样本的激活差异，并使用逆偏度加权的KMeans聚类来识别这些差异中反复出现的模式，从而将聚类质心作为“概念”向量。与SAE试图重建激活空间不同，该方法直接建模“差异”，理论可解释为一种无监督的判别分析。主要实验结果表明，在跨模态（图像、文本、音频）的五个模型和多个数据集上，该方法在探针损失（Probe Loss）指标上平均排名第一，优于多种SAE变体，在部分任务上接近有监督的线性判别分析（LDA）上界。该方法还支持无损的概念引导，证明了提取概念的因果影响力。其局限在于评估依赖有标签数据、假设概念为线性表示，且未解决概念自动命名的问题。

### 🏗️ 模型架构

本文提出的是一种算法流程，而非一个端到端的神经网络模型。其整体架构如下图所示：

![论文中的流程图](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/10JEfJtiJM-1.png)

完整流程：
1.  输入：预训练神经网络在某一层对N个样本的激活值，每个激活是一个D维向量。
2.  采样激活差异：随机配对样本，计算每对样本激活的差值，得到一个包含N个差异向量的集合。
3.  加权聚类：使用KMeans算法对差异向量进行聚类，得到k个聚类质心（即“概念”方向）。关键的创新在于，在计算距离时，对每个差异向量根据其投影分布的逆偏度进行加权。偏度高的方向（即大部分值接近零但有极端值）会被降权，以促进最终概念的多样性。
4.  输出：k个聚类质心向量，每个向量代表激活空间中的一个“概念”方向。

核心组件与数据流：
- 差异采样器：从激活对中生成差异向量，旨在捕获样本间的判别性信息。
- 偏度计算模块：计算每个候选差异方向在全体样本投影上的偏度，并将其转化为权重。
- 加权KMeans聚类器：执行聚类，输出最终的概念向量。整个流程完全无监督，唯一超参数是聚类数量k。

### 💡 核心创新点

1.  基于“差异”而非“重建”的概念建模：与SAE等方法通过重建激活来提取特征不同，本文受德勒兹哲学启发，直接对样本间的激活差异进行建模和聚类，将“概念”定义为反复出现的差异方向。这为概念提取提供了一个全新的视角。
2.  偏度加权聚类以促进多样性：发现并利用了激活差异方向普遍存在偏度分布这一特性。通过引入逆偏度作为KMeans的权重，有效抑制了少数冗余、偏度高的方向主导聚类的结果，显著提升了所提取概念的多样性和代表性。
3.  与判别分析的理论联系：从理论上将所提出的方法阐释为一种无监督的判别分析。在假设激活差分方向的协方差各向同性的情况下，该方法等价于寻找最大化样本间分离度的方向，这为其有效性提供了坚实的理论支撑。
4.  支持无损的概念引导：由于提取的概念向量直接存在于原始激活空间，因此可以通过简单的加法操作（`x + α*c_i`）对模型内部表示进行引导，且过程可逆、无信息损失，这在实践中非常实用。

### 🔬 细节详述

- 训练数据：论文未提供新的训练数据。该方法使用的是预训练模型在现有公开数据集上的激活值。具体数据集包括：ImageNet（图像）、WikiArt（图像）、IMDB（文本）、CoNLL-2003（文本）、AudioSet（音频）。各数据集规模与划分见附录。
- 损失函数：该方法本身不涉及训练一个神经网络，因此没有传统的训练损失函数。其核心算法是KMeans聚类。
- 训练策略：不适用。方法是对预训练模型的冻结激活进行离线分析。
- 关键超参数：
    - 聚类数量 `k`：主实验中固定为 6144。
    - 激活层：所有评估均使用各模型最后一个Transformer块的输出激活。
    - 概念空间维度：固定为激活维度的8倍（通常为6144）。
    - 对于基线SAE：论文详细说明了各SAE的训练超参数（如学习率、L1系数）。
- 训练硬件：未说明。
- 推理细节：不适用。概念提取是离线分析过程。概念引导在推理时进行，通过修改激活向量实现。
- 正则化或稳定训练技巧：不适用。唯一的关键技巧是基于偏度的加权，用于稳定聚类并提升多样性。

### 📊 实验结果

主要定量结果（探针损失，越低越好）
本文在多个任务上评估了概念质量。下表展示了关键结果的平均排名（来自Table 1）：

| 方法 | 平均排名（越低越好） |
| :--- | :--- |
| LDA (有监督上界) | N/A |
| Deleuzian (本文) | 1.65 ± 0.85 |
| TopKSAE | 2.65 ± 1.01 |
| A-SAE | 3.20 ± 1.72 |
| Mat-SAE | 5.70 ± 1.90 |
| JR-SAE | 5.75 ± 0.94 |
| Van-SAE | 4.65 ± 1.56 |
| Gat-SAE | 6.65 ± 1.42 |
| ICA | 6.85 ± 2.29 |

结论：该方法在全球范围内优于所有无监督基线（SAE变体和ICA），在20个任务中的13个上取得了最低的探针损失。

结论：该方法提取的概念在不同随机种子下具有很高的一致性（MPPC高），显著优于大多数SAE变体（除Van-SAE在部分任务上）。

消融实验
消融研究（Table 3）证实了两个核心设计的关键作用：
- 使用激活差异作为输入（而非原始激活）：显著提升概念质量。
- 使用逆偏度加权：大幅提升概念的多样性（有效秩更高，最大成对余弦更小）。
