### 💡 毒舌点评

**亮点**：在语音合成领域，首次系统性地构建了大规模（99K对）且聚焦于“自然度”的人类偏好数据集，并配套提出了一个经SFT+RL训练的、支持CoT推理和测试时扩展的生成式奖励模型（GRM），填补了该方向从数据到评估工具的关键空白。**短板**：评估基准（SpeechJudge-Eval）与训练数据同源且经过筛选，其挑战性可能被高估；提出的GRM虽然优于BTRM，但在处理“干净但机械”与“略有噪声但生动”这类复杂权衡时仍存在已知失败案例。

### 📌 核心摘要

1.  **问题**：语音合成领域缺乏大规模、聚焦于整体“自然度”的人类偏好反馈数据集，阻碍了与人类感知真正对齐的模型的发展与评估。
2.  **方法核心**：提出SpeechJudge套件，包含三部分：a) **SpeechJudge-Data**：使用多种先进零样本TTS模型生成99K对语音，由人类标注清晰度和自然度偏好。b) **SpeechJudge-Eval**：基于高一致性样本构建的自然度判断基准。c) **SpeechJudge-GRM**：一个基于Qwen2.5-Omni-7B的生成式奖励模型，通过两阶段训练：SFT（使用教师模型Gemini-2.5-Flash生成的CoT数据）和RL（GRPO算法，以人类偏好为可验证奖励）。
3.  **创新点**：1）构建了首个大规模、多语言、多风格的语音自然度人类偏好数据集。2）设计了专门的自然度判断评估基准，揭示了现有方法（包括强AudioLLM）的局限性。3）提出了经SFT+RL训练的GRM，它不仅能输出判断，还能提供CoT推理过程，并支持通过多数投票进行推理时性能扩展。
4.  **主要实验结果**：
    *   **评估基准**：在SpeechJudge-Eval上，最强闭源模型Gemini-2.5-Flash准确率<70%，凸显任务挑战性。
    *   **模型对比**：SpeechJudge-GRM（SFT+RL）达到77.2%准确率，超过经典BTRM（72.7%）；通过多数投票（@10）可进一步提升至79.4%。
    *   **下游应用**：将GRM用于高自然度样本选择和TTS模型后训练的奖励函数，均提升了主观自然度评价（详见图5、图6）。
5.  **实际意义**：提供了可复用的数据、基准和模型，可用于客观评估语音合成系统的自然度，并能直接作为奖励函数指导TTS模型的偏好对齐训练，推动了语音生成领域的RLHF发展。
6.  **主要局限性**：1）数据集和标注者主要反映中英文双语听众偏好，对其他语言覆盖不足。2）自然度标注为句子级，无法捕捉细粒度局部瑕疵。3）GRM的CoT能力部分继承自教师模型（Gemini），可能存在偏见，且未对中间推理过程进行大规模人工验证。

### 🏗️ 模型架构

论文中的核心模型是**SpeechJudge-GRM（生成式奖励模型）**。其整体架构基于一个现有的多模态大语言模型**Qwen2.5-Omni-7B**。

![论文中的模型架构图](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/I9ED9VWZq6-3.png)

**图4说明**：该图展示了SpeechJudge-GRM的训练流程，即其核心构建方法。
1.  **输入**：对于一个语音判断样本 `(t, a1, a2)`，使用一个精心设计的**Chain-of-Thought (CoT) 提示**（包含任务描述、目标文本t和两个语音a1, a2）作为输入。
2.  **SFT阶段（冷启动）**：使用一个强大的教师模型（Gemini-2.5-Flash）在CoT提示下生成带有推理过程的输出。只将教师模型判断与人类标注一致的样本（图中“正确”部分）用于监督微调（SFT），以提升基础模型的指令遵循和推理能力。
3.  **RL阶段（强化学习）**：使用SFT阶段处理后剩余的、教师模型判断错误的“挑战性”样本（图中“错误”部分）。此时，策略模型就是SFT后的模型。模型在CoT提示下生成多个输出（rollouts），每个输出会被解析出最终的自然度偏好判断（y_M）。将人类标注（y_H）作为**可验证的奖励信号**：如果判断一致（y_M = y_H），奖励为+1，否则为-1。使用**GRPO（Group Relative Policy Optimization）** 算法进行强化学习，目的是在只约束最终判断结果对齐人类偏好的前提下，让模型自主优化其推理和生成CoT的能力。
4.  **推理时**：最终训练好的GRM可以接收新的 `(t, a1, a2)` 对和CoT提示，输出一个包含详细推理过程的自然度判断。此外，它还支持**推理时扩展**：对于同一个输入，生成多个输出（如10个），然后通过**多数投票**决定最终结果，以提高准确率。

该模型本质上是一个**判别模型被建模为生成任务**：它不是直接输出一个分数，而是通过生成文本来表达其判断和推理过程，这使得CoT和投票机制成为可能。

### 💡 核心创新点

1.  **构建大规模语音自然度偏好数据集（SpeechJudge-Data）**：之前工作多为MOS点评分或小规模偏好数据，本文构建了包含99K对、多语言（中英混合）、多风格（常规/表现力）、由多种先进TTS模型生成的语音对，并进行了清晰度和自然度的双重人类标注，为该领域的研究提供了稀缺的基础资源。
2.  **设立专门的自然度判断基准（SpeechJudge-Eval）**：创建了一个包含1000个高一致性（全标注员一致）样本的评估集，标准化了评估任务（给定文本和两个语音，判断哪个更自然）。系统性地评估了现有指标、MOS预测器、深度伪造检测器和多种AudioLLM，揭示了当前技术的局限性（最强模型准确率<70%），定义了一个有价值的挑战性问题。
3.  **开发两阶段训练的生成式奖励模型（SpeechJudge-GRM）**：针对开源AudioLLM（Qwen2.5-Omni）在复杂指令和推理上的不足，提出了“SFT（基于教师CoT数据）+ RL（基于人类偏好可验证奖励）”的训练范式。GRM不仅能输出判断，还提供可解释的CoT推理，并支持推理时通过多数投票进一步提升性能，超越了传统的Bradley-Terry奖励模型（BTRM）。

### 🔬 细节详述

- **训练数据**：
    - **SpeechJudge-Data (train)**：42K对语音。从99K原始数据中过滤掉全标注员不一致的样本，通过多数投票确定标签，并去除平局样本。进一步筛选WER差距<12%的样本（SpeechJudge-Data (hq)），以专注于自然度差异。
    - **SFT数据**：在42K训练集中，使用Gemini-2.5-Flash生成CoT输出，选取其判断与人类一致的**25K**个样本。
    - **RL数据**：选取Gemini-2.5-Flash判断与人类不一致的**17K**个样本，仅使用其CoT提示（Prompt），由策略模型生成输出并计算奖励。
- **损失函数**：
    - **SFT阶段**：标准的自回归语言建模损失（负对数似然），但**仅在模型生成的输出部分（O_teacher）** 进行计算。
    - **RL阶段**：使用GRPO算法。奖励函数是**基于准确率的规则奖励**：对于每个rollout，如果模型解析出的自然偏好（y_M）与人类标注（y_H）一致，奖励为1，否则为-1。优化目标是最大化期望奖励。
- **训练策略**：
    - **优化器**：AdamW（带解耦权重衰减）。
    - **学习率**：SFT为5e-5；RL为5e-6。
    - **批量大小**：SFT最大token数为4000/批；RL的batch size为32，每个prompt的rollout数为8。
    - **参数高效微调**：两阶段均使用**LoRA**。SFT时秩（rank）为128；RL时秩为64。
    - **训练时长**：未明确说明。
- **关键超参数**：模型基座为**Qwen2.5-Omni-7B**。推理时扩展的投票数为10（Voting@10）。
- **训练硬件**：未说明。
- **推理细节**：对于判断任务，解析模型输出中“Output A: X, Output B: X”部分，选择得分更高的作为判断结果。投票模式下，对10个输出结果进行多数表决。
- **正则化**：未特别提及，但使用了LoRA本身具有正则化效果。

### 📊 实验结果

**1. SpeechJudge-Eval基准测试结果（与各基线模型对比）**

| 模型类别 | 模型名称 | 常规(Regular) | 表现力(Expressive) | 总计(Total) |
| :--- | :--- | :--- | :--- | :--- |
| **客观指标** | WER | 59.3 | 57.0 | 57.9 |
| | SIM | 47.5 | 42.5 | 44.5 |
| | FAD | 50.3 | 47.5 | 48.6 |
| **MOS预测器** | DNSMOS | 61.0 | 55.8 | 57.9 |
| | UTMOS | 54.0 | 53.5 | 53.7 |
| **AudioLLM (开源)** | Qwen2.5-Omni-7B | 62.0 | 59.7 | 60.6 |
| | Kimi-Audio-7B-Instruct | 65.5 | 68.0 | 67.0 |
| **AudioLLM (闭源)** | Gemini-2.5-Flash | 73.5 | 66.2 | **69.1** |
| | GPT-4o Audio | 71.5 | 64.7 | 67.4 |

**结论**：传统指标和MOS预测器表现较弱，多数低于60%。AudioLLM表现出较大潜力，但最强模型（Gemini-2.5-Flash）与人类判断的一致性仍低于70%，说明任务具有挑战性。

**2. SpeechJudge-GRM及其变体在SpeechJudge-Eval上的结果**

| 模型 | 常规(Regular) | 表现力(Expressive) | 总计(Total) |
| :--- | :--- | :--- | :--- |
| SpeechJudge-BTRM | 77.5 | 69.5 | 72.7 |
| SpeechJudge-GRM (SFT) | 77.8 | 73.7 | 75.3 |
| SpeechJudge-GRM (SFT) w/ Voting@10 | 77.4 | 77.6 | 77.6 |
| **SpeechJudge-GRM (SFT+RL)** | **79.0** | **76.0** | **77.2** |
| **SpeechJudge-GRM (SFT+RL) w/ Voting@10** | **80.5** | **78.7** | **79.4** |

**结论**：经过SFT+RL训练的GRM在准确率上显著优于BTRM（77.2% vs 72.7%）。引入推理时多数投票（@10）能进一步提升约2个百分点，达到79.4%。

### ⚖️ 评分理由

- **学术质量：6.5/7**：工作系统完整，从数据、基准到模型均有贡献。方法上将RLHF范式成功引入语音自然度评估，并设计了SFT+RL的训练策略以克服现有AudioLLM的短板。实验设计合理，与多��基线对比，并验证了模型在下游任务中的应用价值。主要扣分在于评估基准可能因与训练数据同源而缺乏绝对的挑战性。
- **选题价值：1.5/2**：语音自然度是合成语音的终极追求之一，构建自动化、人类对齐的评估工具是领域核心需求，具有明确的应用前景（用于模型迭代和评估）。该问题虽然重要，但相对垂直，因此未给满分。
- **开源与复现加成：0.5/1**：论文明确承诺开源全部资源（数据、基准、模型、代码），并提供了访问链接。附录中详细描述了数据构建、标注指南、训练超参数等关键复现信息，透明度很高。加成较高。
