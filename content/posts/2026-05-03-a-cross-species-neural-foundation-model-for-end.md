### 📌 核心摘要

1. 要解决的问题：现有言语脑机接口多采用“神经活动->音素->句子”的级联框架，各阶段独立优化，难以达到整体最优。端到端方法虽然被提出，但受限于模型架构（如RNN）和缺乏大规模预训练，性能仍落后于级联方法。
2. 方法核心：提出了端到端BraIn-to-Text框架。其核心是一个使用大规模人类（~98小时）和猴子（~269小时）Utah阵列记录数据，通过掩码建模进行自监督预训练的Transformer神经编码器。微调后，该编码器与一个小型音频大语言模型连接，并通过对比学习进行跨模态对齐，实现从神经活动到句子的直接生成。
3. 与已有方法相比新在哪里：首次在神经解码中引入了跨物种、跨任务（运动与言语）的大规模Transformer预训练；首次将神经编码器与音频大语言模型进行端到端联合优化，而非传统的RNN+文本大模型或音素级级联；证明了该框架能实现尝试性言语与想象性言语表征空间的对齐，支持跨任务泛化。
4. 主要实验结果：在Brain-to-Text '24竞赛中，级联模式下WER降至6.35%，端到端模式下WER从先前的24.69%降至10.22%（集成后）。在低资源想象言语解码任务上，预训练带来的性能提升（WER降低39%-45%）远超尝试性言语任务。

| :--- | :--- | :--- | :--- |
| RNN (基线) | 级联 | 9.76% | 6.67% |
| BIT Cascaded | 级联 | 6.35% | 4.06% |
| BIT Cascaded + Ensemble | 级联 | 5.10% | 1.76% |
| Feng et al. (2024) | 端到端 | 24.69% | - |
| BIT End-to-End | 端到端 | 15.67% | 11.06% |
| BIT End-to-End + Ensemble | 端到端 | 10.22% | 7.76% |

5. 实际意义：为瘫痪患者提供了一种性能更优、优化更灵活的端到端言语通信方案，推动了神经基础模型在生物医学工程中的应用。
6. 主要局限性：端到端推理速度慢（约0.95秒/句），无法满足实时应用需求；依赖双向注意力的编码器不适合在线流式解码；跨物种预训练的收益部分源于更相关的人类数据，猴子数据贡献不明确；仍需解决神经信号非平稳性和长期使用中的共适应问题。

### 🏗️ 模型架构

BIT框架（如图1所示）是一个端到端的神经-文本翻译系统，主要包含四个组件：
1.  Transformer神经编码器：接收20ms时间窗的阈值脉冲数和尖峰波段功率特征。采用时间分块（Patch）策略，将连续多个时间步合并为一个token，以匹配语音产生的慢时间尺度并缩短序列长度。编码器使用相对位置编码和双向注意力，旨在学习富含上下文信息的神经活动表征。
2.  浅层MLP投影器：一个两层的多层感知机，用于将神经编码器输出的高维表征映射到大语言模型（LLM）的嵌入空间。
3.  模态对齐器：在训练阶段用于对比学习。它将池化后的神经和文本嵌入分别投影到一个共享的潜在空间，通过对比损失拉近配对样本的表征，推远不匹配样本的表征。
4.  音频大语言模型解码器：使用经低秩适配微调的小型音频LLM（如Aero1-Audio 1.5B）。神经嵌入可以被视为“神经模态”直接投影到文本空间，也可以被视为“音频模态”通过音频LLM原有的多模态投影器映射。解码器通过自回归方式生成句子。

上图清晰展示了BIT的整体流程：(A)端到端框架概览；(B)神经编码器的预训练（掩码重建）与微调（CTC损失预测音素）过程；(C)最终端到端模型的训练，包括投影器、模态对齐器和音频LLM解码器，使用交叉熵损失和对比损失。

### 💡 核心创新点

1.  跨物种、跨任务的大规模神经信号预训练：利用约367小时的、来自人类（言语、手写）和猴子（上肢运动）的Utah阵列数据，通过掩码建模进行自监督预训练。这是首次在神经解码领域系统性地验证了这种跨物种预训练能带来显著的性能增益，尤其在低数据量的想象语音任务上。
2.  端到端神经-文本生成框架：摒弃了传统的级联框架（先解码音素），直接建立从神经活动到句子的端到端映射。该框架将神经编码器与预训练的音频大语言模型通过简单的投影器连接，并进行联合微调。
3.  神经-文本模态对齐与跨任务泛化：通过对比学习将神经活动嵌入与LLM的文本嵌入对齐到一个共享空间。分析表明，该方法能有效减小尝试性言语与想象性言语在表征空间中的分离，从而实现跨任务迁移。

### 🔬 细节详述

- 训练数据：预训练使用98小时人类Utah阵列数据和269小时猴子运动任务数据。微调使用Brain-to-Text Benchmark '24/25数据集（尝试性言语）及Kunz et al. (2025)的想象言语数据集。
- 损失函数：总损失为交叉熵损失（用于句子生成）与对比损失（用于模态对齐）之和（见附录J）。对比损失采用对称的InfoNCE形式。
- 训练策略：预训练和微调均使用AdamW优化器，采用bfloat16混合精度训练。学习率、批大小等超参数根据任务调整（详见附录R）。微调阶段对LLM应用LoRA（秩8，缩放因子32）。
- 关键超参数：Transformer编码器约700万参数，微调后总模型约1300万参数（编码器+投影器）。音频LLM解码器选用1.5B参数规模。
- 训练硬件：预训练在单卡NVIDIA A100 (80GB)上耗时不到2天。音素解码微调在A40或A100上耗时不到1天。LLM微调在单卡或两卡（针对7B模型）上进行。
- 推理细节：解码使用核采样（p=0.9，温度=0.7）。级联方法使用5-gram LM进行波束搜索，并用OPT-6.7B重新评分。

| 竞赛条目 | WER |
| :--- | :--- |
| BIT End-to-End | 11.06% |
| BIT End-to-End + Ensemble | 7.76% |

| BIT Cascaded | 4.06% |
| BIT Cascaded + Ensemble (竞赛第一) | 1.76% |

关键消融实验：
- LLM解码器类型：音频LLM（如Aero1-Audio 1.5B）显著优于同尺寸的纯文本LLM。
- 编码器预训练：跨物种预训练（BIT-All）> 仅人类预训练（BIT-Human）> 从头训练（BIT-TFS）> RNN。预训练对想象言语任务提升更大。
- 模态对齐：使用对比学习能进一步提升端到端性能。
