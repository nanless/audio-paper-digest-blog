### 📌 核心摘要

这篇论文旨在解决现有脑机接口（BCI）语音解码系统依赖级联框架（先解码音素，再用语言模型组装句子）导致无法全局优化的问题。核心方法是提出一个名为BIT（BraIn-to-Text） 的端到端解码框架，该框架包含一个跨物种、跨任务预训练的Transformer神经编码器和一个音频大语言模型（Audio-LLM）解码器。编码器使用自监督掩码建模在来自人类和猴子的约367小时神经记录数据上进行预训练，以学习通用神经表示；解码器则通过对比学习与编码器输出进行跨模态对齐，直接从神经活动生成句子。与已有方法相比，BIT的新颖之处在于：1）实现了完全可微的端到端训练；2）利用大规模跨物种数据进行预训练，提升了模型的泛化能力，尤其在低数据量的想象语音任务上效果显著；3）证明了小型音频大语言模型在神经解码任务上优于纯文本大模型。

主要实验结果如下：在Brain-to-Text基准测试中，BIT的级联框架在两个榜单上均取得第一（WER 5.10%和1.76%，含模型集成）；其端到端框架相较于之前最佳方法（Feng et al. 2024）将词错误率（WER）从24.69%大幅降低至10.22%（含集成），性能提升超过50%。该工作的实际意义在于推动了更易优化和部署的端到端神经语音接口的发展，为瘫痪患者恢复交流能力提供了新范式。主要局限性包括：1）端到端推理速度较慢，难以满足实时应用需求；2）模型仍需大量未标注神经数据进行预训练，且对标注数据需求量大；3）跨物种迁移中，人类数据的贡献远大于猴子数据，表明神经任务相关性至关重要。

### 🏗️ 模型架构

BIT框架整体分为预训练、音素微调和句子级微调三个阶段。其整体架构流程见图1。

![图1：BIT框架示意图](/audio-paper-digest-blog/images/iclr-2026/2026-05-04/Lp1noMpMUG-0.png)

1. Transformer神经编码器：
- 输入：来自Utah阵列的原始神经活动，包含阈值脉冲计数和脉冲带功率（SBP），以20毫秒为间隔分箱，并跨天进行z分数标准化。
- 核心操作：采用Transformer架构。首先，将时间维度上连续的若干个时间步（Tpatch）合并为一个“时间块”（Patch），以匹配语音产生的慢时间尺度。然后通过一个“块嵌入模块”（LayerNorm -> Linear -> LayerNorm）将数据块映射为Transformer的输入tokens。
- 内部结构：Transformer块包含多头自注意力层（使用RoPE位置编码，双向注意力掩码）和前馈网络。在预训练阶段，采用时间掩码策略：随机遮盖部分神经活动块，并通过“反向块嵌入模块”将Transformer输出投影回原始神经数据维度，使用MSE损失进行重建。在微调阶段，移除掩码模块，Transformer输出连接到一个线性层，预测音素 logits（用于CTC损失）或作为下游解码器的输入。

2. 音频大语言模型解码器：
- 输入：经过微调的神经编码器输出的神经表示。
- 模态投影：神经表示首先通过一个浅层MLP投影器（Linear -> ReLU -> Linear）映射到文本嵌入空间。对于音频LLM，有两种处理方式：
    - 神经模态：将投影后的神经表示视为与文本不同的模态，直接输入LLM。
    - 音频模态：将投影后的神经表示视为一种“音频”，进一步通过音频LLM原有的多模态投影器，映射到音频嵌入空间。
- LLM解码：在LLM输入中，在神经嵌入和目标文本嵌入之间插入一个提示（例如：“将上述神经活动解码为一句英文：”）。模型通过自回归方式，根据神经嵌入和提示生成文本。训练时使用交叉熵损失。
- 微调策略：仅对LLM的部分参数（如注意力和前馈层的线性层）使用LoRA进行微调，以冻结大部分预训练参数。

3. 跨模态对齐模块：
- 功能：增强神经表示与文本表示之间的语义对齐。
- 方法：在投影器之后，神经嵌入和文本嵌入分别通过各自独立的线性层投影到一个共享的潜在空间，并进行L2归一化。然后使用对比损失（对称InfoNCE损失）拉近同一样本的神经与文本“模态token”，推远不同样本的token。

#

### 💡 核心创新点

1.  端到端可微解码框架：将神经编码器与大语言模型解码器整合为一个可微管道，允许端到端优化，克服了传统级联框架（神经网络+ n-gram语言模型）各阶段独立优化导致的性能割裂问题。
2.  跨物种、跨任务大规模自监督预训练：在包含人类和猴子、涉及语音及运动任务的约367小时神经数据上，使用掩码自编码器目标进行预训练。这使得模型能够学习对电极漂移、受试者差异和任务变异鲁棒的通用神经表征，尤其显著提升了在低数据量“想象语音”任务上的性能。
3.  音频大语言模型（Audio-LLM）的有效应用：通过实验证明，将神经活动视为一种类音频模态，并利用在音频任务上预训练的小型大语言模型（如Aero1-Audio 1.5B）进行解码，比使用纯文本大语言模型更有效。这为神经信号的跨模态理解提供了新思路。
4.  跨任务泛化能力：通过表征相似性分析（RSA）和线性判别分析（LDA），证明了BIT学习到的神经嵌入在“尝试语音”和“想象语音”两个任务间实现了语义对齐，减少了任务相关的分离，为跨任务迁移奠定了基础。

### 🔬 细节详述

- 训练数据：
    - 预训练：~98小时人类Utah阵列记录（包含后续解码任务数据）和~269小时猴子运动任务记录。人类数据来源于多项公开研究（见附录A）。
    - 尝试语音解码：Brain-to-Text '24（参与者T12， 12,100句）和'25（参与者T15， 10,948句）基准数据集。
    - 想象语音解码：Kunz et al. (2025) 内部语音数据集（T12: 500句， T15: 712句）。
    - 预处理：所有数据重采样至20ms分箱，跨天z分数标准化。当SBP可用时，将其与阈值脉冲计数共同使用（实验证明此组合WER最低，见表3）。
- 损失函数：
    - 预训练：MSE损失（重建被掩码的神经活动块）。
    - 音素微调：CTC损失（预测音素序列）。
    - 句子微调：总损失 = 交叉熵损失（自回归预测下一个词） + 对比损失（对齐神经与文本模态token）。
- 训练策略：
    - 优化器：AdamW。
    - 超参数搜索：使用Ray Tune随机采样30组超参数（batch size, weight decay, learning rate），基于验证集指标（R²或PER/WER）选择最佳模型。
    - 关键超参数：Transformer编码器约700万参数；MLP投影器隐藏层维度匹配LLM；LoRA秩为8，缩放因子为32。对比损失中的可学习温度τ初始化为0.1。
    - 训练时长：预训练在单卡A100上不到2天完成400 epochs；音素微调在A40/A100上不到1天完成800 epochs。
- 推理细节：使用核采样（nucleus sampling），p=0.9，温度=0.7，最多生成25个新token。
- 模型集成：为达到最佳竞赛性能，采用了模型集成策略。初始化多个不同随机种子的预训练编码器，微调后产生多个候选解码结果，最后由一个微调的LLM（如GPT-3.5/4）从候选中选择最佳句子。

### 📊 实验结果

主要结果（尝试语音解码）

| 竞赛条目 | WER (Brain-to-Text '24 holdout) | WER (Brain-to-Text '25 holdout) |
| :--- | :--- | :--- |
| 先前最佳端到端方法 (Feng et al. 2024) | 24.69% | - |
| BIT End-to-End | 15.67% | 11.06% |
| BIT End-to-End + Ensemble | 10.22% | 7.76% |
| RNN基线 (级联) | 9.76% | 6.67% |
| 先前最佳级联方法 (Feghhi et al. 2025) | 7.98% | - |
| BIT Cascaded | 6.35% | 4.06% |
| BIT Cascaded + Ensemble | 5.10% | 1.76% |

关键结论：BIT的级联框架在两个榜单上均取得单模型和集成模型的SOTA。端到端框架的WER相比之前最佳方法降低了超过50%。
