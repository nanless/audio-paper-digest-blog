### 💡 毒舌点评

亮点：论文实验设计扎实，通过在两个独立的音频视觉深度伪造数据集上运行完全匹配的众包任务，为“人类判断的可靠性”这一基础问题提供了极其清晰、量化的实证数据，尤其是揭示了模态归因（判断是音频假、视频假还是两者皆假）的普遍困难。短板：研究止步于描述人类（众包工人）的表现，没有与当前先进的自动化深度伪造检测器在同一批样本上进行直接对比，这大大削弱了其结论的说服力——我们无法知道这些“难以被人类发现”的伪造，对于机器来说是否也同样困难。

### 📌 核心摘要

1. 本文研究了众包工人在检测音视频深度伪造时，区分真实与伪造视频的一致性，以及在标记伪造时，识别操纵类型（纯音频、纯视频、音视频）和报告时间戳的一致性。
2. 方法核心是在Prolific平台上，针对AV-Deepfake1M和TMC两个数据集，使用完全相同的实验协议，收集了960个视频级别的判断。
3. 相比已有的人类或自动化检测研究，本文的新意在于：在受控的匹配实验设计下，同时对比了两个主流音视频伪造数据集，并系统分析了不同聚合策略（多数投票、Dempster-Shafer）的效果。
4. 主要实验结果显示，众包工人很少将真实视频误判为伪造，但遗漏了大量的伪造视频，尤其是在AV-Deepfake1M数据集上（假阴性率高达72.2%）。聚合判断可以稳定真实性信号，但无法挽回被大多数工人一致漏掉的伪造。识别操纵类型的准确性远低于识别真实性，音视频联合操纵最难识别。关键数据见下表：

| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| AV-Deepfake1M | 多数投票 | 0.297, 0.917, 0.449 | 0.909, 0.278, 0.426 | 0.438 | 0.083 | 0.722 |

5. 实际意义在于，众包可以作为音频视觉真实性评估的一个可扩展的“筛选”环节，但其错误主要表现为漏报而非误报。模态归因（判断是哪种类型的操纵）目前尚不可靠，需要专门的支持界面或交给下游专家/模型处理。
6. 主要局限性包括：样本规模有限（每数据集48个视频），可能无法覆盖实践中的全部多样性；参与者池（主要为美国Prolific用户）的普适性未知；任务引导可能影响了对音频通道的关注；未与自动化检测器进行直接对比。

#

### 🏗️ 模型架构

本文不涉及提出新的机器学习模型。其核心是一个用于收集和评估众包判断的实验框架。该框架的流程如下：
1.  输入：来自AV-Deepfake1M和TMC数据集的、预先划分好类别（真实、纯音频操纵、纯视频操纵、音视频联合操纵）的音视频剪辑。
2.  任务流程：
    *   工人（Prolific平台招募）首先完成人口统计问卷。
    *   然后，工人按随机顺序观看分配到的4个视频（每个工作单元）。
    *   对于每个视频，工人做出第一步判断：标记为“真实”或“伪造”。
    *   如果标记为“伪造”，则进入第二步：选择操纵类型（纯音频、纯视频、音视频），并给出一个近似的操纵开始时间戳（格式：mm:ss.cc）。
3.  输出：每个视频获得10个独立的众包判断，形成包含真实性标签、操纵类型（如适用）和时间戳的数据集。
4.  评估组件：框架包含多种聚合和评估策略：
    *   聚合策略：多数投票（以“真实”打破平局）和Dempster-Shafer理论（结合工人可靠性权重）。
    *   评估指标：用于真实性检测的精确率、召回率、F1、FPR、FNR；用于衡量工人一致性的Krippendorff‘s α、多数一致率、成对一致率；用于分析时间戳报告的IQR和一致性分数。

#

### 💡 核心创新点

1.  跨数据集的匹配实验设计：在完全相同的实验协议、任务界面和聚合方法下，对比了AV-Deepfake1M和TMC两个主流音视频深度伪造数据集，直接揭示了数据集特性（如视频长度、操纵类型分布、现实程度）对人类判断准确性和一致性的巨大影响。这比在单一数据集上研究更稳健。
2.  对聚合策略的实操权衡分析：不仅比较了简单的多数投票和更复杂的Dempster-Shafer聚合，还明确指出了两者在实践中的权衡：Dempster-Shafer提高了对伪造视频的召回率（减少漏报），但同时增加了误报率。这为实际部署提供了清晰的决策依据。
3.  聚焦于模态归因的困难性：系统研究了当工人能识别出视频是伪造的之后，能否准确指出操纵发生在哪个模态（音频、视频或两者）。研究发现这一环节的噪声远大于最初的真实性判断，尤其是音视频联合操纵常被错误地归因为单一模态。这指出了当前界面和人类感知的关键瓶颈。

### 🔬 细节详述

*   训练数据：本文是评估研究，不涉及模型训练。数据使用了两个公开数据集：AV-Deepfake1M [8] 和 TMC [13]。每个数据集采样48个视频，平衡4种条件（真实、纯音频、纯视频、音视频），共96个视频。
*   损失函数：不适用。
*   训练策略：不适用。
*   关键超参数：每个视频收集10个独立判断；每个工作单元包含4个视频；任务目标完成时间10分钟，支付1.50英镑。
*   训练硬件：不适用。
*   推理细节：不适用。
*   正则化或稳定训练技巧：不适用。
*   评估设置细节：
    *   操纵类型识别评估设置：提出了三种评估标准：(1) `Authenticity + Type`：最严格，将漏报的伪造直接算作类型错误；(2) `Any Fake Vote`：只要有一个工人标记为伪造，就考虑其类型投票；(3) `Majority Fake`：仅在多数投票判定为伪造的视频上评估类型准确率。
    *   统计分析：使用非参数检验（Mann-Whitney U, Kruskal-Wallis, McNemar），并进行多重比较校正（Bonferroni, Holm-Bonferroni）。
    *   时间戳一致性：通过将时间戳归一化到视频时长，并计算中位数和IQR，以及定义“±5%窗口”内的一致性分数来量化。

### 📊 实验结果

主要实验结果表格（源自论文表3和正文）：

| 研究问题 | 比较维度 | AV-Deepfake1M 结果 | TMC 结果 | 关键结论 |
| :--- | :--- | :--- | :--- | :--- |
| RQ1: 真实性检测准确率 | 多数投票准确率 | 0.438 | 0.646 | TMC上表现显著更好 |
| | 多数投票 FPR | 0.083 | 0.083 | 误报率低且一致 |
| | 多数投票 FNR | 0.722 | 0.444 | 漏报是主要错误，且数据集间差异大 |
| | DS vs 多数投票 准确率提升 | +0.020 (0.438->0.458) | +0.062 (0.646->0.708) | DS能提升准确率，但程度不显著(p≥0.05) |
| RQ2: 工人一致性 | Krippendorff‘s α | 0.113 | 0.353 | 整体一致性有限，TMC更高 |
| | 平均多数一致率 | 0.696 | 0.777 | TMC上每视频约8/10票一致 |
| RQ3: 操纵类型识别 | (Any Fake Vote) 总体类型准确率 | 0.343 | 0.139 | 识别类型非常困难 |
| | (Any Fake Vote) 音频视频联合类型准确率 | 0.000 | 0.167 | 音视频联合操纵最难归因 |
| | (Any Fake Vote) 音视频联合判断被归为“真实”比例 | 60.8% | 58.3% | 超过半数被漏判 |
| | 时间戳一致性中位IQR | 0.193 | 0.063 | TMC上时间戳更集中 |
| | 时间戳一致性中位分数 | 0.333 | 0.750 | TMC上时间戳报告更可靠 |

消融与细分结果：
*   数据集影响：TMC在准确率、一致性和时间戳可靠性上均显著优于AV-Deepfake1M（Mann-Whitney U, p<0.05）。
*   操纵类型影响：在AV-Deepfake1M上，音视频联合操纵比纯音频操纵更难准确归因（中位准确率0.225 vs 0.450, p<0.05）。在TMC上，纯音频操纵最难归因（中位准确率0.000），显著低于纯视频和音视频联合（p<0.01）。
*   聚合策略影响：Dempster-Shafer聚合在两个数据集上都提高了伪造视频的召回率（减少漏报），但也降低了真实视频的召回率（增加误报）。与多数投票的差异在统计上不显著。

重要对比声明：论文没有与任何自动化深度伪造检测器的性能进行直接对比，因此无法将人类表现置于当前技术发展的具体上下文中评估。
