### 📌 核心摘要

1. **问题**：在微控制器（MCU）上部署的TinyML模型需要可靠且低开销的不确定性估计，以检测数据分布漂移或模型错误。然而，传统方法（如深度集成、MC Dropout）因需要多次前传、额外分支或状态存储，在毫瓦级硬件上难以实现。
2. **方法核心**：本文提出SNAP-UQ，一种基于自监督的逐层激活预测的单次前传不确定性估计方法。其核心是在网络骨干的少数层（如中间层、倒数第二层）附加轻量级头（int8量化），利用低秩投影从当前层激活预测下一层激活的统计量（均值和方差）。预测误差（标准化残差）形成“逐层惊讶度”信号，经聚合和单调映射后得到最终的不确定性分数。
3. **创新点**：
    - **思路创新**：将不确定性信号源从模型输出层或多次采样，转移到网络内部的**层间动态转换**上，认为分布偏移会先破坏层间特征流的平稳性。
    - **实现创新**：设计完全适配MCU约束，所有计算在一次前传中完成，无需状态缓冲；使用1x1卷积+全局平均池化的投影器、int8量化头、查找表（LUT）替代指数运算。
    - **理论联系**：证明了在特定假设下，其惊讶度分数等价于条件负对数似然和条件马氏距离，并具有对通道缩放的不变性。
4. **主要实验结果**：
    - **部署效率**：在Big-MCU上，SNAP-UQ相比早退集成和深度集成方法，Flash占用减少37-57%，延迟降低24-35%。在Small-MCU上，深度集成方法因内存溢出（OOM）无法运行，而SNAP-UQ仍能高效部署（如SpeechCommands上Flash 118KB，延迟113ms）。
    - **监控性能**：在损坏数据流监控任务中（如MNIST-C），SNAP-UQ的AUPRC达到0.66，优于基线（BASE: 0.54， 深度集成: 0.56），且检测延迟最短（24帧）。其AUPRC随损坏严重度增加而增长最快（见图2）。
    - **故障检测**：在ID正确与否检测（ID✓— ID×）上，SNAP-UQ在MNIST（AUROC 0.90）和SpeechCommands（0.94）上达到最优；在OOD检测（ID✓— OOD）上，在SpeechCommands（0.92）上与最佳基线持平，在CIFAR-10（0.94）上接近最佳（表3）。
    - **校准**：在ID校准上，SNAP-UQ降低了MNIST和SpeechCommands上的NLL和ECE（表4）。
5. **实际意义**：为TinyML设备提供了一种实用、轻量、单次前传的不确定性监控方案，使其能在资源严苛的条件下，实时感知自身预测的可信度，对安全可靠的边缘AI部署具有重要价值。
6. **主要局限性**：依赖对网络中间层激活的访问，可能不适用于完全黑盒模型；对层投影器的秩（rank）和层选择（tap placement）敏感；协方差建模简单（对角/低秩），可能无法捕捉复杂的跨通道依赖。

### 🏗️ 模型架构

SNAP-UQ不是一个独立的模型，而是**附加到现有固定骨干网络（如DSCNN, ResNet-8, MobileNetV2）上的轻量级不确定性估计模块**。其整体数据流与架构如下：

![SNAP-UQ pipeline.](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/YdK1ZRhrKi-0.png)

**图1：SNAP-UQ 流水线示意图。** 展示了其如何集成到一个标准骨干网络中。骨干网络（f1, ..., fD）在选定层（ℓ）被“截取”以暴露激活值（aℓ）。每个截取点包含：1）低秩投影器（Pℓ）：将前一层激活aℓ-1压缩为低维表示zℓ，对卷积网络使用1×1卷积+全局平均池化实现。2）轻量级预测头（gℓ）：一个微型线性层，输入zℓ，输出对当前层激活aℓ的预测均值（μℓ）和对数方差（log σ²ℓ），从而定义一个条件高斯分布p(aℓ|aℓ-1)。3）惊讶度计算：计算实现激活aℓ与预测分布之间的标准化残差，形成逐层惊讶度分数eℓ。所有eℓ被加权聚合为总惊讶度S(x)。最后，一个离线训练的单调逻辑映射（Logistic w）将S(x)（以及可选的分类器置信度信号m(x)）转换为最终的不确定性分数U(x)∈[0,1]。虚线框表示离线训练步骤（训练预测头{gℓ}和映射参数）；推理阶段只需一次前向传播，无状态、无额外缓冲区，完全兼容MCU。

**完整输入输出流程**：
1. **输入**：单个数据样本（如图像、音频特征）。
2. **骨干网络前传**：数据通过固定的骨干网络，依次产生各层激活a1, ..., aD。
3. **逐层惊讶度计算**：
    - 在预设的层索引集合S（通常为2-3个，如中间层和倒数第二层），对每个ℓ∈S：
        - **投影**：对前一层激活aℓ-1应用投影器Pℓ，得到低维特征zℓ = Pℓ(aℓ-1)。
        - **预测**：将zℓ输入微型预测头gℓ，得到预测的激活统计量(μℓ, log σ²ℓ)。
        - **惊讶度计算**：计算标准化残差uℓ = (aℓ - μℓ) ⊙ (σℓ)⁻¹，其中⊙为逐元素乘法，σℓ = exp(0.5 * log σ²ℓ)。然后计算宽度归一化的惊讶度：e̅ℓ = (1/dℓ) * ||uℓ||²₂，dℓ为激活维度。
4. **聚合**：将各层的惊讶度加权求和，得到标量总惊讶度S(x) = Σ_{ℓ∈S} wℓ * e̅ℓ(x)。权重wℓ可均匀设置或按方差倒数分配。
5. **映射**：将S(x)与可选的分类器即时置信度代理m(x)（如最大概率、概率间隔的函数）一起，输入一个轻量级单调逻辑映射：U(x) = sigmoid(β₀ + β₁S(x) + β₂m(x))，输出最终不确定性分数。
6. **输出**：U(x) ∈ [0,1]，值越高表示不确定性越大。

**关键设计选择及动机**：
- **逐层预测而非重建**：目标不是重建aℓ-1，而是预测aℓ的统计量。这使得模型更关注特征转换的“可预测性”，而非精确重构，对噪声和扰动更鲁棒。
- **对角高斯假设**：预测协方差为对角矩阵，以封闭形式简化评分，避免昂贵的矩阵运算，并天然支持int8量化和每通道尺度。
- **标准化**：通过除以预测的标准差σℓ，使惊讶度分数对通道缩放（如BN层、量化）具有不变性（命题2.3），提高了跨架构和部署场景的泛化性。
- **轻量级实现**：投影器Pℓ使用全局平均池化（GAP）将空间维度压缩为1，大幅减少计算和内存；预测头gℓ为线性层，参数极少；所有算术在int8/int32下完成，指数运算用LUT替代。

### 💡 核心创新点

1. **基于内部层间动态的不确定性信号源**：与传统依赖输出层置信度或多次前传的方法不同，SNAP-UQ从网络内部的**特征转换过程**中提取不确定性。其核心洞察是，分布偏移往往先破坏层间特征流的平稳性，导致中间激活变得“出乎意料”（高惊讶度），即使最终输出层仍可能过于自信。这提供了一种更早、更根本的故障指示器。
2. **专为TinyML约束设计的单次前传、无状态实现**：所有不确定性计算都嵌入到一次标准前向传播中完成，无需额外前传、内存缓冲区（如MC Dropout的多次采样存储）或辅助退出分支。投影器和预测头设计极致轻量（int8权重、GAP、LUT），额外Flash开销仅为几十KB，MAC增加<2%，完全符合MCU的功耗和内存预算。
3. **与理论度量（NLL， 马氏距离）的清晰联系**：论文提供了严格的理论推导（命题2.1, 2.2），证明了在对角高斯假设下，聚合的惊讶度S(x)等价于条件负对数似然（NLL）和条件马氏距离的仿射变换。这为该启发式信号提供了坚实的理论基础，并揭示了其与现有不确定性方法的联系与区别（条件性 vs. 无条件性）。
4. **全面的MCU级评估与对比**：论文不仅在标准数据集上报告指标，还严格在**真实MCU硬件（Big-MCU和Small-MCU）** 上测量Flash、RAM、延迟和能量，并模拟流式监控场景。评估了SNAP-UQ在多种任务（视觉/音频、分类/监控、ID/CID/OOD）上的表现，并与一系列基线进行了公平对比，其中许多基线因内存限制在小MCU上无法运行，凸显了SNAP-UQ的部署优势。

### 🔬 细节详述

- **训练数据**：
    - **数据集**：MNIST, CIFAR-10, TinyImageNet (视觉); SpeechCommands v2 (音频)。
    - **来源**：标准公开数据集。
    - **规模**：各数据集标准训练/测试划分，并额外划分10%训练集作为开发集（dev）用于校准和阈值选择。
    - **预处理**：使用标准归一化（如MNIST: µ=0.1307, σ=0.3081；CIFAR-10: 逐通道均值和方差）。音频使用log-Mel特征（40 Mel bands）。
    - **数据增强**：视觉使用随机仿射变换、随机裁剪、翻转、颜色抖动、Cutout（Big-MCU）等。音频使用随机时间平移、背景噪声混合、SpecAugment、随机增益等。
    - **损坏/分布外数据**：使用MNIST-C, CIFAR-10-C, TinyImageNet-C（视觉）和合成的SpeechCmd-C（音频）作为损坏样本；使用Fashion-MNIST, SVHN, 非关键词语音等作为OOD样本。
- **损失函数**：
    - **总损失**：`L = L_clf + λ_SS * L_SS + λ_reg * R`
    - **L_clf**：标准的交叉熵分类损失，使用标签监督骨干网络训练。
    - **L_SS**：自监督惊讶度损失。对于每个小批量B和每个截取层ℓ∈S，`L_SS = (1/|B|) Σ_{x∈B} Σ_{ℓ∈S} [ (1/2)|| (aℓ - μℓ) ⊙ σℓ⁻¹ ||²₂ + (1/2) 1ᵀ log σ²ℓ ]`。这本质上是预测分布的负对数似然。为平衡不同维度层贡献，先对每层损失按`1/dℓ`归一化。
    - **R**：正则化项，`R = Σ_{ℓ∈S} ||log σ²ℓ||₁ + λ_w Σ_{ℓ∈S} (||W_{μ,ℓ}||²₂ + ||W_{σ,ℓ}||²₂)`，惩罚极端方差预测和过大的头权重，防止退化和过拟合。
    - **权重**：辅助损失权重`λ_SS`在{10⁻³, 5·10⁻³, 10⁻²}中搜索。
- **训练策略**：
    - **优化器**：Adam（MNIST）、SGD with momentum（CIFAR-10, TinyImageNet）、AdamW（SpeechCommands）。
    - **学习率**：采用余弦退火调度。例如MNIST: 1e-3 → 1e-5 over 50 epochs; CIFAR-10: 0.2 → 5e-4 over 200 epochs。
    - **Batch Size**：128（CIFAR-10, TinyImageNet），256（MNIST, SpeechCommands）。
    - **Warmup**：`λ_SS`在训练初期线性warmup（如MNIST前5个epoch，CIFAR-10前20个epoch）以稳定训练。
    - **其他技巧**：标签平滑（CIFAR-10），MixUp（Big-MCU），全局梯度裁剪（CIFAR-10, TinyImageNet），EMA（TinyImageNet）。
- **关键超参数**：
    - **骨干网络**：DSCNN（SpeechCommands, ~130k参数），紧凑ResNet（CIFAR-10, ~0.3-0.5M参数），MobileNetV2 0.5x（TinyImageNet, ~1.3M参数）。
    - **SNAP-UQ截取层**：通常2层（中间层和倒数第二层）。
    - **投影器秩（rℓ）**：从{32, 64, 128}中选择，以平衡性能与计算开销。
    - **预测头**：线性层，输出维度为`2 * dℓ`（预测μ和log σ²）。
    - **方差参数化**：`σ² = softplus(ξ) + ε²`，其中`ε = 1e-4`，`log σ²`被钳位在`[log 1e-4, log 1e2]`。
    - **映射参数**：逻辑回归的参数β₀, β₁, β₂在开发集上拟合。
- **训练硬件**：论文中未明确说明GPU/TPU型号及训练时长。只提到在MCU上的构建和测量细节。
- **推理细节**：
    - **单次前传**：如架构所述，所有计算在一次前向传播中流式完成。
    - **量化部署**：投影器和头权重存储为int8（per-tensor scales），使用int32累加器。`exp(-0.5 log σ²)`通过256项查找表（LUT）近似计算。
    - **不确定性阈值**：使用固定阈值τ对U(x)进行二分类（正常/异常），τ在开发流上通过最大化F1分数确定。
- **正则化/稳定技巧**：
    - 方差下界和钳位：防止`σ²`趋近于零或无穷。
    - 权重衰减：应用于投影器和头的参数。
    - 梯度分离（可选）：在计算`L_SS`时，对aℓ使用`stop_gradient`，防止辅助损失扰动骨干网络训练，提高在小数据集上的稳定性。
    - 量化感知训练（QAT）：可选，在训练最后阶段插入伪量化层以减少int8误差。

### 📊 实验结果

- **主要Benchmark与数据集**：MNIST, CIFAR-10, TinyImageNet, SpeechCommands v2及其损坏版本（-C）。
- **主要指标**：Flash占用(KB)、峰值RAM(KB)、延迟(ms)、能量(mJ)；流式监控AUPRC；故障检测AUROC（ID✓— ID×， ID✓— OOD）；ID校准（NLL, BS, ECE）。
- **与最强基线对比**：
    - **MCU部署效率**（表1关键数据）：在Big-MCU (SpeechCommands)上，SNAP-UQ比早退集成(EE-ens)快35%，小24%；比深度集成(DEEP)快26%，小37%。在Small-MCU (CIFAR-10)上，EE-ens和DEEP因OOM无法运行，而SNAP-UQ的Flash为158KB，延迟178ms。
    - **流式监控**（表2关键数据）：在MNIST-C上，SNAP-UQ的AUPRC为0.66，优于BASE(0.54), DEEP(0.56)；检测延迟24帧，低于其他所有方法。
    - **故障检测**（表3关键数据）：在ID✓— ID×任务上，SNAP-UQ在MNIST(0.90)和SpeechCommands(0.94)上达到最优，优于DEEP(0.85, 0.91)和QUTE(0.87, 0.91)。在ID✓— OOD任务上，在CIFAR-10上SNAP-UQ(0.94)接近最强的G-ODIN(0.95)和DEEP(0.92)。
- **关键消融实验**：
    - **投影器秩(rℓ)**：更高的秩通常带来稍好的性能，但会增加计算成本和内存（附录N详细讨论）。
    - **协方差模型**：添加低秩校正(`Σ = diag(σ²) + BB^T`)在资源允许时可以收紧条件模型（如SNAP-UQ+在CIFAR-10校准上匹配DEEP）。
    - **映射选择**：逻辑映射更适合ID校准，等保回归更适合固定覆盖率监控（附录J讨论）。
    - **梯度分离**：在MNIST等小数据集上，分离aℓ的梯度可能提高稳定性（附录N报告）。
- **不同条件下结果**：在多个数据集（视觉/音频）、多种MCU（Big/Small）、多种任务（分类、流监控、故障检测、校准）上均报告了结果，展示了方法的普适性和稳健性。性能随损坏严重度增加的趋势（图2）也符合预期。
