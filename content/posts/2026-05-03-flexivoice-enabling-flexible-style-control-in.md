### 💡 毒舌点评

亮点在于其“渐进式后训练”策略如同精准的外科手术，系统地解决了风格、音色、内容三者纠缠的顽疾，使得自然语言指令能真正“驯服”语音合成模型。短板是其在追求极致风格表达时，生成语音的字错率（WER）较基座模型略有上升，且对参考语音的依赖仍是一个需要平衡的点。

### 📌 核心摘要

1.  **问题**：在零样本文本转语音（TTS）中，同时用自然语言指令控制说话风格和用参考语音克隆音色时，存在“风格-音色-内容冲突”，模型容易忽略指令，而受到参考语音或文本内容中固有风格的干扰。
2.  **方法核心**：提出FlexiVoice，一个基于大语言模型（LLM）核心的零样本TTS系统。其创新点在于提出“渐进式后训练（PPT）”框架，分三步走：首先用多模态DPO让模型初步学会同时遵循指令和参考语音；然后用解耦GRPO，在冲突场景下强制模型分离风格与音色/内容；最后用指令GRPO，借助音频语言模型奖励，增强对复杂开放指令的泛化能力。
3.  **新在何处**：不同于以往简单地将指令和参考语音作为输入条件，FlexiVoice通过PPT框架，显式地将“条件化”问题转化为一个主动的“解耦”过程，并构建了大规模、高质量的指令-语音数据集FlexiVoice-Instruct作为支撑。
4.  **主要实验结果**：在自建的多模态解耦评估集上，FlexiVoice在英语/中文的“文本+参考语音”困难任务中，指令遵循准确率（ACC-I）分别达到78.2%/75.8%，远高于基线（如VoxInstruct为23.9%/18.7%）。在复杂指令基准InstructTTSEval上，平均准确率（英语79.3%，中文70.8%）超越所有开源基线，逼近Gemini-pro等闭源系统（80.3%/84.8%）。主观评价CMOS均为正，表明其表达力被人类评审认可。

    | Ground-truth | 84.3 | 82.5 |
    | Gemini-pro | 80.3 | 84.8 |
    | MiMo-Audio-7B-Instruct | 72.6 | 70.5 |
    | VoxInstruct | 50.4 | 47.5 |
    | **FlexiVoice** | **79.3** | **70.8** |
5.  **实际意义**：该系统为实现更自然、灵活的人机语音交互提供了有力工具，用户可通过自然语言描述所需情感、语速、语调等，并配合任意音色参考，生成定制化语音，在配音、虚拟助手、有声读物等领域有广阔应用前景。
6.  **局限性**：推理阶段涉及LLM自回归生成和流匹配，速度可能受硬件限制。虽然解决了主要冲突，但在极端风格转换时仍可能对参考语音的音色相似度造成轻微影响（SV分数略有下降）。

### 🏗️ 模型架构

FlexiVoice的架构是一个典型的基于LLM的生成式TTS流水线，主要包含三个阶段：预处理（输入编码）、LLM核心（离散token生成）和声码器（波形生成）。

1.  **输入处理**：系统接受三个可选输入：文本（必需）、自然语言风格指令（可选）、参考语音（可选，用于音色克隆）。文本和指令会按照LLM的输入模板进行格式化（如图3所示）。参考语音则通过一个**冻结的语音分词器**（DualCodec）转换为离散语义token序列。
2.  **LLM核心**：采用预训练的Phi-3.5-mini-instruct LLM。格式化后的文本/指令token序列与参考语音token序列被拼接，作为LLM的输入。LLM以自回归方式生成目标语音的离散token序列。
3.  **声码器**：生成的离散token序列首先通过一个**流匹配**（Flow Matching）模块（在Emilia数据集上预训练），被转换为梅尔频谱图。最后，梅尔频谱图通过一个**Vocos声码器**转换为最终的音频波形。

整个架构的关键设计选择在于将风格和音色的控制解耦：风格主要由自然语言指令在LLM层面进行控制，而音色则通过参考语音的token在流匹配模块作为条件进行建模。预训练阶段只训练LLM核心，后训练阶段则主要针对LLM核心进行对齐优化。

### 💡 核心创新点

1.  **渐进式后训练框架**：提出PPT，这是一个专门针对可控TTS的课程学习方案。它通过从简单到复杂的三阶段训练（DPO -> 解耦GRPO -> 指令GRPO），系统性地解决了多模态控制中的模态冲突问题，而非简单堆叠条件。
2.  **显式解耦训练策略**：在S2阶段，通过构建指令情感与参考语音情感冲突的训练场景，并设计多目标奖励（情感准确性和说话人验证），迫使模型在数学优化层面分离并忽略无关的风格信号，专注于音色保持和指令遵循。
3.  **大规模高质量指令数据集**：构建了FlexiVoice-Instruct（4316小时），利用LLM（Deepseek-V3）为广泛来源的语音（包括游戏配音）生成自然、多样的风格描述指令，弥补了现有数据集指令模板化、多样性不足的缺陷。

### 🔬 细节详述

- **训练数据**：
    - **预训练**：混合使用了Emilia（大规模多语言）、FlexiVoice-Instruct（4316小时）、ParaSpeechCaps、多个情感数据集、KeSpeech（方言/年龄/性别）、NVSpeech（副语言标签）等。
    - **后训练**：
        - S1（DPO）：使用ESD情感数据集，构建偏好对（同一说话人、同一句子、不同情感）。
        - S2（解耦GRPO）：从NCSSD采样对话文本，并随机分配情感标签和参考语音（中性或冲突情感）。
        - S3（指令GRPO）：从预训练数据中采样1000条，另外用LLM生成14000条复杂指令-文本对。
- **损失函数/训练策略**：
    - **预训练**：标准的交叉熵损失，训练LLM核心预测下一个语音token。
    - **S1 (DPO)**：使用DPO损失，偏好数据来自情感数据集。
    - **S2 (解耦GRPO)**：使用GRPO算法，奖励包括：`r_ser`（情感识别模型打分，0-1）和 `r_sv`（说话人验证结果，0或1）。优势函数为两者归一化后的和。
    - **S3 (指令GRPO)**：使用GRPO算法，奖励 `r_llm` 由Kimi-Audio-7B-Instruct模型对生成语音是否匹配指令给出二元判断（0或1）。训练时混合少量S2数据以防遗忘。
- **关键超参数**：LLM骨干为Phi-3.5-mini-instruct（约3.8B参数）。DPO训练：3 epochs，lr=1e-5，β=0.1。S2 GRPO：2 epochs，lr=1e-5，β=0.1，组大小G=8。S3 GRPO：2 epochs，组大小G=6。
- **训练硬件**：8x NVIDIA A800 (80GB) GPU。总后训练时间约3.5天（S1: ~2h, S2: ~36h, S3: ~42h）。
- **推理细节**：论文未详细说明解码策略（如温度、beam size）。
- **正则化**：在S3阶段混合S2数据进行多任务训练，以缓解灾难性遗忘。

### 📊 实验结果

论文在多个维度进行了全面评估，关键结果如下：

**1. 多模态控制与解耦能力（表2）**
评估集包含单模态（TO）和多模态（TR）任务，每种又分简单（Easy）和困难（Hard）。
| 任务类型 | 难度 | 指标 | FlexiVoice (EN) | FlexiVoice (ZH) | 最强基线 (VoxInstruct) |
| :--- | :--- | :--- | :---: | :---: | :---: |
| **TO** | Easy | ACC-I↑ | 97.4 | 99.8 | 70.6 / 48.6 |
| **TO** | Hard | ACC-I↑ / ACC-T↓ | 89.4 / 6.6 | 98.4 / 0.8 | 17.8 / 21.2 / 29.0 / 21.2 |
| **TR** | Easy | ACC-I↑ / SV↑ | 89.4 / 91.0 | 81.8 / 98.8 | 58.5 / 89.0 / 19.4 / 46.8 |
| **TR** | Hard | ACC-I↑ / ACC-R↓ / E-SIM↑ / SV↑ | 78.2 / 10.6 / 0.87 / 95.8 | 75.8 / 13.2 / 0.80 / 98.4 | 23.9 / 90.6 / 18.7 / 59.8 |
**结论**：FlexiVoice在指令遵循准确率上大幅领先所有基线，即使在指令与文本/参考语音冲突的困难设置下，也能保持高准确率和低干扰率（ACC-T/ACC-R），同时维持较高的说话人相似度（SV），证明了其强大的解耦能力。

**2. 可听度与主观评价（表3）**
| 模型 | TO-Easy WER↓ (EN) | Q-MOS↑ | CMOS↑ |
| :--- | :---: | :---: | :---: |
| Ground-truth | 4.50 | 3.16 | 0.00 |
| FlexiVoice-Base | 5.01 | 3.72 | -0.12 |
| **FlexiVoice** | **5.99** | **4.08** | **+0.91** |
**结论**：FlexiVoice的WER略有增加，但主观质量评分（Q-MOS）和比较评分（CMOS）均为最佳，表明其生成的语音自然且表达力更强，人类感知上并无可懂度下降。

**3. 复杂指令遵循（InstructTTSEval基准，表4）**
基准包含声学参数指定（APS）、描述性风格指令（DSD）和角色扮演（RP）三级任务。
| 模型 | 英语平均 | 中文平均 |
| :--- | :---: | :---: |
| Ground-truth | 84.3 | 82.5 |
| Gemini-flash | 88.7 | 85.4 |
| Gemini-pro | 80.3 | 84.8 |
| MiMo-Audio-7B-Instruct | 72.6 | 70.5 |
| VoxInstruct | 50.4 | 47.5 |
| **FlexiVoice** | **79.3** | **70.8** |
**结论**：FlexiVoice在复杂指令遵循上表现卓越，英语平均准确率接近Gemini-pro，中文平均准确率超越MiMo-Audio-7B-Instruct，远超其他开源TTS系统。

**4. 渐进式后训练有效性（消融实验，表5）**
| 训练策略 | 解耦集平均准确率 | InstructTTSEval平均准确率 |
| :--- | :---: | :---: |
| FlexiVoice-Base | 54.9 | 66.4 |
| + S3 (直接训练复杂指令) | 54.7 | 72.3 |
| + S3→S1 (顺序相反) | 84.4 | 74.8 |
| + S1→S2+S3 (联合训练) | 84.1 | 75.5 |
| **+ S1→S2→S3 (PPT，本文)** | **88.7** | **79.3** |
**结论**：消融实验清晰地证明了：1）直接进行复杂指令训练效果差；2）训练顺序至关重要，反向训练会导致遗忘；3）联合训练因目标冲突不如渐进训练。本文的PPT路径在所有指标上最优。

![消融实验结果对比](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/F7GmbfyVg9-3.png)

*上图直观地展示了不同训练顺序（S3先、反向、联合）与本文PPT策略（S1->S2->S3）在解耦评估集TR-hard任务上指令遵循准确率（ACC-I）随训练轮次的变化，清晰地体现了PPT策略的优越性和稳定性。*
