### 📌 核心摘要

1. 要解决什么问题：现代神经网络严重依赖固定的激活函数（如ReLU），这限制了其适应任务特定结构和高效捕获高阶交互的能力，尤其在需要高保真信号表示的隐式神经表示等领域存在频谱偏置等瓶颈。
2. 方法核心是什么：提出了一种名为深度低秩分离神经网络（LRNN）的新架构。其核心是为每个神经元设计可学习的“乘积结构激活函数”：将输入线性投影到多个维度后，每个维度通过一个可学习的一元函数进行变换，最终将这些变换结果相乘，从而生成高度灵活的、数据依赖的非线性激活。
3. 与已有方法相比新在哪里：1) 架构层面：LRNN泛化了MLPs，将固定的标量激活函数替换为可学习的向量到标量的乘积映射，能自然捕获乘积交互。2) 理论层面：为LRNNs建立了普遍近似定理，并证明了其能缓解具有衰减ANOVA结构的函数的维度灾难，以及通过组合频率合成自适应控制频谱偏置。3) 性能层面：在多个基准上，LRNN用更少参数实现了远超现有SOTA（如SIREN, SPDER）的性能。
4. 主要实验结果如何：在多个任务上取得SOTA：a) 图像表示：在1000张ImageNet图像上，LRNN以~200k参数达到40dB PSNR的100%成功率，而SIREN和SPDER的成功率分别仅为1.8%和26.4%（见下表）。b) 音频表示：MSE比基线低3-11倍。c) PDE求解：以8倍参数缩减超越SIREN，误差比KANs低100-1000倍。d) 稀疏CT重建：获得无伪影重建，PSNR达29.13dB，优于所有基线（见下表）。
    | 模型 | PSNR (dB) | SSIM |
    |---|---|---|
    | LRNN | 29.13 | 0.7455 |
    | WIRE | 28.83 | 0.6413 |
    | Gauss | 27.84 | 0.6855 |
    | SIREN | 27.46 | 0.6877 |
    | ReLU | 26.89 | 0.6341 |
5. 实际意义是什么：LRNNs提供了一种强大的、具有独特归纳偏置的构建块，能够在紧凑的参数下学习极具表达力的表示。这对于需要高保真信号重建（如医学成像、计算机图形学）和高效求解高维PDE的科学计算领域具有重要应用价值。
6. 主要局限性是什么：1) 论文中提到，其反向传播由于需要存储中间乘积结果，内存占用高于标准MLPs，尽管提出了融合等优化策略。2) 每迭代时间（wall-clock time）在某些任务上高于部分基线模型（如SIREN），尽管它达到高目标质量的速度更快。

### 🏗️ 模型架构

LRNN的整体架构是对多层感知机（MLP）的泛化，旨在通过可学习的乘积结构激活函数增强表达能力。

![论文中的图片](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/EB2Qgp5Vb0-9.png)
(图10：深度LRNN架构示意图。展示了数据流从输入x(0)经过多个LRNN层ϕ(k)逐步变换，最终通过输出层Sout得到预测。)

完整流程与主要组件：
1.  输入投影：对于第k层的第ℓ个神经元，首先将前一层的输出ϕ(k-1)通过一个线性层（权重Wℓ,(k)，偏置bℓ,(k)）投影到一个固定维度¯d_k的向量zℓ,(k)。这一步与标准MLP类似，但维度¯d_k是一个关键超参数。
2.  产品结构激活（核心）：LRNN神经元的激活不再是一个标量函数，而是计算一个乘积：
    φ(k)_ℓ(zℓ,(k)) = ∏_{j=1}^{¯d_k} (1 + γ * g^{(k)}_ℓ,j(z_{ℓ,(k),j}))
    - γ (缩放因子)：设为1/√¯d_k。其作用是稳定前向和反向传播的方差，确保梯度流稳定，是实现自动相关性确定（ARD）的关键，类似于Xavier/He初始化或LoRA中的缩放。
    - g^{(k)}_ℓ,j (一元分量函数)：每个投影维度z_j都通过一个独立的、可学习的函数g(·)进行变换。在实践中，这些函数被参数化为一个小型MLP（例如，一层隐藏层+线性输出层）。其内部激活函数可以根据任务选择（如SIREN的sin，或SPDER的sin(x)√|x|）。
    - 乘积与(1+·)结构：乘积操作天然捕获了不同投影维度间的高阶交互。引入“1+”的偏移使得初始化时（g(·)初始化为0）每个因子为1，乘积为1，便于从基线开始学习；同时显式包含了常数项和可加项，使其展开后类比于ANOVA分解。
3.  层输出：一个LRNN层的所有神经元输出组成向量ϕ(k) = [φ(k)_1, φ(k)_2, ..., φ(k)_rk]^T。在每层输出后应用LayerNorm是稳定深度LRNN训练的必要技巧，因为乘积结构会改变激活统计特性。
4.  堆叠与输出：多个这样的LRNN层可以堆叠，形成深度LRNN。最后一层的输出ϕ(L)通过一个线性层Sout映射到目标输出空间。
5.  参数共享：为降低复杂度，可以在同一层内共享一元分量函数g^{(k)}_j，即所有神经元ℓ在第k层使用相同的函数集{g^{(k)}_j}。消融研究表明，对于复杂高频信号，不共享（即每个神经元独立学习）能获得更高保真度。

关键设计动机：乘积结构不仅提供了比加性结构（如标准MLP）更强的高阶交互建模能力，还使得LRNN能够编码类似于低秩张量分解（如CP分解）的“和-积”结构。这使得LRNN在理论上能高效表示具有衰减ANOVA相互作用的函数，从而缓解维度灾难。

### 💡 核心创新点

1.  可学习的乘积结构激活函数：这是LRNN最核心的创新。之前方法（如ReLU、SIREN）使用固定或参数有限的激活函数。LRNN的每个神经元通过一个乘积，将多个可学习的一元变换组合成一个高度灵活、数据依赖的激活函数，实现了从“固定标量”到“可学习向量到标量映射”的跨越。
2.  理论保证的表达优势：论文不仅提出架构，还提供了坚实的理论分析。包括：证明了LRNN的普遍近似定理；关键定理（Theorem 2）表明，对于具有衰减ANOVA结构（即主要由低阶变量交互构成）的函数，LRNN的参数复杂度是多项式增长而非指数增长，从而缓解维度灾难；证明了LRNN通过乘积产生的组合频率合成能力，使其能自适应控制频谱偏置（Lemma 2）。
3.  多领域SOTA性能与效率提升：在隐式神经表示（图像、音频）和科学计算（PDE）等多个高难度基准上，LRNN用更紧凑的模型（参数更少）达到了远超现有先进基线（SIREN, SPDER, KAN）的性能。例如，在ImageNet高保真度图像表示上达到100%成功率，在PDE任务上实现8倍参数缩减。

### 🔬 细节详述

- 训练数据：论文在多个任务上使用不同数据集，具体如下：
    - 图像表示：Cameraman (256x256灰度)、Retina (256x256 RGB)、ImageNet子集 (1000张256x256图像)、DIV2K (超分辨率任务)。
    - 音频表示：四个音频片段（bach古典音乐，counting计数语音，reggae雷鬼音乐，reading朗读语音）。
    - PDE求解：高频Poisson方程。
    - CT重建：一张256x256胸部CT图像。
    - 预处理：对于图像，将像素坐标归一化到[0,1]；对于音频，将时间归一化。数据增强未说明。
- 损失函数：主要使用均方误差（MSE） 作为损失函数，适用于回归任务。对于分类任务（附录I），使用交叉熵损失。论文中未提及损失权重。
- 训练策略：
    - 优化器：所有实验均使用Adam优化器。
    - 学习率：LRNN通常使用较高的学习率（如1e-3），而基线模型（SIREN, SPDER）使用作者推荐的1e-4。
    - 学习率调度：LRNN常使用StepLR调度器（如每100步衰减，因子γ=0.8或0.9）。基线模型通常不使用调度器。
    - 训练步数：INR任务（图像、音频）通常训练1000步。
    - Batch size：对于INR任务，由于处理坐标，batch size通常很大（如16384）。
- 关键超参数（以图像表示实验为例）：
    - 分离秩（r）：控制LRNN层的宽度/容量，如106。
    - 投影维度（¯d）：每个神经元的乘积中的因子数量，如16。这是控制交互阶数和频谱复杂度的关键。
    - 深度：LRNN模型通常为2层。
    - 分量函数MLP结构：每个g(·)是一个小型MLP，例如“输入->激活->线性输出”。隐藏神经元数量为1。
    - 频率参数（ω0）：用于缩放分量函数内部激活函数（如sin(ω0 z)）的输入，控制基础频率，如30。
- 训练硬件：单张NVIDIA 4090 GPU。
- 推理细节：对于INR任务，训练好的模型直接用于从输入坐标生成输出值（如像素值、信号值），无需解码策略。对于CT重建，模型在投影域训练，然后用于重建图像。
- 正则化与稳定技巧：
    - LayerNorm：在每层LRNN输出后应用，对稳定训练至关重要（消融研究表明去除后误差增大数个量级）。
    - 方差控制初始化：通过γ = 1/√¯d的缩放因子，确保前向激活方差和反向梯度方差之和与¯d无关，实现稳定初始化。
    - 参数共享：可选，以减少参数量。

### 📊 实验结果

论文在四个主要领域进行了全面实验，证明了LRNN的优越性。

1. 图像表示（INR）
- 主要Benchmark：Cameraman, Retina, ImageNet子集（1000张），DIV2K。
- 指标：峰值信噪比（PSNR）。
- 关键结果：
    - Cameraman图像（~197k参数）：LRNN-SPDER达到107.94 dB，远超第二名SPDER（49.0 dB）和SIREN（35.27 dB）。

    (图3：Cameraman图像重建对比。左图显示LRNN重建几乎与原图无异，而SIREN等存在模糊。右图收敛曲线显示LRNN持续上升且远超其他模型。)
    - ImageNet鲁棒性研究：LRNN在40dB PSNR目标上达到100%成功率，而SIREN和SPDER的成功率分别为1.8%和26.4%（见下表）。这证明了LRNN在高保真度要求下的巨大优势。

    | SPDER | 26.4% | N/A |
    | LRNN | 100% | 8.7 |
    - 高分辨率图像（Kodak, Parrot）：LRNN在训练损失和PSNR曲线上均优于SIREN、WIRE、Gauss、ReLU+PE、SPDER（见下图）。

2. 音频表示
- 数据集：bach, counting, reggae, reading四个音频片段。
- 指标：MSE损失，频率相似度（ρ_AG）。
- 关键结果：LRNN-SPDER在所有数据集上均显著优于SIREN和SPDER，MSE降低3-11倍，且频率相似度更高（见下表），表明其在时频域都更准确。

|---|---|---|
| SIREN | 1.21(0.28) | 0.9986(5) |
| SPDER | 1.12(0.05) | 0.9988(3) |
| LRNN-SPDER | 0.10(0.01) | 0.9999(0) |

3. PDE数值求解（高频Poisson方程）
- 基准：频率参数n=2和n=4的Poisson方程。
- 指标：测试集MSE。
- 关键结果：
    - LRNN以16k参数达到了比132k参数的SIREN更低的误差（n=2），实现了8倍参数缩减。
    - 在n=4时，57k参数的LRNN将误差比132k参数的SIREN降低了近一个数量级。
    - 相比KAN（Kolmogorov-Arnold Networks），LRNN的误差低100-1000倍（见下图）。

4. 稀疏视图CT重建
- 任务：从50-100个稀疏投影重建256x256胸部CT图像。
