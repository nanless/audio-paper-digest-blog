### 📌 核心摘要

1.  要解决的问题：当前用于情感理解的多模态大语言模型存在两大关键缺陷：一是将情感预测建立在无关的音频视觉线索上（推理错误），二是为了合理化情感而虚构出不存在的线索（感知错误），后者尤其受语言模型的文本先验驱动。
2.  方法核心：提出AVEm-DPO，一种多模态直接偏好优化技术。它通过构建两类偏好对：(1) 基于提示的模态输入偏好，确保模型关注正确的模态线索；(2) 基于情感的响应偏好，惩罚那些包含无关线索或虚构线索的回答。同时引入文本先验去偏正则化项，减少模型对仅文本输入的依赖。
3.  与已有方法的比较新意：与仅使用响应偏好的Naive-DPO不同，AVEm-DPO显式地在音频视觉输入层面和响应层面构建偏好，并专门针对情感推理任务设计了“推理正确但线索无关”和“情感相关但线索虚构”两类拒绝响应。与Vista-DPO相比，其模态偏好是提示词（prompt）驱动的，更具针对性。
4.  主要实验结果：在提出的EmoReAlM基准测试上，AVEm-DPO使参考基线模型（“Our base”和“EmotionLLaMA⋆”）的平均准确率分别从65.1%提升至83.3%和从63.8%提升至80.1%（相对提升约28%和25.5%）。在零样本评估的现有数据集（DFEW, RAVDESS, MER2023, EMER）上，也获得了6-19%的相对性能提升。具体关键结果见下表。

| 模型 | DFEW (UAR/WAR) | RAVDESS (UAR/WAR) | MER2023 (F1) | EMER (Clue/Label/Spurious/Halluc.) |
| :--- | :--- | :--- | :--- | :--- |
| Our base | 56.78 / 60.14 | 53.59 / 53.01 | 89.19 | 5.63 / 6.45 / 5.41 / 5.19 |
| + AVEm-DPO | 58.54 / 64.24 | 58.66 / 55.48 | 92.18 | 6.37 / 7.08 / 7.09 / 6.75 |
| EmotionLLaMA⋆ | 54.89 / 58.26 | 52.59 / 48.12 | 90.01 | 5.78 / 6.21 / 5.36 / 5.23 |
| + AVEm-DPO | 57.06 / 62.12 | 56.21 / 51.03 | 91.68 | 6.02 / 6.99 / 7.02 / 6.62 |

5.  实际意义：提供了一个严谨的基准（EmoReAlM）和一个有效的优化框架（AVEm-DPO），可用于评估和提升多模态大模型在情感推理任务上的可靠性、可解释性和鲁棒性，推动社交AI发展。
6.  主要局限性：EmoReAlM基准源自DFEW数据集，可能继承其文化偏差；当前工作主要针对短视频（~2-10秒），长视频情感推理尚未探索；对“厌恶”等模糊情感的识别仍有提升空间。

### 🏗️ 模型架构

AVEm-DPO是一种偏好优化训练方法，并非提出一个全新的基础模型架构。它作用于已有的音频视觉多模态大语言模型（MLLM），如论文中使用的“EmotionLLaMA”变体。整体流程是：在预训练或微调后的MLLM基础上，使用构造好的偏好数据集，通过AVEm-DPO损失函数对模型进行进一步优化。

主要组件和流程如下：
1.  基础模型（πref）：一个音频视觉MLLM。论文中使用了两个版本：“Our base”（基于EmotionLLaMA改进，使用Whisper-Large-v3作为音频编码器，LanguageBind作为视频编码器）和“EmotionLLaMA⋆”。它们接收音频、视频和文本提示作为输入，输出文本响应。
2.  偏好数据集（Dpref）：包含（音频，视频，提示，优选响应yw，拒绝响应yl）元组。拒绝响应yl分为两类：
    *   视频相关但情感无关（yvr_l）：线索存在于输入中，但无法解释情感。
    *   情感相关但视频虚构（yer_l）：线索常与情感关联，但未在输入中出现（幻觉）。
3.  优化目标（AVEm-DPO损失）：核心是公式(9)：`LAVEm-DPO = Ly_DPO-TPD + λav*Lav-prompt_DPO`。
    *   情绪响应偏好项（Ly_DPO-TPD）：在标准DPO损失基础上，加入文本先验去偏（TPD）项。该公式(8/10)鼓励模型给出优选响应yw，同时惩罚给出两类拒绝响应yl的倾向，并额外惩罚那些仅基于文本就能预测出的响应（通过TPD项实现）。
    *   提示词模态偏好项（Lav-prompt_DPO）：公式(5)。根据当前提示x所指向的模态（音频/视频），构造一个拒绝的输入对(al, vl)，其中仅修改提示相关模态的输入（例如，若提示问视频，则修改视频输入，保持音频不变），强制模型的响应必须基于正确的模态输入。
4.  文本先验去偏（TPD）：关键创新之一。通过公式(7)，在奖励函数中减去一项`γTPD * log πtext(y|x)`，其中πtext是仅基于文本输入的语言模型（使用基础模型的LLM骨架）。这惩罚了那些仅凭文本先验就能生成的响应，促使模型更多地依赖音频视觉证据。
![图4](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/td682AAuPr-3.png)
图4：AVEm-DPO中的偏好对构建示意图。上方展示了基于提示的模态偏好：对于一个特定模态（如视觉）的问题，拒绝对通过修改该模态的输入构造。下方展示了情绪响应偏好：一个优选响应对应两个拒绝响应（一个线索相关但情感无关，一个情感相关但线索虚构）。

训练时，在基础模型的LLM部分附加LoRA模块进行适配，以保持原始文本能力。

### 💡 核心创新点

1.  EmoReAlM基准测试：创建了一个专门评估音频视觉情感推理中“推理错误”（线索-情感虚假关联）和“感知错误”（线索幻觉）的标准化基准。它包含4000个人工验证的MCQA样本，涵盖基本推理、模态一致性和压力测试（探测虚假关联与幻觉）。其创新在于聚焦于情感特定的跨模态推理可靠性，而非通用对象级幻觉。
2.  基于提示的模态偏好优化（PMP）：在DPO框架中，首次系统性地引入了由输入提示（prompt）驱动的模态级输入偏好。这解决了通用多模态DPO可能忽略模态对应关系的问题，确保模型对关于音频（或视频）的问题，其响应确实基于音频（或视频）输入。
3.  文本先验去偏（TPD）：设计了一个轻量级正则化项，在DPO优化中显式惩罚那些仅靠语言模型文本先验就能生成的响应。这直接针对由LLM骨架强文本关联性导致的线索幻觉问题，是解决“感知错误”的关键。

### 🔬 细节详述

*   训练数据：偏好数据集使用MAFW和MER2025 Track-1训练集构建，通过类似EmoReAlM的流水线（但使用Gemini-2.5 Flash生成）自动生成，未经人工验证。共生成41687个偏好样本。
*   损失函数：详见上文模型架构部分。关键超参数：β=0.1，λav=1.0，βer=βvr=0.5，γTPD=0.2。
*   训练策略：在NVIDIA DGX节点（8x H100 GPU）上训练。学习率5e-7，每GPU批量大小2，梯度累积4步，训练1个epoch。在LLM骨干网络上使用LoRA（rank=8, scale=4）。
*   关键超参数：模型规模与基础模型相同（基于7B参数量LLM的MLLM）。DPO温度β=0.1。
*   训练硬件：8块NVIDIA H100 GPU。
*   推理细节：论文未在正文中明确说明推理时的解码策略（如温度、beam size），可能沿用基线默认设置。
*   正则化技巧：文本先验去偏（TPD）是核心正则化技术；使用LoRA防止全参数微调导致灾难性遗忘。
