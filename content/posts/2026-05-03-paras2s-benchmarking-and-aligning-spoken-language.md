### 📌 核心摘要

1.  问题：现有的语音到语音（S2S）模型虽然能进行对话，但普遍缺乏对用户语音中的副语言信息（如情绪、语气、年龄、性别）的感知和恰当回应能力，导致对话“不通情达理”。同时，缺乏能够评估这种能力的公开基准。
2.  方法核心：提出了ParaS2S框架，包含两大部分：1) ParaS2SBench，一个专门设计来测试模型副语言意识的基准，其特点是使用内容中立但风格对比强烈的查询；2) ParaS2SAlign，一个强化学习（RL）框架，利用一个分阶段的自动评估器作为奖励信号来训练模型。
3.  与已有方法相比新在哪里：1) 首次为S2S模型构建了端到端评估副语言意识的基准（以往基准止步于文本评估）。2) 提出了一种“语言解耦”的多阶段自动评估器（PolyTone训练+LLM判断），有效缓解了端到端音频大模型判断时的“风格幻觉”问题，其评分与人类更相关。3) 证明了利用该评估器进行RL训练，可以在极少的人工标注数据下，超越使用大量数据的监督微调（SFT）方法。
4.  主要实验结果：
    *   评估器有效性：多阶段自动评估器与人类评分的皮尔逊相关系数最高达到0.776（O2行），显著优于端到端音频LLM基线（0.618）。
    *   模型性能：在ParaS2SBench上，经过RL（GRPO）训练的Kimi-Audio模型（4.382分）相比纯SFT（3.955分）提升约10.8%，并超越所有现有开源和闭源模型。具体分数见下表。

    | 模型/方法 | 合成数据平均分 | 真实数据平均分 | 总平均分 |
    | :--- | :--- | :--- | :--- |
    | Whisper-GPT-TTS (基线) | 3.022 | 3.487 | 3.176 |
    | GPT-4o Voice Mode | 3.284 | 3.639 | 3.403 |
    | Qwen2.5 Omni | 3.248 | 3.612 | 3.369 |
    | Kimi-Audio SFT (本文) | 4.076 | 3.714 | 3.955 |
    | Kimi-Audio GRPO (本文) | 4.441 | 4.161 | 4.382 |
    | GPT-TTS (Topline) | 4.705 | 4.766 | 4.725 |

5.  实际意义：为开发更自然、更有同理心的语音交互系统提供了关键的评估工具和高效的训练范式，证明了通过RL和可扩展的自动评估，能以更低的数据成本提升模型的副语言意识，推动S2S模型从“能说会道”向“善解人意”迈进。
6.  主要局限性：自动评估器虽优于基线，但相关性仍未达到完美（<0.8），可能成为RL训练的性能天花板；评估主要围绕英语展开，跨语言适用性未验证；训练和评估的查询在主题和TTS音色上做了隔离，但模型在更复杂真实场景中的泛化能力仍需观察。

### 🏗️ 模型架构

本文的核心贡献并非一个单一的新神经网络模型，而是一个包含数据构建、自动评估和强化学习训练的完整系统框架（ParaS2S）。其整体架构如图1所示。

![ParaS2S整体框架](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/CcmDDh070o-0.png)
图1：ParaS2S整体框架。底部展示了ParaS2SBench的构建过程和自动评估器；顶部展示了用于强化学习的奖励模型蒸馏过程。

该框架主要分为两大模块，相互配合：

模块一：ParaS2SBench（基准与评估器）
1.  数据构建：
    *   合成语音查询：使用LLM生成内容中立、风格对比的查询文本（例如，同一句话用快乐和悲伤两种语气说），然后通过TTS系统（如gpt-4o-mini-tts, CosyVoice）合成语音，并经过基于WER和Emotion2Vec的过滤以及人工校验。
    *   真实语音查询：从IEMOCAP、MELD等情感数据集中筛选符合要求的对话轮次。
    *   测试集覆盖：年龄、性别、情绪、讽刺四个副语言维度，每个维度300个合成查询，加上真实数据共2690个查询。
2.  多阶段自动评估器：
    *   阶段1：副语言分析：使用经过PolyTone训练策略微调的专用分析模型（如Emotion2Vec用于情绪/讽刺，预训练模型用于性别/年龄），以及AudioReasoner，分别从输入和输出语音中提取转录文本、情绪、性别、年龄和语调描述（自然语言形式）。PolyTone训练使用相同内容、不同风格的平行数据，迫使模型关注声学特征而非文本内容，从而减少“风格幻觉”。
    *   阶段2：LLM综合评判：将提取的所有文本信息（输入内容/风格、输出内容/风格）连同专家设计的评分指南（r）输入给一个文本LLM（如GPT-4.1），输出1-5分的连续自然度评分。

模块二：ParaS2SAlign（强化学习训练框架）
1.  基座模型：选择具备强大智能和开源特性的Kimi-Audio作为初始S2S模型。
2.  SFT热身：由于现有S2S模型普遍缺乏副语言意识，先用少量高质量配对数据（10小时）进行监督微调，使其具备初步的差异化回应能力，为后续RL提供良好的策略起点。
3.  奖励模型蒸馏：由于完整的评估器流水线运行缓慢，不适合在线RL。因此，将评估器蒸馏为一个快速、轻量的奖励模型（基于Qwen2.5-Omni + LoRA）。具体做法是：用热身模型对大量查询生成多种回应，用完整评估器打分，形成`(查询语音，回应语音，分数)`数据对来训练奖励模型。
4.  GRPO强化学习：使用奖励模型作为评分器，在大量未标注的语音数据上，采用组相对策略优化（GRPO）算法，最大化生成回应的奖励得分。同时通过KL散度约束防止模型偏离基座模型太远，以保留其原有对话能力。

### 💡 核心创新点

1.  首个面向S2S模型的副语言意识基准（ParaS2SBench）：创新性地设计了内容中立、风格对比的测试查询，并首次实现了对输出语音波形在内容和风格上的联合评估，直接揭示了当前模型“不通情达理”的问题。
2.  “语言解耦”的多阶段自动评估器：针对端到端音频大模型在评估对话自然度时易产生“风格幻觉”的局限，提出了将语音信息解耦为文本描述（转录、风格标签、语调描述），再由LLM判断的流水线。其中，PolyTone训练策略是确保风格分析模型准确性的关键。
3.  数据高效的RL训练范式（ParaS2SAlign）：证明了利用设计良好的自动评估器作为奖励信号，通过RL（GRPO）进行后训练，可以在仅需少量（10小时）监督数据热身的情况下，达到甚至超越使用五倍数据进行纯SFT的效果，有效缓解了高质量配对数据稀缺的瓶颈。

### 🔬 细节详述

- 训练数据：
  - PolyTone数据：为每个副语言类别生成1万条语音提示及对应风格标签，用于微调风格分析模型。
  - SFT数据：构建10万条语音提示，为每条提示生成一个合适的回应（文本+TTS合成语音），总计约100小时。用于SFT热身和作为纯SFT基线。
  - 奖励模型数据：使用1万条语音提示，每条用热身模型生成32种回应，形成32万`(提示，回应，分数)`三元组。
  - RL数据：使用所有语音提示，但丢弃所有文本和风格标签，仅使用语音波形进行训练。
- 损失函数：
  - SFT/奖励模型：标准的交叉熵损失（下一个词预测）。
  - GRPO（公式3,4）：结合了策略梯度损失和KL散度惩罚项。其中，优势函数`Âg`由奖励模型给出的分数归一化得到。
- 训练策略与超参数：
  - PolyTone：单卡H100训练。
  - SFT：8卡H100 FSDP，学习率1e-5，全局batch size 64。
  - 奖励模型LoRA微调：单卡H100，学习率1e-6，batch size 10。
  - GRPO RL：8卡H100 FSDP，学习率5e-4，全局查询batch size B=32，组大小G=8（即每个查询生成8个候选回应）。KL惩罚系数β=0.2（根据消融实验确定）。
- 训练硬件：主要使用NVIDIA H100 GPU。
- 推理细节：未具体说明解码温度、beam size等。RL训练中的回应采样使用高采样温度以增加多样性。
- 正则化技巧：GRPO中的KL散度约束（`β`）是防止策略退化和保持原有能力的关键技巧。

### 📊 实验结果

1. 自动评估器有效性验证（表2）
论文将多阶段自动评估器（O1-O6）与端到端音频LLM基线（B1）及人类评分进行对比，结果如下：

| 输入风格信息 | 输出风格信息 | 平均皮尔逊相关系数 |
| :--- | :--- | :--- |
| B1: gpt-audio (基线) | - | 0.618 |
| O1: 无 | 无 | 0.757 |
| O2: 无 | 语调描述 (✓) | 0.776 |
| O3: 无 | 情绪标签 (✓) | 0.731 |
| O4: 无 | 情绪标签 (✗) | 0.743 |
| O5: 真值标签 | 语调描述 (✓) | 0.723 |
| O6: 模型预测标签 | 语调描述 (✓) | 0.701 |

结论：使用“语调描述”（O2）比使用离散情绪标签（O3/O4）更能捕捉回应风格，相关性更高。PolyTone训练对情绪和讽刺的预测至关重要（对比O5和O6）。

2. 模型性能对比（表4）
在ParaS2SBench上，各模型在合成和真实数据上的表现如下：

| 模型/方法 | 合成数据平均分 | 真实数据平均分 | 总平均分 |
| :--- | :--- | :--- | :--- |
| Whisper-GPT-TTS (基线) | 3.022 | 3.487 | 3.176 |
| GPT-4o Voice Mode | 3.284 | 3.639 | 3.403 |
| Gemini | 3.447 | 3.762 | 3.552 |
| Qwen2.5 Omni | 3.248 | 3.612 | 3.369 |
| Kimi-Audio (基座) | 2.892 | 1.265 | 2.350 |
| Kimi-Audio SFT (本文) | 4.076 | 3.714 | 3.955 |
| Kimi-Audio GRPO (本文) | 4.441 | 4.161 | 4.382 |
| GPT-TTS (Topline) | 4.705 | 4.766 | 4.725 |

结论：现有S2S模型表现接近忽略风格的基线。本文方法显著超越所有现有模型，RL（GRPO）比SFT提升约10.8%。
