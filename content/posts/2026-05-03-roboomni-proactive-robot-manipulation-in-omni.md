亮点：它敏锐地抓住了当前VLA模型“等指令”的呆板痛点，并构建了一整套从“新问题定义”到“新架构”再到“新数据集”的解决方案闭环，特别是将语音中的副语言特征（如情感、说话人身份）作为关键推理线索，而非丢弃给ASR，这是一次重要的认知升级。短板：目前的实验场景仍以相对简单的“单步/少步抓取放置”为主，在更复杂的多步骤、长序列任务中，其“主动推理”的准确率和稳定性如何，以及如何处理复杂对话中的误解与修正，论文未做深入探讨，距离真正的“管家式”智能仍有距离。

### 📌 核心摘要

1. 解决问题：针对现有视觉-语言-动作（VLA）模型依赖显式指令、无法主动从多模态上下文（语音、环境声、视觉）中推断用户潜在意图的局限性，提出了“跨模态上下文指令”这一新问题设置。
2. 方法核心：提出RoboOmni，一个基于端到端全模态大语言模型的“感知器-思考器-对话器-执行器”（Perceiver-Thinker-Talker-Executor）统一框架。它直接处理语音波形和环境声音（而非ASR文本），融合视觉信号，进行意图推理、确认交互，并生成动作。
3. 新贡献：相比仅处理文本或ASR文本的方法，RoboOmni能保留语音的副语言线索（情感、身份、语调），并具备主动对话能力。为解决数据匮乏，构建了包含14万集、覆盖6种上下文指令类型的大规模OmniAction数据集。
4. 实验结果：在OmniAction-LIBERO仿真基准上，RoboOmni平均成功率（85.6%）显著超过最强文本基线NORA（25.9%）。在真实WidowX机械臂实验中，成功率（73.9%）超过最佳ASR+VLA基线（52.2%）。消融实验证实了音频、视觉和副语言线索的互补性至关重要（如移除音频，意图识别准确率从88.89%暴跌至11.11%）。具体实验结果对比如下表所示：

| 模型/方法 | OmniAction-LIBERO-TTS 平均成功率 | OmniAction-LIBERO-Real 平均成功率 |
| :--- | :--- | :--- |
| OpenVLA (Ground-truth Text) | 2.6% | - |
| NORA (Audio → ASR → Text) | 25.9% | 17.4% |
| π0 (Ground-truth Text) | 4.4% | 73.8% |
| RoboOmni (Ours) | 85.6% | 76.6% |

![论文中的实验结果对比图](https://nanless.github.io/audio-paper-digest-images/iclr-2026/2026-05-03/OJh7oBCYhL-4.png)
图5内容：该图展示了在真实世界实验中，RoboOmni与ASR+VLA基线在六种上下文指令类型上的成功率对比，RoboOmni在所有类别上均显著领先。

5. 实际意义：为创建更自然、主动、能“察言观色”的服务机器人提供了新的技术路径和基准，推动了机器人从被动执行向主动协作的范式转变。
6. 主要局限性：实验验证的任务复杂度有限，多集中于单次抓取；“主动交互”的质量和效率评估指标尚显简单；模型对长对话历史和高噪声环境的鲁棒性有待进一步验证。

### 🏗️ 模型架构

RoboOmni是一个基于全模态大语言模型的端到端框架，其核心是将所有模态（文本、语音、音频、视觉、动作）统一到共享的token空间进行联合自回归生成。

![RoboOmni整体框架图](https://nanless.github.io/audio-paper-digest-images/iclr-2026/2026-05-03/OJh7oBCYhL-3.png)
图4内容：RoboOmni的Perceiver-Thinker-Talker-Executor架构。视觉和音频信号经编码后，与文本token一同输入LLM核心（Thinker），后者生成文本token（用于对话）、离散动作token（经Executor解码为机器人控制指令）或语音token（经Talker合成语音波形）。

其架构主要包含四个组件：

1.  感知器（Perceiver）：负责多模态输入编码。在每个时间步，它接收一帧图像V_t、一段音频S_t（包含语音和环境声）和对话历史C_t。使用模态特定的编码器（如视觉编码器、音频编码器）将其分别转换为嵌入向量v_t, s_t, c_t，然后拼接成统一的表示X_t = [v_t; s_t; c_t]，送入思考器。该设计使得模型能直接处理原始音频，保留副语言信息。

2.  思考器（Thinker）：核心推理引擎，基于LLM主干网络（如Qwen2.5-Omni）。它接收来自感知器的统一表示X_t，并在联合词汇空间V ∪ A上自回归地生成序列。这个序列可以无缝交织文本token（用于对话）、语音token（用于生成语音）和动作token（用于控制机器人），实现了感知、推理、交互与控制的统一。

3.  对话器（Talker）：语音生成模块。接收来自思考器的离散文本token和高层语义表示，通过分层架构将其转换为语音波形，使机器人能以语音形式回应用户，形成闭环交互。

4.  执行器（Executor）：动作生成模块。思考器会生成一系列离散动作token r_{t:t+N}（使用FAST+分词器，将7维连续动作向量编码为离散符号序列）。执行器负责将这些token解码回连续的动作指令（Δx, Δθ, ΔGrip），控制机器人执行操作。

关键设计选择：该架构最大的特点是端到端和统一token空间。它避免了级联系统中ASR、LLM、VLA之间信息传递的损耗和延迟，使得模型可以在一个自回归过程中同时进行多模态理解、推理和动作生成。

#

### 💡 核心创新点

1.  定义“跨模态上下文指令”新范式：首次系统性地提出并定义了机器人需要从非显式的、多模态上下文（对话语气、环境声音、说话人身份、多人对话等）中主动推断用户意图的场景，超越了传统“直接指令”设置。
2.  提出端到端全模态感知-决策-执行框架（RoboOmni）：与以往ASR+VLA或模块化规划器-控制器系统不同，RoboOmni在一个统一的LLM中直接融合语音、环境音频、视觉和文本，生成对话和动作。这保留了对意图推断至关重要的副语言特征（如情感、说话人身份），并实现了更快的推理速度（图10显示其延迟仅为ASR+OpenVLA的0.49倍）。
3.  构建大规模全模态机器人操作数据集（OmniAction）：为解决新范式下的数据匮乏问题，构建了包含140k集数据、5000+说话人、2400+事件声音、640种背景、6种上下文指令类型的专用数据集。其构建流程（文本脚本化->听觉实现->验证）也具有方法论创新。
4.  实现主动式交互能力：RoboOmni不仅能执行，还能在推断出模糊意图后，通过生成语音主动向用户提问确认（“Would you you me get you a Coke?”），形成了“感知-推理-确认-执行”的完整闭环，这是传统VLA模型所不具备的。

### 🔬 细节详述

- 训练数据：
    - 数据集名称：OmniAction。
    - 来源：基于Open-X Embodiment数据集中的轨迹进行扩展。
    - 规模：141,162个（C，V，A）三元组，覆盖112种技能，748种物体。
    - 预处理与增强：采用三阶段流水线：(1)文本脚本化：使用GPT-4o将原子指令改写为包含6种类型（情感线索、重叠语音、非语言线索、身份线索、双人对话、三人对话）的多轮对话，并扩展交互回应。(2)听觉实现：使用TTS引擎（MOSS-TTSD, CosyVoice, Gemini-TTS）合成语音，模拟多说话人与语音重叠，插入2482种非语言事件和640种环境背景音。(3)验证：人工抽查确保意图可恢复性（98.7%一致率）。
- 损失函数：
    - 采用统一的自回归最大似然目标。对于对话和动作生成，均最小化负对数似然。总损失为两者之和：`L(θ) = L_chat(θ) + L_act(θ)`，在批量内进行交错训练。具体公式见论文第5节（公式3，4，5）。
- 训练策略：
    - 预训练：在OmniAction数据集上进行大规模预训练。使用64张A100 GPU，训练10天（约15360 A100小时），batch size为512，学习率为5e-5，前1k步进行warm-up，共训练10个epoch。
    - 监督微调（SFT）：在下游具体任务（如LIBERO）上微调。使用8张A100 GPU，学习率5e-5，训练1万至3万步。
- 关键超参数：
    - 输入图像分辨率：224x224。
    - 音频采样率：16,000 Hz。
    - 动作块大小（Action Chunk Size）：6。
    - FAST+离散动作token词表大小：2048。
    - 模型主干：基于Qwen2.5-Omni（3B参数版本，文中对比实验使用）。
- 训练硬件：如上所述，预训练64xA100，SFT 8xA100。
- 推理细节：论文未明确说明推理时使用的解码策略（如beam search）。从生成过程看，应为自回归采样或贪心解码。推理延迟在单张RTX 4090 GPU上测量。
- 正则化/稳定训练技巧：论文中未明确提及使用的Dropout、权重衰减等具体技巧。

### 📊 实验结果

论文在仿真和真实世界两个层面进行了全面评估。

1. 仿真评估（OmniAction-LIBERO-TTS）：在包含Spatial, Goal, Object, Long-Horizon四类任务、六种上下文指令类型的基准上，与四款代表性VLA基线（OpenVLA, OpenVLA-OFT, π0, NORA）在“真实文本提示”和“音频→ASR→文本提示”两种设置下对比。结果如下表：

| 任务套件 | Ground-truth Text Prompt (最佳基线) | Audio →ASR →Text Prompt (最佳基线) | RoboOmni (Ours) |
| :--- | :--- | :--- | :--- |
| Spatial (平均) | 49.8% (NORA) | 56.5% (NORA) | 93.0% |
| Goal (平均) | 12.5% (NORA) | 16.3% (NORA) | 85.8% |
| Object (平均) | 7.2% (OpenVLA) | 13.8% (NORA) | 84.0% |
| Long-Horizon (平均) | 32.3% (NORA) | 51.0% (NORA) | 79.5% |
| 总平均 | 16.3% | 25.9% | 85.6% |

表1内容：RoboOmni在所有任务类型和所有上下文指令上均大幅领先基线。尤其在Goal和Object这类模糊性高的任务上优势更为明显。

![论文中的实验结果对比图](https://nanless.github.io/audio-paper-digest-images/iclr-2026/2026-05-03/OJh7oBCYhL-4.png)
图5内容：在真实世界实验中，RoboOmni（73.9%）对比ASR+NORA（52.2%）等基线的成功率，展示了其处理真实语音指令的鲁棒性优势。

2. 真实世界评估（OmniAction-LIBERO-Real & WidowX 250S）：
- 在收集了10名志愿者真实语音指令的仿真变体上，RoboOmni（76.6%）优于π0（73.8%）和NORA（17.4%）。
- 在WidowX 250S机械臂真实部署中，RoboOmni平均成功率73.9%，比最佳ASR+VLA基线（NORA）的52.2%高出21.7个百分点（见图5）。

3. 主动辅助能力评估：
- 意图识别：在特定测试集上，RoboOmni准确率达88.89%，高于ASR+GPT-4o（55.56%）和Qwen2.5-Omni基线（见图7a）。
- 交互能力定性评估：图7b展示了RoboOmni能进行多轮主动提问澄清（如“Would you like me to put the egg dumpling into the hot pot?”），而其他模型要么直接错误执行，要么无法利用上下文。

4. 消融实验：
- 输入组件消融：移除视觉、音频或副语言线索后，意图识别准确率分别下降至58.89%、11.11%和50.56%，证明各模态互补性（见表3）。
- 预训练效率：使用OmniAction预训练后微调，模型在2000步内即可达到近90%准确率，而从头训练在30000步后仍只有约30%（见图8）。
- 架构对比：将RoboOmni与“Qwen2.5-Omni作为规划器 + 文本VLA作为控制器”的级联流水线对比，RoboOmni在所有上下文指令类型上均优于后者（见图9）。

![论文中的推理延迟对比图](https://nanless.github.io/audio-paper-digest-images/iclr-2026/2026-05-03/OJh7oBCYhL-9.jpg)
图10内容：RoboOmni的单次推理延迟（0.49x）约为ASR+OpenVLA（1.00x）的一半，证明了端到端模型在效率上的优势。

![论文中的失败分析图](https://nanless.github.io/audio-paper-digest-images/iclr-2026/2026-05-03/OJh7oBCYhL-0.png)
