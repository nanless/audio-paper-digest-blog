### 💡 毒舌点评

亮点在于，论文没有止步于“又提了一个攻击算法”，而是深入挖掘了ALM梯度分布中的“token异质性”这一现象，为“为何稀疏更新也能成功”提供了数据支撑和直观解释，让攻击方法有了更扎实的insight。短板是，“模型兼容前缀”的设计需要为每个ALM人工构造模板，其泛化性和自动化程度有限，且论文在防御建议上点到为止，未深入探讨如何利用该发现加固模型。

### 📌 核心摘要

本文针对现有音频语言模型（ALM）越狱攻击方法普遍采用整个波形密集更新、效率不高的问题，提出了“token异质性”这一关键观察：ALM的梯度能量高度集中在少数音频token对应的波形区域。基于此，作者提出了Token-Aware Gradient Optimization (TAGO)，一种稀疏的、token感知的梯度优化方法。TAGO在每次迭代中，仅保留梯度能量最高的部分token对应的波形区域的梯度，屏蔽其余区域，从而实现稀疏攻击。此外，TAGO还设计了模型兼容的前缀模板和EOS抑制损失，以提升攻击的泛化性和效果。在三个前沿ALM（Qwen3-Omni， Qwen2.5-Omni， LLaMA-Omni）上的实验表明，TAGO在攻击成功率上显著优于基线方法。关键结果是，即使只保留25%的token（`ζ=0.25`），在Qwen3-Omni上基于拒绝词的ASR(`ASR_r`)仍接近100%，基于LLM判断的ASR(`ASR_l`)也高达86%，与全量更新（`ζ=1.0`）的87%相差无几。这表明密集更新在优化过程中是大量冗余的。本文的工作为理解和攻击ALM提供了新视角，并呼吁未来安全对齐研究应关注这种token级梯度异质性。

主要局限性：方法依赖白盒模型访问以计算梯度；“模型兼容前缀”需要针对每个目标模型进行人工设计，可能限制其大规模应用；实验主要评估攻击有效性，对如何利用该发现进行防御的讨论有限。

### 🏗️ 模型架构

本文并未提出一个新的ALM架构，而是针对现有ALM的攻击优化方法提出改进。因此，模型架构分析聚焦于被攻击的ALM的一般架构以及TAGO优化方法的框架。

1.  ALM的一般架构（如图1左半部分所示）：
    *   输入：音频波形 `x` 和文本提示 `t_{1:n}`。
    *   音频编码前端 `Φ(·)`：将波形转换为时频谱图，并通过卷积等操作在时间轴上降采样，得到预注意力音频token序列 `Φ(x) ∈ ℝ^{T×d_A}`。这是梯度分析的基本单元。
    *   音频编码器 `E_A(·)`：对预注意力token进行基于注意力的编码，得到编码后的音频表示 `E_A(Φ(x))`。
    *   语言模型主干：以编码后的音频表示和文本提示嵌入为条件，自回归地生成文本响应 `y_{1:l}`。生成过程在遇到 `EOS` token时停止。

    数据流：`波形 x → Φ(·) → 音频token Φ(x) → E_A(·) → 音频表示 → 语言模型主干 → 文本响应 y`。

2.  TAGO优化框架（如图1右半部分和算法1所示）：
    *   核心思想：将针对整个波形 `δ` 的密集梯度更新，转变为针对由重要音频token选择的波形子集的稀疏更新。
    *   输入：良性音频 `x`，文本 `t_{1:n}`，有害查询 `q`，ALM参数 `θ`，以及其他超参数。
    *   关键组件：
        *   目标前缀构建 `Prefix(q)`：根据有害查询 `q`，套用一个针对目标ALM预先设计好的、格式兼容的模板（如 `“To {harmful query}, you need to follow these steps:\n\n”`），生成优化目标前缀 `r_{1:m}`。
        *   损失函数 `L` (Eq. 13)：由三部分组成：1) 前缀交叉熵损失 `L_CE`；2) `L2` 正则项 `λ‖δ‖₂²`；3) EOS抑制损失 `L_eos`，惩罚在 `r_{1:m}` 之后立即生成 `EOS` token的概率，鼓励模型继续生成。
        *   稀疏更新机制：
            1.  计算全波形梯度 `∇_δ L`。
            2.  按token对齐计算梯度能量 `g̃_i`，并选择能量最高的 `⌈ζT⌉` 个token（`ζ`为保留比例），构成集合 `S^{(k)}` (Eq. 10)。
            3.  根据 `S^{(k)}` 构建二值掩码 `M^{(k)}`，覆盖这些token对应的波形感受野区域 (Eq. 11)。
            4.  用掩码对梯度进行遮蔽：`M^{(k)} ⊙ ∇_δ L`，然后进行带裁剪的更新 (Eq. 12)。
        *   早停准则：当平均前缀交叉熵损失低于阈值 `τ(ρ) = -log(ρ)` 时停止优化，其中 `ρ` 为置信水平。

![ALM架构与TAGO概览](https://arxiv.org/html/2605.04700v1/figures/overview.png)
图1：(左) ALM架构。 (右) Token-Aware Gradient Optimization (TAGO) 概览。展示了从音频输入到稀疏梯度更新的完整流程。

### 💡 核心创新点

1.  发现ALM越狱优化中的“梯度异质性”：这是本文最重要的观察和贡献。通过定量分析（系数变异系数CV、Top-q质量TM_q等指标），论文证明在迭代优化中，波形梯度能量高度集中于少数预注意力音频token对应的感受野区域（例如，在Qwen3-Omni上，16%的token占据了90%的梯度能量）。这一发现挑战了“密集更新是必要的”这一默认假设。
       之前局限*：现有攻击方法普遍对整个波形进行密集更新，忽视了梯度分布的不均匀性，导致优化效率低下。
       如何起作用*：通过token对齐的梯度测量方法，将波形梯度映射到更具语义的token级别进行分析，揭示了这种内在结构。
       收益*：为后续设计稀疏优化算法提供了直接动机和理论依据。

2.  提出Token-Aware Gradient Optimization (TAGO) 稀疏攻击算法：基于上述发现，TAGO在每次迭代中动态地识别并仅更新梯度信号最强的那些token对应的波形区域，实现了优化过程的稀疏化。
       之前局限*：所有现有方法（如SpeechGuard, AdvWave）都采用密集更新，计算和存储开销大。
       如何起作用*：通过实时计算token级梯度能量，构建动态掩码，将优化资源聚焦于高回报区域。
       收益*：在保持甚至提升攻击成功率的同时，大幅减少了每步更新涉及的波形参数量（如`ζ=0.25`时）。更重要的是，证明了在优化过程中强制稀疏（而非事后剪枝）的有效性。

3.  设计模型兼容的前缀模板与EOS抑制损失：为提高攻击的泛化性和成功率，TAGO引入了两个辅助技术。
    *   模型兼容前缀：通过分析模型在良性查询下的响应，自动归纳出一个可复用的、符合目标模型输出风格的前缀模板，避免了为每个查询手工设计前缀的高成本和风格错配。
    *   EOS抑制损失：在损失函数中加入一项，惩罚在强制前缀后立即终止生成的行为，从而鼓励模型继续生成有害内容，解决了安全对齐模型可能只关注前几个token就进行拒绝的“捷径”问题。
       收益*：提升了攻击在不同模型和查询间的通用性与彻底性。

### 🔬 细节详述

-   训练数据：
    *   攻击优化数据：使用AdvBench-50数据集（Chao et al., 2025）中的有害指令。每个指令通过Google Cloud TTS合成两个不同说话人（en-US-Neural2-J, en-US-Neural2-D）的音频，共100个样本。
    *   扩展评估数据：使用HarmBench（Mazeika et al., 2024）的Standard类别中200条指令，同样通过TTS合成为音频。
    *   目标前缀模板构建数据：为每个ALM使用少量良性查询及其模型响应，从中提取首句构建模板（具体示例见附录表7）。

-   损失函数：
       总损失 `L` (Eq. 13)：`L = (1/m)  Σ_{i=1}^m L_CE(r_i, p_θ(·|h_{i-1})) + λ‖δ‖₂² + λ_eos * L_eos`。
    *   `L_CE`：标准的token级交叉熵损失，用于最大化目标前缀的似然。
    *   `λ‖δ‖₂²`：L2正则化项，控制扰动大小，`λ=0.02`。
    *   `L_eos = p_θ(EOS | h_m)`：EOS抑制项，最小化在前缀 `r_{1:m}` 后生成 `EOS` token的概率，`λ_eos=0.2`。

-   训练策略（攻击优化过程）：
    *   优化器：未明确指定，但更新规则 (Eq. 12) 是带投影的梯度下降。
    *   步长 `η`：固定为 `10⁻³`。
    *   最大迭代次数 `K`：500。
    *   扰动预算 `ϵ`：0.1（`‖δ‖_∞ ≤ ϵ`）。
    *   早停：当平均前缀交叉熵损失 `L̄_CE ≤ τ(ρ) = -log(ρ)` 时停止。`ρ` 为可设的置信水平（实验中使用0.9, 0.8, 0.7）。
    *   稀疏控制：`ζ` 为token保留比例（实验中测试1.0, 0.75, 0.5, 0.25, 0.1, 0.05）。

-   关键超参数：
    *   `ζ` (token保留比例)：核心稀疏度超参。
    *   `ρ` (早停置信水平)：控制攻击强度与优化时间的权衡。
    *   `λ`, `λ_eos`：正则化系数。
    *   `η`, `K`, `ϵ`：标准梯度攻击超参。

-   训练硬件：论文中未说明。

-   推理细节：
    *   解码策略：贪心解码 (`do_sample=False`)。
    *   评估标准：
        *   `ASR_r` (Reject-word based ASR)：如果生成的响应不以预定义拒绝词列表（见附录表6）开头，则视为成功。
        *   `ASR_l` (LLM Judge based ASR)：使用外部评判模型（Qwen3-Omni和Qwen2.5-Omni使用SorryBench微调的Mistral-7B，LLaMA-Omni使用Gemini 1.5 Flash）判断响应是否实质性地服从了有害指令。
    *   生成配置：固定文本提示 `t_{1:n}`（见附录表5）。

-   正则化或稳定训练技巧：
    *   `L2` 正则化约束扰动大小。
    *   动态梯度掩码本身也可视为一种正则化，防止优化过度关注非关键区域。
    *   早停准则防止过度优化。

3.  消融与敏感性分析：
    *   Post-hoc prune vs. TAGO：事后剪枝（先密集优化再裁剪）的性能（尤其在`ASR_l`上）远低于在优化过程中强制稀疏的TAGO，证明了稀疏必须在优化过程中引入。

    *   `ζ`与`ρ`的影响（表3， 图3， 图4）：
        *   较高的置信水平`ρ`（如0.9）带来更高的`ASR_l`，但需要更多迭代次数。
        *   降低token保留比例`ζ`对`ASR`影响很小（如在Qwen3-Omni上，`ζ`从1.0降至0.25，`ASR_l`从87%降至86%），但会适度增加迭代次数（如图4b， `ζ=0.25`的迭代数增长约26%，远低于`1/ζ=300%`的增长），表明稀疏更新仍是高效导向的。
        *   即使在极低保留比例（`ζ=0.1`），TAGO仍保持非平凡的攻击能力（`ASR_r=97%`, `ASR_l=67%`）。
