## 补充信息

- [模型架构] 补充：论文在附录D中提供了TAGO方法能工作的理论分析。其核心是提出了“γ-集中度假设”（Assumption D.2），假设在每次迭代中，被掩码保留的梯度能量占总梯度能量的比例存在一个下界γ_k。基于此假设和损失函数的局部L-光滑性，论文推导出了定理D.3，证明了TAGO的每一步更新都能保证损失函数下降，下降幅度与保留的梯度能量成正比。这为稀疏更新的有效性提供了初步的理论依据，而不仅仅是经验观察。

- [细节详述] 补充：论文在附录E证明了其早停策略的理论合理性。具体来说，当优化在平均前缀交叉熵损失 \(\overline{\mathcal{L}}_{\text{CE}} \leq \tau = -\log \rho\) 时停止，这蕴含了在教师强制下，模型生成目标前缀 \(r_{1:m}\) 的概率下界为 \(\rho^m\)（命题E.1）。这为通过早停阈值τ控制攻击置信度提供了概率解释。

- [实验结果] 补充：论文在图4中展示了在Qwen3-Omni上更宽范围的token保留比例 \(\zeta \in \{1.0, 0.75, 0.5, 0.25, 0.1, 0.05\}\) 的扩展评估结果。具体数据显示，即使在极端稀疏的情况下（\(\zeta=0.1\)），TAGO仍能取得 \(\text{ASR}_r=97\%\) 和 \(\text{ASR}_l=67\%\) 的成功率；在 \(\zeta=0.05\) 时，成功率进一步下降至 \(\text{ASR}_r=76\%\) 和 \(\text{ASR}_l=38\%\)。这部分结果展示了该方法在极端稀疏度下的性能边界。

- [论文自我声明的局限性] 补充：论文在结论部分明确指出的局限性是，其构造的模型兼容前缀模板可能无法完美匹配每一个有害查询，并提出了未来可探索基于隐藏状态可解释性来设计自适应目标的改进方向。

### 📌 核心摘要

1. 要解决什么问题：现有的针对音频语言模型（ALM）的越狱攻击方法通常对整个音频波形进行密集的梯度优化，这在高维音频空间中效率低下且可能存在大量冗余计算。
2. 方法核心是什么：本文提出“Token-Aware Gradient Optimization”（TAGO）。其核心发现是，ALM越狱优化的梯度能量在由音频编码器产生的“音频token”上分布极不均匀，少数token承载了绝大部分梯度信号。TAGO利用这一特性，在每次迭代中，仅选择梯度能量最高的前ζ比例音频token，仅更新这些token对应波形区域的扰动，从而实现稀疏、高效的攻击优化。此外，方法还包括构造模型兼容的目标响应前缀和抑制EOS token的早停。
3. 与已有方法相比新在哪里：区别于以往“更新全部波形”的密集优化（如SpeechGuard）或仅优化后缀的方法（如AdvWave），TAGO首次从token粒度分析并利用了优化信号的异质性，实现了迭代过程中的动态、稀疏波形更新。
4. 主要实验结果如何：在三个SOTA ALM（Qwen3-Omni， Qwen2.5-Omni， LLaMA-Omni）上，TAGO显著优于所有基线。例如，在Qwen3-Omni上，当token保留比例ζ=0.25时，攻击成功率（ASRl）仍高达86%，仅比全量更新（ζ=1.0）的87%下降1个百分点。同时，后验剪枝方法（Post-hoc prune）效果远差于训练中稀疏化的TAGO，证明了在优化过程中动态施加稀疏性的必要性。关键结果见下表：

| 方法 | Qwen3-Omni (ASRr/ASRl) | Qwen2.5-Omni (ASRr/ASRl) | LLaMA-Omni (ASRr/ASRl) |
| :--- | :--- | :--- | :--- |
| SpeechGuard | 100% / 42% | 94% / 49% | 100% / 34% |
| AdvWave | 70% / 45% | 36% / 4% | 100% / 68% |
| TAGO (ζ=1.0) | 100% / 87% | 100% / 65% | 100% / 71% |
| TAGO (ζ=0.25) | 99% / 86% | 97% / 53% | 100% / 72% |

5. 实际意义是什么：这项研究揭示了当前ALM安全对齐可能存在的一个弱点：模型的防御响应可能过度依赖于音频输入的特定局部区域。这为攻击者提供了更高效的攻击路径，同时也警示防御者需要关注并加固这些关键区域。此外，发现的梯度稀疏性对优化其他音频生成任务可能具有启示。
6. 主要局限性是什么：攻击基于白盒假设，需要模型梯度，这在现实中并非总是可用。论文也承认，其构造的固定前缀模板可能无法完美匹配所有有害查询，未来可探索更自适应的目标。此外，攻击的最终效果仍依赖于模型本身的安全对齐强度（如LLaMA-Omni明显弱于Qwen系列）。

### 🏗️ 模型架构

TAGO并非一个独立的生成模型，而是一种针对现有ALM进行越狱攻击的优化算法。其完整流程如下：
![TAGO方法概览](https://arxiv.org/html/2605.04700v1/figures/overview.png)
图1：TAGO方法概览与ALM架构示意图。
- 输入：良性音频波形 \(x\)，文本提示 \(t_{1:n}\)，有害查询 \(q\)。
- 核心组件与流程：
    1.  模型兼容前缀构造：通过少量良性查询获取ALM的典型响应开头，构造一个模板化的前缀 \(r_{1:m}\)（如对Qwen3-Omni为“To {有害查询}, you need to follow these steps:\n\n”），用于后续优化目标。
    2.  迭代稀疏优化（算法1核心）：
        - 梯度计算：计算损失函数 \(\mathcal{L}\) 对当前扰动 \(\delta^{(k)}\) 的梯度 \(\nabla_\delta \mathcal{L}\)。损失包含三部分：(1) 使响应以目标前缀开始的交叉熵损失；(2) L2扰动正则化；(3) EOS抑制损失（防止模型在输出前缀后立即停止）。
        - Token对齐梯度能量计算：根据ALM音频编码器前端 \(\Phi(\cdot)\) 的结构，将波形梯度按“音频token”的感受野 \(\mathcal{R}(i)\) 进行聚合，得到每个音频token的梯度能量 \(\tilde{g}_i^{(k)}\)。
        - 稀疏Token选择：根据token梯度能量，选择能量最高的前 \(\lceil \zeta T \rceil\) 个token，构成集合 \(\mathcal{S}^{(k)}\)。
        - 掩码生成与稀疏更新：生成一个二值掩码 \(M^{(k)}\)，仅在 \(\mathcal{S}^{(k)}\) 中token对应的感受野区域为1，其余为0。将全量梯度与 \(M^{(k)}\) 逐元素相乘，实现稀疏更新：\(\delta^{(k+1)} \leftarrow \text{Clip}(\delta^{(k)} - \eta (M^{(k)} \odot \nabla_\delta \mathcal{L}))\)。
- 输出：优化后的对抗性音频 \(x+\delta\)，用于诱导ALM产生违规响应。

关键设计选择及其动机：
- 基于“预注意力音频token”进行分析：选择在音频编码器自混合信息之前的中间表示（\(\Phi(x)\)）进行分析，是为了保持梯度信号与时间局部区域的对应关系，便于可解释的token级操作。
- 迭代动态掩码：而非一次性确定重要区域，因为梯度的重要性在优化过程中会发生变化。图2的热力图展示了高能量token的动态漂移。
- EOS抑制：动机是防止模型在被迫输出前缀后立即终止，从而鼓励其继续生成违规内容，提高攻击的“深度”。

### 💡 核心创新点

1.  发现并量化ALM越狱优化中的Token级梯度异质性：这是全文的基石。作者通过实验（表1， 图6， 7， 9-14）系统证明了，无论是累积梯度还是最终迭代的梯度，其能量都高度集中在少数音频token上。例如，在Qwen3-Omni上，仅16%的token就占据了90%的梯度能量。这一发现挑战了“必须密集更新波形”的传统假设。
2.  提出Token-Aware Gradient Optimization (TAGO)：基于上述发现，设计了在优化过程中动态、稀疏地更新波形的方法。其创新在于将优化粒度从波形样本点提升到具有语义和结构意义的“音频token”，并利用梯度的异质性实现高效攻击。这是方法论上的直接创新。
3.  构建模型兼容的前缀模板与EOS抑制机制：为了提升攻击的通用性和成功率，TAGO没有使用固定前缀，而是为每个ALM定制响应模板（表7），并增加了EOS抑制损失。这使得攻击目标更贴近模型原生行为，是提升方法实用性的工程创新。

### 🔬 细节详述

- 训练数据：
    - 攻击目标查询：AdvBench-50（50条有害指令）和HarmBench（200条有害指令）。每条查询通过Google Cloud TTS合成为两个不同说话人的音频。
    - 前缀模板构造：每个ALM使用3条良性查询及对应模型响应。
- 损失函数：如公式(13)所示：\(\mathcal{L} = \frac{1}{m}\sum_{i=1}^{m}\mathcal{L}_{\text{CE}}(r_i, p_\theta(\cdot|h_{i-1})) + \lambda\|\delta\|_2^2 + \lambda_{\text{eos}}\mathcal{L}_{\text{eos}}\)。
    - \(\mathcal{L}_{\text{CE}}\)：标准交叉熵损失，用于强迫模型输出目标前缀 \(r_{1:m}\)。
    - \(\lambda\|\delta\|_2^2\)：L2正则项，控制扰动大小。\(\lambda=0.02\)。
    - \(\lambda_{\text{eos}}\mathcal{L}_{\text{eos}}\)：EOS抑制项，\(\mathcal{L}_{\text{eos}} = p_\theta(\text{EOS}|h_m)\)，即目标前缀输出后，下一个token为EOS的概率。\(\lambda_{\text{eos}}=0.2\)。
- 训练策略（优化策略）：
    - 优化器：梯度下降（标准SGD变体），未使用Adam等自适应优化器。
    - 学习率（步长）：\(\eta = 10^{-3}\)。
    - 最大迭代次数：\(K=500\)。
    - 扰动预算：\(\|\delta\|_\infty \leq \epsilon = 0.1\)。
    - 早停：当前缀交叉熵损失 \(\overline{\mathcal{L}}_{\text{CE}} \leq \tau(\rho) = -\log(\rho)\) 时停止，\(\rho\) 为目标置信度（0.7， 0.8， 0.9）。
- 关键超参数：
    - Token保留比例 \(\zeta\)：{1.0, 0.75, 0.5, 0.25, 0.1, 0.05}。
    - 早停置信度 \(\rho\)：{0.9, 0.8, 0.7}。
- 训练硬件：论文中未说明。
- 推理细节：
    - 解码策略：贪心解码（greedy）。
    - 文本提示：每个ALM有固定的默认对话模板（表5）。
- 评估指标：
    - \(\text{ASR}_r\)：基于拒绝词列表的成功率。响应开头不含列表中的拒绝短语即为成功。
    - \(\text{ASR}_l\)：基于LLM Judge的成功率。使用专门的Mistral-7B模型（SorryBench Judge）或Gemini 3 Flash进行判断。
- 正则化/稳定技巧：梯度裁剪（\(\text{Clip}_{[-\epsilon, \epsilon]}\)），L2扰动正则化。
