### 📌 核心摘要

本文旨在解决当前主流的有监督语义语音分词器在噪声环境下输出序列不稳定（脆弱性）的关键问题，这种不稳定会严重损害下游语音大模型的性能。为解决该问题，论文提出了StableToken，其核心是多分支投票-LFQ模块与噪声感知共识训练策略。该方法通过多个并行分支处理输入，并在位级进行多数投票以产生稳定的共识token，从而在架构上内置了容错能力；同时，通过让少数分支处理加噪声版本，多数分支处理干净版本，并利用共识损失迫使它们对齐，从而显式训练模型学习噪声不变性。与现有最强的S3分词器相比，StableToken将平均单元编辑距离（UED）从26.17%大幅降低至10.17%，相对改进超过60%，在各类合成及真实噪声下均取得了新的最佳性能。这一改进直接转化为下游任务的鲁棒性提升：在抗噪ASR中，其WER相比基线在低信噪比下降低超过30%；在语音情感识别中，其准确率在噪声下下降更慢；在语音合成中，也取得了更低的WER和相当的MOS分数。论文的主要贡献是首次系统性地揭示了现有语义分词器的脆弱性根源，并提出了一个在架构和训练上协同设计的、高效（推理开销可忽略）的鲁棒分词器。其局限性可能包括训练流程相对复杂，以及大词表可能带来的潜在挑战。

### 🏗️ 模型架构

StableToken的整体架构旨在增强量化过程的鲁棒性，其核心是插入在预训练语音编码器（基于Whisper-large-v3）中间的Voting-LFQ模块。

1.  输入处理：输入语音波形首先由语音编码器处理，得到一系列隐藏状态。这些状态经过平均池化下采样，得到每个时间步的紧凑表示 `h ∈ R^D`。
2.  多分支并行投影：表示 `h` 被送入 `n` 个独立的线性投影层（分支），每个分支 `i` 生成一个投影向量 `pi ∈ R^d`：
    `pi = Wi * h + bi`，其中 `Wi` 和 `bi` 是分支独有的可学习参数。
3.  二值化：每个投影向量 `pi` 通过符号函数（sign）被二值化为 `Bi ∈ {-1, +1}^d`。训练时通过直通估计器（STE）回传梯度。
4.  位级共识投票：
    - 训练时：计算所有分支在每个比特位 `j` 上的平均值得分 `(sfinal)j`。这个连续值反映了该位的共识置信度。
    - 推理时：对平均得分 `(sfinal)j` 再次应用符号函数，得到最终的共识二值向量 `Bfinal`。通过选择奇数个分支 `n`，确保严格的多数投票规则。
5.  Token生成：将 `Bfinal` 中的 `-1` 和 `+1` 映射为 `0` 和 `1`，视为一个二进制数，确定性地映射到一个整数索引 `k ∈ [0, 2^d - 1]`，即最终的鲁棒语音token。

![架构图](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/17DNmdQ9aU-1.png)
图2展示了StableToken的整体架构。标准的单路径量化器被多分支Voting-LFQ模块取代。放大的视图显示了n个并行分支生成独立的二进制表示，然后通过位级多数投票聚合为一个最终token。图中还说明了在“噪声感知共识训练”过程中，随机选择少数分支接收扰动输入，多数分支接收干净输入，共识损失迫使扰动分支与共识对齐。黄色路径仅在训练时使用。

关键设计动机：传统的单路径量化器是脆弱的，输入微小扰动靠近量化边界时，输出token会发生跳变。多分支投票机制通过引入冗余和集成，使得最终决策依赖于多个独立视角的共识，从而极大地提高了对单个分支（可能受噪声影响）错误的容忍度。这种设计在推理时额外开销极小，因为投影层轻量且可并行执行。

### 💡 核心创新点

1.  位级（Bit-wise）共识投票机制：这是本工作最核心的创新。与传统的词级（Token-level）多数投票或集成方法不同，StableToken在更细粒度的比特位进行投票。这带来了两个关键优势：(a) 在训练时提供了更丰富、连续的监督信号；(b) 在推理时具有强大的纠错能力，即使多数分支在“词”级别产生了错误token，只要其底层比特位的错误是稀疏且分散的，仍有可能通过投票恢复出正确的token。
2.  噪声感知共识训练策略：该训练方法与多分支架构协同设计，旨在显式地灌输表示不变性。它创造了一个“内部对抗”场景：让一部分分支处理干净音频，另一部分处理加噪音频，然后通过共识损失（L2损失）迫使所有分支（包括处理噪声的分支）的中间表示向全局平均（由干净分支主导）对齐。这使得模型学会了忽略与语义无关的声学扰动。
3.  架构与训练的协同设计：多分支架构为噪声感知训练提供了必要的结构基础（多个分支可以接受不同输入），而噪声感知训练则释放了多分支架构在表示学习上的潜力，使其生成的各个分支的表示本身就具有噪声不变性，从而在投票前就提高了整体系统的鲁棒性。

### 🔬 细节详述

- 训练数据：StableToken在约150,000小时的多样化语音语料库上预训练，包括开源数据集（如LibriSpeech、GigaSpeech、Emilia、AISHELL-1等）和内部数据。详细列表见论文附录B.1。
- 损失函数：总损失为加权和：`L_total = L_ASR + λ1  L_consensus + λ2  L_commitment + λ3 * L_codebook`。
    - `L_ASR`：标准ASR交叉熵损失，监督转录文本。
    - `L_consensus`：共识损失，L2范数，惩罚每个分支的预量化向量 `pi` 与所有分支平均值 `pall` 的偏差。权重 `λ1 = 0.25`。
    - `L_commitment` 和 `L_codebook`：来自LFQ框架的正则化损失，分别鼓励隐藏状态接近量化表示和码本均匀使用。权重 `λ2 = 0.25`, `λ3 = 1.0`。
- 训练策略：
    - 优化器：AdamW，学习率调度器OneCycleLR，最大学习率 `1.5e-5`，预热步数1000，权重衰减0.01。
    - 数据增强（噪声注入）：训练时，在音频波形级随机应用五种增强之一：高斯噪声、粉噪、褐噪、比特压碎、真实噪声，强度在特定范围内随机采样（见附录表9）。对于多分支训练，每次前向传播中，随机选择 `k` 个分支（`k < n/2`，本研究 `n=5, k=2`）接收增强后的音频表示，其余 `n-k` 个分支接收干净表示。
- 关键超参数：
    - 模型基于Whisper-large-v3编码器初始化。
    - 词表大小：8192（对应 `d=13` 位）。
    - 帧率：25Hz。
    - 投票者数量 `n=5`（经实验确定为最佳平衡点）。
- 训练硬件：未在正文中明确说明具体GPU型号和训练时长，但在附录B.6中提到了用于推理效率评估的硬件（NVIDIA H20 GPU和AMD EPYC 9K84 CPU）。
- 推理细节：对于超过30秒的长音频，采用标准的分块处理策略，每块独立处理后拼接token序列。分析表明，块边界的token稳定性与中部区域一致（见附录B.8）。

### 📊 实验结果

1. 分词器层面性能：
- 噪声鲁棒性：在FLEURS数据集上，对合成噪声（高斯、粉噪、褐噪、比特压碎）和真实噪声（包括分布外噪声）进行评估。结果如表1所示，StableToken的平均UED为10.17%，远低于最佳监督基线S3 Tokenizer的26.17%和最佳SSL基线R-Spin的16.48%。

| 模型类型 | 模型名称 | 平均UED% ↓ |
| :--- | :--- | :--- |
| SSL语义分词器 | R-Spin | 16.48 |
| 语义蒸馏分词器 | SpeechTokenizer (8层) | 62.07 |
| 有监督语义分词器 | S3 Tokenizer | 26.17 |
| | CosyVoice2 | 38.66 |
| | StableToken (Ours) | 10.17 |

表1：不同语义分词器的噪声鲁棒性对比（平均单元编辑距离 UED% ↓）。StableToken在所有噪声条件下均大幅领先。

- 重建质量：在LibriSpeech和SEED数据集上，训练流匹配模型从token重建音频。如表2所示，StableToken在WER和MOS上均达到最优或具有竞争力，证明了鲁棒性提升并未牺牲重建保真度。

| 模型 | WER ↓ (LS-clean) | WER ↓ (LS-other) | MOS ↑ (LS-clean) | MOS ↑ (LS-other) |
| :--- | :--- | :--- | :--- | :--- |
| GLM-4-Voice | 4.04 | 9.33 | 4.07 | 3.99 |
| S3 Tokenizer | 5.78 | 13.38 | 3.40 | 3.31 |
| CosyVoice2 | 4.25 | 9.68 | 3.36 | 3.25 |
| StableToken | 3.84 | 7.99 | 4.09 | 3.83 |

表2：音频重建质量对比。StableToken在准确性和自然度上均表现优异。

2. 下游SpeechLLM性能：
- ASR（抗噪语音识别）：在合成/真实噪声下的LibriSpeech和CHiME-4数据集上评估。图3（上半部分）显示，在所有噪声条件和SNR下，基于StableToken的模型WER均低于基线，且随着噪声加剧，优势更明显。在CHiME-4 test-real集上（表3），StableToken的WER为35.90%，相对次优基线（GLM-4-Voice的51.08%）降低约30%。
- SER（抗噪语音情感识别）：在加噪的ESD数据集上评估。图3（下半部分）显示，基于StableToken的模型在各噪声水平下的分类准确率均显著高于基线，表明其能更好地从噪声中提取情感线索。
- TTS（语音合成）：在SEED-TTS基准上评估。表3显示，StableToken模型生成的语音在英文（WER 4.43%）和中文（WER 3.02%）上的字错误率均大幅低于基线，同时MOS分数具有竞争力或更高。
