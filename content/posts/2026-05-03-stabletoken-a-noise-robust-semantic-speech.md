### 📌 核心摘要

1.  问题：现有的监督式语义语音分词器虽然能提取语义信息，但对与语义无关的声学扰动（噪声）异常脆弱。即使在人耳听来清晰的语音中，微小的噪声也会导致分词器输出的离散令牌序列发生剧烈变化，这给下游的大语言模型带来了巨大的学习负担。
2.  方法核心：提出StableToken，一种基于共识机制的抗噪分词器。其核心是Voting-LFQ模块，采用多分支（n=5）并行处理音频，并在比特位级别进行多数投票来生成最终稳定的令牌。训练时，采用噪声感知共识训练策略：让部分分支处理带噪语音，其他分支处理干净语音，并通过共识损失强制所有分支的输出对齐，从而学习对噪声不变的表示。
3.  创新点：与传统的单路径量化架构相比，该工作实现了架构与训练策略的协同设计。多分支投票机制提供了细粒度的错误纠正能力；噪声感知训练则为这一架构提供了针对性的监督信号，使其能显式学习噪声不变性。
4.  主要实验结果：在噪声鲁棒性上达到SOTA，平均单元编辑距离（UED）从最佳基线的26.17%降至10.17%，相对降低超60%。同时保持了顶尖的语音重建质量。下游验证显示，基于StableToken的语音大模型在ASR、SER、TTS任务上，尤其在强噪声环境下，性能显著优于基线。例如，在0dB信噪比的真实域外噪声下，ASR的WER相对降低了30%以上。
5.  实际意义：为构建更健壮、更实用的端到端语音大模型奠定了坚实基础。一个稳定的语义分词器能简化下游模型的学习，提升其在实际噪声环境中的性能。
6.  主要局限性：验证场景虽然多样，但仍以合成噪声和可控的真实噪声为主；对于更极端的非平稳噪声、多说话人场景等的泛化能力有待进一步验证。此外，模型依赖于预训练的Whisper编码器，其性能上限可能受限于骨干网络。

### 🏗️ 模型架构

StableToken的整体架构遵循“预训练编码器-分词器”的范式，但对分词器部分进行了根本性重构。

整体输入输出流程：
1.  输入：原始语音波形。
2.  编码：由预训练的Whisper-large-v3编码器处理，得到一系列中间隐藏状态。
3.  下采样：通过平均池化，将隐藏状态序列下采样，每个时间步得到一个紧凑的向量 `h ∈ R^D`。
4.  量化：`h` 被送入核心的Voting-LFQ模块进行量化，最终输出一个稳定的离散令牌 `k`。
5.  输出：对于整段语音，输出是一个离散令牌序列。

核心组件：Voting-LFQ模块
该模块是稳定性的关键，其结构如下：
1.  多分支投影：输入向量 `h` 通过 `n` 个独立的线性投影层（`n=5`），得到 `n` 个不同的投影向量 `p_i ∈ R^d`。每个分支拥有独立的参数 `W_i` 和 `b_i`。
    *   `p_i = W_i h + b_i`
2.  二值化：每个投影向量 `p_i` 通过符号函数（sign function）被二值化为 `B_i ∈ {-1, +1}^d`。训练时使用直通估计器（STE）来传播梯度。
    *   `B_i = sign(p_i)`
3.  位级投票（训练阶段）：为了提供平滑的监督信号，对 `n` 个二值向量 `B_i` 在每一维（比特位）上进行平均，得到连续的软投票分数向量 `s_final`。
       `(s_final)_j = (1/n)  Σ_{i=1 to n} (B_i)_j`
4.  最终令牌生成（推理阶段）：对软投票分数 `s_final` 取符号，得到最终的共识二值向量 `B_final`。
    *   `(B_final)_j = sign((s_final)_j)`
    *   `B_final` 中的-1和+1被映射为0和1，构成一个二进制数，从而确定性地映射到一个整数索引 `k ∈ {0, ..., 2^d-1}`，即最终的语音令牌。

![图2：StableToken的架构图。左侧展示了从输入到Speech Tokens的整体流程。右侧放大展示了Voting-LFQ模块的内部结构：多个并行分支（Branch 1, 2, ..., n）对编码器隐藏状态进行处理，生成独立的二值表示，然后通过“Bit-wise Self-voting”（位级自投票）机制聚合为单一令牌。图中还区分了训练（Training）和推理（Inference）阶段的不同数据流：训练时，扰动输入仅被送入随机选择的少数分支（k个），而干净输入被送入其余分支。](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/17DNmdQ9aU-1.png)

关键设计选择与动机：
*   多分支冗余：通过多个独立的视角（分支）处理同一输入，构建容错能力。
*   位级投票而非令牌级投票：这是核心创新。即使多数分支在令牌级别预测错误，只要其内部多数比特位是正确的，最终仍能通过位级多数决恢复正确的令牌。这极大提升了鲁棒性。
*   使用Lookup-Free Quantization (LFQ)：无需维护和查询传统的码本，使架构更简洁，且便于在比特位层面进行操作。

### 💡 核心创新点

1.  多分支位级投票量化（Voting-LFQ）：这是一种全新的分词器架构。它用多个并行的、轻量的二值量化分支取代了传统的单路径量化器。通过在训练阶段聚合连续的软投票分数，在推理阶段执行严格的比特位多数决，实现了比令牌级集成更精细、更强大的错误纠正能力。这是解决架构脆弱性的核心。
2.  噪声感知共识训练：这是一种与架构紧密耦合的训练策略。它通过在训练时向少数分支注入可控的噪声扰动，并设计共识损失（L2 loss）来强制这些受扰分支与干净分支的输出对齐，从而显式地教会模型忽略噪声，关注共识信号。这为多分支架构提供了有效的监督，解决了训练信号遥远的问题。
3.  协同设计范式：论文的突出贡献在于将上述架构与训练策略作为一个整体进行设计。多分支架构为噪声感知训练提供了必要的结构（可以注入不同“视图”），而噪声感知训练则释放了多分支架构的鲁棒潜力，两者相辅相成，缺一不可。
4.  系统性的问题定义与验证：论文首次系统性地指出了监督式语义分词器在噪声下的普遍脆弱性，并提出了一个明确的度量（UED%）。同时，不仅在分词器层面验证，更在下游语音大模型的多个任务（理解、生成）上验证了改进分词器鲁棒性带来的实际收益，论证链条完整。

### 🔬 细节详述

- 训练数据：分词器预训练使用约15万小时的多语言语音数据，包括LibriSpeech、GigaSpeech、WenetSpeech、Emilia等公开及内部数据（详见附录表7）。
- 损失函数：总损失为加权和：`L_total = L_ASR + λ1L_consensus + λ2L_commitment + λ3*L_codebook`。
    *   `L_ASR`：标准的交叉熵损失，用于ASR任务。
    *   `L_consensus`：共识损失，计算所有分支预量化向量 `p_i` 与其全局平均 `¯p_all` 之间的L2距离。权重 `λ1=0.25`。
    *   `L_commitment`：承诺损失，鼓励隐藏状态 `h` 接近量化后的表示。权重 `λ2=0.25`。
    *   `L_codebook`：码本熵损失，促进码本使用均匀。权重 `λ3=1.0`。
- 训练策略：
    *   优化器：AdamW。
    *   学习率调度：OneCycleLR，最大学习率 `1.5e-5`。
    *   预热步数：1000。
    *   梯度裁剪：1.0。
    *   关键策略：在训练的每次前向传播中，对每个样本，从5个分支中随机选择 `k` 个（`k < n/2`，即2个）分支，将带噪的隐藏状态 `h'` 送入；其余 `n-k` 个分支接收干净的隐藏状态 `h`。噪声类型（高斯、粉噪、棕噪、比特压缩、真实噪声）和强度（SNR范围见附录表9）随机采样。
- 关键超参数：
    *   编码器：基于 whisper-large-v3（6.8亿参数）。
    *   分词器码本大小：8192，对应比特维度 `d=13`（2^13=8192）。
    *   帧率：25 Hz。
    *   分支数量（投票人数）：`N=5`（通过实验在表5中确定，为性能与效率的最佳平衡点）。
    *   分词器嵌入在编码器的第16层（通过消融实验在附录表20中验证，平衡语义鲁棒性和声学细节）。
- 训练硬件：论文中未明确说明。
- 推理细节：推理时，所有 `n` 个分支都接收相同的干净输入，并执行位级多数决生成最终令牌。对于超过30秒的音频，采用分块（每块30秒）处理后拼接的方式。
- 正则化/稳定训练技巧：使用STE进行梯度回传；共识损失本身起到稳定训练的作用；采用OneCycleLR调度器。
