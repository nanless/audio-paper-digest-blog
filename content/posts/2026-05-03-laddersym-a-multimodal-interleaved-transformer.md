### 📌 核心摘要

这篇论文针对音乐学习者练习错误检测任务，提出了一个名为LadderSym的新型多模态Transformer模型。该模型旨在解决现有方法（如Polytune）的两个核心局限：1) 晚期融合设计限制了参考音频与练习音频之间的精细对齐能力；2) 将乐谱仅以音频形式表示会引入频率重叠歧义，尤其在和弦演奏时。LadderSym的核心创新包括：1) 设计了一个名为“Ladder”的双流编码器，在每个Transformer层之前交替进行跨流对齐与融合，实现了特征提取与跨模态对齐的解耦；2) 在解码器端引入符号乐谱（MIDI）作为提示（Prompt），为模型提供明确的参考信息，减少了音频表示的歧义。实验在MAESTRO-E和CocoChorales-E合成数据集以及新收集的真实初学者数据集上进行。相比之前的SOTA模型Polytune，LadderSym在MAESTRO-E上将漏音（Missed Note）的F1分数从26.8%提升至56.3%，多音（Extra Note）F1从72.0%提升至86.4%；在CocoChorales-E上，漏音F1从51.3%提升至61.7%，多音F1从46.8%提升至61.4%。该工作不仅推动了音乐错误检测任务，其提出的跨模态频繁对齐与非对称特征提取的设计原则，对强化学习中的奖励模型、人类技能评估等领域也具有启示意义。主要局限性在于模型对大幅度速度变化缺乏鲁棒性，且在密集和声场景下漏音检测仍具挑战。

### 🏗️ 模型架构

LadderSym是一个序列到序列的模型，由Ladder编码器和T5解码器构成，整体流程如图3所示。

![图3：LadderSym架构图](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/cizuvfyQXs-2.png)

完整输入输出流程：
- 输入：1) 参考乐谱的音频（Score Audio），2) 学生的练习音频（Practice Audio），3) 参考乐谱的符号化表示（Symbolic Score Prompt，来自MIDI）。
- 输出：一个MIDI-like的令牌序列，标记每个音符为“正确”（Correct）、“漏音”（Missed）或“多音”（Extra）。

主要组件与数据流：
1.  Ladder编码器：这是一个双流Transformer编码器，专门处理两个音频输入。
    - 双流输入：参考音频（`Pref`）和练习音频（`Pprac`）分别通过独立的音频分词器（基于AST的ViT patch embedding）转换为嵌入序列。
    - 交替对齐与融合模块：这是Ladder的核心。在每个编码层i，对齐操作依次在两个流之间交替进行（如图5所示）。其核心公式为：
        - `P(i+1)_ref = ViT_ref( P(i)_ref + CA(P(i)_prac, P(i)_ref) )`
        - `P(i+1)_prac = ViT_prac( P(i)_prac + CA(P(i+1)_ref, P(i)_prac) )`
        其中`CA`代表跨注意力（Cross-Attention）操作。首先，练习音频的表示通过跨注意力来对齐并融合到参考音频的表示中，然后通过一个标准的ViT层处理。接着，更新后的参考音频表示再通过跨注意力对齐并融合回练习音频的表示，并经过另一个ViT层。这种交替设计确保了在每个层，信息都能在两个流之间流动，同时每个流仍保持独立的参数用于特征提取。
    - 融合输出：两个流最终的表示`P(final)_ref`和`P(final)_prac`被拼接（Concat）成一个统一的上下文向量`Hfused`。
2.  T5解码器：一个自回归解码器。
    - 提示（Prompt）构建：在解码开始前，将符号化乐谱（`Sym`）序列作为提示令牌，与起始令牌（SOS）一起拼接在输入的最前面。这相当于告诉解码器：“这是标准答案，请结合编码器听到的音频，找出差异”。
    - 生成过程：解码器以`Hfused`为上下文，从提示开始自回归地生成错误检测令牌序列。

关键设计选择及动机：
- 交替跨层对齐：动机是克服前人工作（如Polytune）“晚期融合”导致对齐不充分的问题。论文通过探针实验（Table 1）和消融实验（Table 4）证明，在2-3层进行联合编码效果最佳，但更多的联合层会损害特征提取能力。Ladder的设计通过在每一层都进行对齐，但保持流参数独立，巧妙地结合了早期融合（强对齐）和晚期融合（特化特征提取）的优点。
- 符号提示：动机是解决仅使用音频表示乐谱时，因和弦等并发音符导致的频率混淆歧义。实验证明（Table 5），结合音频和符号提示比单独使用任一模态效果更好。

### 💡 核心创新点

1.  Ladder双流交织编码器：
    - 局限：前人晚期融合（Polytune）限制了跨流交互；早期融合（全联合编码器）又因参数共享牺牲了特征特化。
    - 创新：提出了一种新的混合融合架构，在每个Transformer层使用跨注意力模块交替对齐两个音频流，同时保持各流的编码器参数独立。这实现了“频繁对齐”与“非对称特征提取”的结合。
    - 收益：通过探针实验（Table 1）证实，该架构使练习音频流保留了较强的局部信息（Local Practice: 0.681），而参考音频流则更擅长编码跨流特征（Cross-Stream Score to Practice: 0.300），形成了有效的分工。最终显著提升了对齐和比较能力，尤其是在漏音检测上。
2.  解码器符号乐谱提示：
    - 局限：将乐谱转化为音频（如Polytune）会引入歧义，模型难以分辨重叠音符。
    - 创新：将乐谱的离散符号表示（MIDI令牌）作为解码器的提示输入，为错误检测提供了清晰、无歧义的参考。
    - 收益：消融实验（Table 5）显示，该策略与改进的Ladder编码器结合（LadderSym）取得了最佳性能，尤其在挑战性的MAESTRO-E数据集上效果提升明显。
3.  任务建模与数据集贡献：
    - 局限：真实世界的初学者错误数据稀缺，标注困难。
    - 创新：1）将错误检测明确建模为序列生成问题，输出包含时间、音高和错误标签的令牌序列。2）创建并开源了首个较大规模的真实初学者演奏数据集（20首曲子，161个错误），并探索了使用LadderSym作为“人机协同”标注工具的工作流，加速标注过程。
    - 收益：在真实数据上验证了模型的泛化能力（LadderSym漏音F1: 78.5% vs. Polytune: 63.9%），并为解决领域“鸡生蛋”数据问题提供了一条可行路径。

### 🔬 细节详述

- 训练数据：
    - 数据集：主要使用MAESTRO-E和CocoChorales-E两个部分合成数据集。
    - 来源与规模：MAESTRO-E基于MAESTRO数据集的MIDI，通过算法（Algorithm 1）注入错误后用MIDI-DDSP合成音频，包含1k+钢琴轨道，200k+错误。CocoChorales-E基于CocoChorales数据集，包含40k+轨道，13种乐器，25k+错误。
    - 预处理：音频被分割成2.145秒的非重叠片段，计算STFT频谱图（2048点FFT，128样本hop，512 mel-bins），并使用ViT方法将其分割为16x16的patch，每个片段产生512个令牌。
    - 数据增强：训练时使用了令牌洗牌（Token Shuffling），即在不改变语义的情况下打乱输出令牌顺序，以提升泛化能力。
- 损失函数：加权交叉熵损失（Weighted Cross-Entropy Loss），用于缓解正确音符与错误音符（漏音/多音）之间的类别不平衡。在MAESTRO-E上，错误损失的权重设置为10（Table 7）。
- 训练策略：
    - 学习率：初始为2e-4，使用余弦退火调度器衰减至1e-4。
    - 优化器：AdamW。
    - 训练步数/轮数：300个epoch。
    - 批大小：MAESTRO-E为48个频谱图段/批；CocoChorales-E为96个频谱图段/批。
    - 调度策略：余弦退火（Cosine Annealing）。
- 关键超参数：
    - 模型大小：总参数量为172M（LadderSym），小于Polytune的192M。
    - 架构配置：Ladder编码器有12层，T5解码器有8层，以匹配之前工作中的AST编码器和T5解码器。编码器输出维度为768，投影至512以匹配解码器维度。
- 训练硬件：在单卡NVIDIA A100-80GB GPU上训练。使用混合精度（bf16-mixed）。
- 推理细节：
    - 解码策略：自回归解码。
    - 其他：论文未提及温度、beam size等具体解码超参数。
- 正则化/稳定训练技巧：主要依靠加权损失和令牌洗牌数据增强。论文未明确提及其他正则化技巧。

### 📊 实验结果

论文在三个数据集上评估了模型：合成的MAESTRO-E、CocoChorales-E和新收集的真实初学者数据集。评估指标为“错误检测F1分数（Error Detection F1）”，针对正确（C）、漏音（M）、多音（E）三类分别计算。

主要对比结果（Table 2）：

| 数据集         | 模型            | Correct (F1) | Missed (F1) | Extra (F1) |
| :------------- | :-------------- | :----------- | :---------- | :--------- |
| MAESTRO-E  | LadderSym   | 94.4%    | 54.7%   | 86.4%  |
|                | Polytune        | 90.1%        | 26.8%       | 72.0%      |
|                | Explicit Align. | 43.5%        | 6.6%        | 39.9%      |
| CocoChorales-E | LadderSym   | 97.7%    | 61.7%   | 61.4%  |
|                | Polytune        | 95.4%        | 51.3%       | 46.8%      |
|                | Explicit Align. | 36.7%        | 7.7%        | 23.5%      |

关键结论：LadderSym在所有类别和数据集上均大幅超越了SOTA模型Polytune和显式对齐基线，尤其在挑战性的MAESTRO-E漏音检测上F1几乎翻倍。

真实世界数据集性能（未微调）：
- 漏音F1：LadderSym平均78.5%，Polytune平均63.9%。
- 多音F1：LadderSym平均81.6%，Polytune平均80.6%。
- 结论：模型在真实数据上的表现验证了其泛化能力。

核心消融实验1：融合位置影响（Table 4）
- 实验通过改变联合编码器层数（Ljoint），固定总层数（12）或模态特定层数进行消融。
- 结论：性能在2-3个联合层时达到峰值，证实了过多层联合编码会损害特化能力，这驱动了Ladder的逐层对齐设计。

核心消融实验2：输入表示（Table 5）
| 输入配置/编码器设计 | MAESTRO-E Missed | MAESTRO-E Extra | CocoChorales-E Missed | CocoChorales-E Extra |
| :------------------ | :---------------- | :-------------- | :-------------------- | :------------------- |
| Prompt Only         | 24.3%             | 62.5%           | 44.6%                 | 45.8%                |
| Audio Only (Polytune) | 26.8%             | 72.0%           | 46.8%                 | 51.3%                |
| Prompt + Audio (Polytune) | 46.7% ↑       | 81.7% ↑     | 56.1% ↑           | 58.1% ↑          |
| Ladder (仅编码器改进) | 46.0% ↑           | 82.0% ↑         | 61.0% ↑               | 62.3% ↑              |
| LadderSym (最终模型) | 54.7% ↑       | 86.4% ↑     | 61.7% ↑           | 61.4% ↓              |

结论：1）“音频+提示”策略显著优于单一输入。2）Ladder编码器独立使用时已带来大幅提升。3）两者结合（LadderSym）在最具挑战的MAESTRO-E上取得最佳整体性能。
