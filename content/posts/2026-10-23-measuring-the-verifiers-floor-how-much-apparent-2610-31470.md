## 📌 核心摘要

文本到语音保真度评测常把合成语音交给自动语音识别系统转写并计算词错误，其中混入识别器自身错误，尤其稀有词、人名和外来词上难分合成错误与识别错误。论文对每句同时取文本、原始人声录音和多个合成版本，让三个识别器全部转写，评估器C的往返结果待核查，另两个识别器只负责复核。转写文本经归一化对齐后形成词级判定：某识别器在人声中听出记为h，在任一合成版本中听出记为s，该s输出直接作为三种估计的公共输入。标准往返只看C在合成中是否听出；单识别器掩码先用C的人声漏检hC筛掉词再判；三识别器裁决要求至少一者在人声听出才纳入，且三者在所有合成版本均未听出才判合成错误。与已有只在语料级比较识别词错误和听者转写的工作不同，本文做到词级、按词频段的三识别器核查，并揭示简单丢弃的偏差。在500句LibriSpeech上，按Zipf频段统计的评估识别器人声漏检率为常用词1.5%、极稀有词32.9%；同一批句子的任一合成版本命中设置下，按判后词计算的TTS词错误率从标准往返到三识别器裁决，F5-TTS由0.63%降到0.22%，Kokoro-82M由0.72%降到0.22%。结论适用于英文朗读语音的两套语料，单识别器掩码会丢掉真错误并保留约一半假错误，残留错误多为拼写变体，需听辨确认。原文未披露训练、推理或部署成本。

## 🧭 深度解读

### 要测什么：合成读对了吗，为何借识别器来判

这篇论文研究的输入是一句待合成的文本，目标是判断文本转语音系统是否把每个词读对了，且必须保留罕见人名、地名、古语和外来词这些最容易丢失的信息。输出是一个词级判定：该词在合成音频里是否可被听到。研究生刚接触这个方向时，最需要先分清合成质量里的韵律自然度和内容正确性，本文只管后者。

直接请听音人逐词听写最可信，但贵且慢，所以常用做法是自动语音识别往返：用一个自动语音识别系统把合成音频转写成文字，再与输入文本对齐计算词错误。这里的词错误在本文被收窄为词漏检率，即参考词在转写里没被完全听到就算漏掉，不计多出来的插入词。这种收窄让分析聚焦于漏读和误读，但代价是忽略插入类问题。

这样做的困难是判官本身会犯错。如果识别器连真人读的同一个词都听不到，那么合成音频上同样的漏检就说不清是谁的错。刚入门容易误以为往返错误率越高合成越差，本文要拆开的就是这一层混淆。理解这一点，才能明白后文为什么要对真人录音也跑一遍识别器。

### 已有路线把识别器当判官，存在两类相反的偏差

用识别器转写代替听音人来测可懂度是常见路线，但已有报告指出识别器词错误与听音人的一致程度只是松散相关。还有工作发现先生成多个候选再留下最好的做法，其结果依赖于用哪个识别器家族当评委。也就是说换一个判官，最优候选的选择结果就会变，这说明判官不是中立的尺子。

偏差有 2 个方向。一是本文主攻的假阳性：合成读对了但识别器听错，记成合成错误；二是反方向的假阴性，即识别器靠语言模型从上下文猜出本该读的内容，把真实合成错误掩盖掉。论文引用了相关讨论，并明确自己不重跑那篇罕见词系统的工作，只是补上对方声明未测的在真值音频上的误报下限。

最接近的是某附录里对一个合成系统比较识别器词错误与听音人转写的工作，但只做到语料整体层面。本文的不同在于做到词频相关、词级三识别器核验，并追踪它们对罕见词结论的影响。比较的前提相同，都是用识别器转写评价合成可懂度，区别在于本文把分析细化到每个词和每个频率段。

### 具体问题：罕见词错误里多少只是验证器听错

论文要回答的是验证器的地板问题：当评估用识别器报告合成在罕见词上错了很多，其中多少在真人录音上同样听不到，因而根本不能算合成的错。罕见词恰好是两类错误叠加的地方，合成难读对，识别器也难听对。如果不拆开，就会把识别器的无知当成合成的无能。

为此作者要求每个测试句都有原始真人录音，对真人录音和多个合成版本跑同一批识别器。真人录音上的错误是诊断基线，不是严格下界，因为合成语音可能比真人更易或更难识别，这一点原文明确提醒。这个提醒很重要，它防止读者把真人错误率当成可以直接减掉的本底。

比较对象是同一些可判定词上的 3 种估计：标准往返、单识别器掩码、三识别器裁决。问题不是比哪个合成系统更好，原文明确说两个合成系统的生成方式和候选数不同，不做系统间比较。读者复述时要守住这个边界，不要把两系统的绝对值拿来排名。

### 整体流程：同一批句子跑真人与合成，再逐词对齐判定

流程沿一个测试句走。先有参考文本、对应真人录音和多个合成版本。3 个识别器各自转写所有音频，文本都用 Whisper 英文文本归一器归一化再与参考对齐。若参考词与转写完全匹配，或至多 3 个词仅差空格，就判该识别器听到了该词。空格宽容是为了不把分词差异算成错误。

记真人录音里听到为一种状态，在至少一个合成版本里听到为另一种状态。因此所有错误率都是任一候选命中的比率，候选越多越容易命中而下降。论文还报告单个候选和按评估器漏检最少选出的保留候选，以对照实际选优部署。只报任一命中会夸大合成的成功率，所以多口径并列是必要的。

**文本转语音 × 自动语音识别往返 × 词漏检率：** 文本转语音负责把输入文本读成音频，自动语音识别往返负责把这段音频再转写成文字并与原文比对，词漏检率在这里只计漏掉的参考词而不计插入词。三者搭配的意义是借识别器代替听音人做可扩展的正确性检查，但代价是同时测了合成与识别两个系统，识别器听错会被记成合成错误。

### 谁来听：三个识别器家族的分工与解码条件

3 个识别器分别是 Whisper large-v3-turbo、无语言模型的 wav2vec2.0 large 和 OWSM v3.1，全部用贪心解码。其中最后一个是被研究的评估器，前两个只做复核。选不同家族的用意是减少同一类语言模型猜词带来的共谋，但不能完全消除共有盲区。贪心解码保证了转写过程确定，不引入搜索随机性。

合成侧用两种系统制造多样性。一种用随机种子生成多个版本并模仿给定说话人音色，另一种本身确定性生成所以用多个音色造出多个版本。因为候选数的含义和变化来源不同，跨系统数值不能直接比高低。这一点是理解实验设置的关键，否则会误读后文的并列数字。

**评估器 C × 核验器 A × 核验器 B：** 评估器 C 是被研究的往返判官，即 OWSM v3.1，它的漏检决定标准错误率；核验器 A 是 Whisper large-v3-turbo，核验器 B 是无语言模型的 wav2vec2.0 large，只用来复核 C 的每个词判决。三者分工是 C 给出待检验的错误集合，A 和 B 提供独立听觉证据，组合后可以区分是 C 自己听错还是合成真的没读对。

统计上句子内词不独立，所以置信区间用句子级百分位自助法重采样得到，重复录音的句子成组重采样；零错误的格子用假设词独立的上界方法，原文注明了该假设的局限。句子级重采样保留了同句词之间的相关性，比把词当独立样本更诚实。

### 什么算听到：对齐规则与可判定词的来历

对齐只看参考词是否被找回，不计插入，所以不是完整词错误率。这种收窄让结论更聚焦于漏读和误读，但代价是忽略了多读和重复等插入类问题。初学者要记住，分母是参考词数，分子是没被听到的参考词数，插入词不进入计算。

可判定词的定义很关键：至少有一个识别器在真人录音里听到，才有资格进入合成错误判定。若 3 个识别器在真人录音里都没听到，该词直接无法判定。这部分在非常罕见词里占比很高，后文数字会显示其代价。无法判定不是合成对了，而是连裁判资格都没有。

**真人录音基线 × 可判定词：** 真人录音基线指对测试句的原始真人朗读跑同一识别器，得到识别器自身在该词上的漏检率；可判定词指至少有一个识别器在真人录音里听到了该词，才进入后续的合成错误判定。二者搭配的理由是只有真人能读对的词才值得追问合成是否读错，否则无法区分音频不清、拼写归一还是识别器盲区。

### 三种估计如何判定一个词：从标准往返到三方裁决

对一个词，标准往返只要评估器在所有合成版本里都没听到就判合成错误。单识别器掩码多加一个前提：评估器必须在真人录音里听到过该词，否则直接忽略。三识别器裁决的逻辑是先看是否可判定，再看是否 3 个识别器在所有合成里都没听到。3 种口径的分母和严格程度都不同。

\[\begin{split}\mathrm{err}(w)={}&\big[h_{A}(w)\lor h_{B}(w)\lor h_{C}(w)\big]\\ &\wedge\neg\big[s_{A}(w)\lor s_{B}(w)\lor s_{C}(w)\big].\end{split}\]

公式中或关系表示任一识别器在真人里听到即为可判定，与关系后半表示 3 个识别器在合成里全都没听到才判错。也就是说被裁决保留的错误必须熬过更多份转写，而标准错误只需熬过较少份，这种池化本身就会拉开差距，原文明确提醒不能把差距全归为纠错能力。

下面原表用 4 个真实单词展示 3 种估计的分歧来源，比较问题是同一词在不同证据下会被判对还是判错。表头给出真人录音里谁听到、合成里多数转写是什么，以及 3 种估计各自的结论。

| word | human | TTS output (A / B / C) | (1) | (2) | (3) |
| --- | --- | --- | --- | --- | --- |
| Phoebe | A, B, C | fuby / pube / fuby | error | error | error |
| Tessa | A, B, C | = / = / tess | error | error | correct |
| stile | A, B | = / = / style | error | ignored | correct |
| Veolan | A | violan / violan / tullyviolen | error | ignored | error |

该表说明掩码的两类失败：只被个别识别器在真人里听到的词会被掩码误删，而只是评估器自己在合成上失败的词会被掩码误留。裁决用三家证据交叉，既能捞回前者，又能推翻后者。但裁决仍不完美，猜词和共有盲区会压低错误，拼写变体会抬高错误。

**单识别器掩码 × 三识别器裁决：** 单识别器掩码指只看 C，若 C 在真人录音里没听到该词就直接忽略该词；三识别器裁决指只要 A 或 B 或 C 任一在真人录音里听到该词就保留，而只有 A、B、C 在所有合成版本里都没听到才判为合成错误。前者省事但只用同一双耳朵决定取舍，后者用三家族交叉验证来同时减少误删真错误和误留假错误。

### 没有训练时本文实际计算了什么，词频如何划分

本文没有训练任何声学或语言模型，这里讲的是实际执行的计算与构造。计算是推理与比对：用现成识别器转写真人与合成音频，归一化、对齐、按规则逐词投票，再按频段和句子聚合。没有梯度更新，没有参数冻结与重置的讨论，输出不确定性来自合成随机种子、音色选择和自助重采样。

词频用通用词频库的 Zipf 尺度，数值含义是每 1000000 词出现次数的对数，越小越罕见，带数字的符号不分段。选句用的另一套语料库口径是在约一万句转写里至多出现 2 次，句级难度用该口径算占比。两套口径相关但不等同，前者做跨语料可比的频段划分，后者做选句和趋势图。

**Zipf 词频 × 语料库罕见词占比：** Zipf 词频是用 wordfreq 库计算的通用频率，z 等于 3 表示每百万词出现一次，小于 2.5 为非常罕见词；语料库罕见词占比指该词在约 1.1 万句 LibriSpeech 转写里至多出现两次，再按句算占比。两者分工是前者做跨语料可比的频段划分，后者做选句和画趋势图的句级难度指标，组合后既能看词级漏检随频率的变化，也能看句级错误随难词增多的趋势。

需要指出方法修订的探索性：词匹配规则是在看过这些集合的对齐后修改过的；主集先取部分句子发现高难句太少趋势不清，又补了罕见词占比最高的难句，所以趋势分析是探索性的，不能当预注册结论读。这个交代决定了后文相关系数的解读分量。

### 数据与句子的构成：测了哪些语音，难词从哪来

主集是数百句朗读测试与开发句，每句十几到 30 词，平均 20 词出头，罕见词占比从零到 40%，而各难度箱的平均句长保持相近，控制了长度混淆。复测集是英文美国口音的另一语料录音，对应一百多句，其中部分句子被录 2 次，句长和时长覆盖短句到长句，人名数字更多。

这种构成意味着结论只在英语朗读语音、这两套文本分布下成立。部分识别器在其中一个语料上训练过，且评估器身兼评估与裁判，存在偏向自身错误的可能。重复录音的句子在统计上成组处理，避免同一文本的 2 次录音被当独立样本。

候选数在不同集合和系统下不同，直接影响任一命中的命中率，所以跨集、跨系统的绝对值比较必须先对齐候选数和生成方式。原文为此同时报告单候选和保留候选，就是为了让读者看到口径变化的影响。

### 剩下的裁决错误是什么：真读错还是拼写不同

测量对象是三集合里共几十个裁决错误的内容构成。方法是看识别器转写是否指向不同发音。指标是其中可明确归为发音不同的例数与占比，占比越高越支持合成真有问题。比较问题是残留错误里有多少经得起发音层面的推敲。

原文报告三集合的裁决错误总数分别为二十多例、二十多例和十多例，大多是人名、古语外来词和缩写。其中一部分转写指向不同发音，例如人名被转写成发音明显不同的字符串，另一部分是拼写变体同音或文本产物。若只计发音不同组，非常罕见词和整体错误率都会进一步下降，但罕见词仍最难。

限制是纯转写无法区分拼写变体与真误读，约一半残留可能是拼写变体，所以必须做听音测试才能定论。这也意味着裁决错误率仍是偏高的估计，而猜词与共有盲区又使其偏低，两边偏差同时存在。读者不要把裁决数字当成真值，它只是比标准更接近真值的中间估计。

### 为何不能直接删掉识别器听不到的词

要判断单识别器掩码是否无偏，做法是以另两个识别器当裁判，只看它们在真人里听到的词，再对比评估器在真人里漏掉与听到的两组上，它们在合成里发现错误的频率，以及掩码保留的错误里有多少能被它们在合成里听到。比较问题是被掩码删掉的词和留下的词，哪边更可能是真错误。

| --- | --- | --- | --- |
| LS, F5-TTS | 3.9 [1.5, 6.8] | 0.2 [0.1, 0.3] | 53 [35, 71] |
| LS, Kokoro | 4.9 [2.2, 8.1] | 0.2 [0.1, 0.3] | 64 [48, 79] |
| FLEURS, F5-TTS | 6.0 [2.3, 10.4] | 0.3 [0.1, 0.6] | 56 [35, 79] |

该原表显示掩码删掉的恰是合成最易错的词，相差一个数量级以上，同时它保留的错误约一半被另两家推翻。也就是说掩码同时犯两种错：丢掉真错误，又留下假错误。限制是评估器漏掉的词对另两家也难，它们在真人里仅听到其中 30%，而评估器听到的词它们听到几乎全部，所以部分反差是共有难度。分母效应可排除，只在评估器听到的 90% 以上词上算掩码，变化很小。趋势上掩码与裁决的差异不显著，论文只断言掩码有偏，不宣称趋势差异显著。本表数值与单位依据论文 PDF。

### 哪些结论还站不稳：听音缺失与小样本的代价

最大缺口是没有听音测试。所有合成错误判定都来自识别器，共有盲区会同时抬高或压低错误，论文已准备对裁决错误、被去掉的错误和对照词做听音，但尚未执行。在听音完成前，残留错误里拼写变体与真误读的比例只能靠转写推测。

其次是错误数太少。裁决错误仅几十例，罕见词估计与趋势的区间很宽，最右箱的跳变可能随样本改变。范围也窄：仅英语朗读、两语料，且部分识别器在其中一个语料上训练过，评估器身兼评估与裁判。换语言、换判官或换候选数都需要重测地板。

还有两处探索性操作需要打折：一是先看部分句子结果再补难句，二是看过对齐后修改匹配规则。它们不推翻方向性结论，但趋势显著性应按探索性解读，不宜直接当确证。复述时要保留这些条件，不要把探索性相关说成预先验证的规律。

### 要复现第一步做什么，需要哪些数据与计算

复现从配对数据开始：取同样的朗读句与另一语料文本，找到各自原始真人录音，再用两种合成系统按原文候选数与音色设置生成多版本。接着用英文归一器归一化，用贪心解码跑三家转写，按完全匹配或仅差空格规则对齐。第一步最容易出错的是录音与文本对不上，务必保证每句都有真人录音。

关键是复刻 3 种口径的计数：标准只看评估器在合成是否全漏，掩码要求评估器在真人听到，三方裁决用公式要求至少一家在真人听到且三家在合成全漏，并分别在任一命中、单候选和保留候选下报告。统计用句子级自助法，零错误格用上界方法。分母必须用可判定词，而不是全部词。

本文未声明代码模型数据已公开，证据只显示作者计划发布代码、句表与全部转写。复现成本主要是合成与三家识别器的推理量，原文未给硬件与时长，部署延迟与费用无法从本文得出。代码、权重、数据是否可得是三件事，要分开核实。

### 什么时候值得用这套做法，还缺哪项验证

当你用识别器往返评估合成且关心罕见词、人名与外来词时，值得照做四件事：按词频报告识别器在真人录音上的漏检；不要直接删掉识别器听不到的词；对争议罕见词用另两家族或听音人复核；同时报告单候选与任一候选命中，避免只报后者夸大命中。这 4 条是本文最具操作性的建议。

容易误解的是把裁决后 2 到 3 倍下降读成合成变好了，其实是扣掉了验证器自身的错；也不能把掩码后数值变小读成更准，它删掉了最易错的词又留下一半假错误。另一误解是把共有难度当单方故障，评估器漏掉的词对另两家也难，说明部分是文本或音频本身难。

还缺的验证就是听音测试。只有听过那几十个残留错误、被推翻的错误和对照词，才能确认拼写变体占比与真误读率，进而判断非常罕见词到底难多少。在此之前，结论的成立条件是英语朗读、这三家识别器与本文候选数和对齐规则，换判官、换语言或换候选数都需要重测地板。
