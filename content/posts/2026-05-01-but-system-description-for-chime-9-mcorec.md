### 📌 核心摘要

1.  问题：在多人重叠对话录音中进行准确的说话人归属语音识别（ASR）和对话组聚类是一个难题，尤其在视觉线索有用但长上下文音视频ASR系统应用有限的情况下。
2.  方法核心：提出一个长上下文音视频目标说话人ASR系统。该系统以预训练的NVIDIA Parakeet ASR模型为基础，通过可学习的加权求和、卷积对齐和乘性门控机制，将预训练AV-HuBERT提取的视觉特征（唇部动作）融入声学编码器。对于对话组聚类，采用基于Qwen3.5-122B LLM估计转录文本主题相似度，然后进行层次聚类。
3.  创新之处：与基线系统相比，主要创新在于：(1) 提出了一种灵活的视觉特征融合方式，允许模型从不同深度的视觉层中自适应选择信息；(2) 将ASR与聚类解耦，利用LLM强大的语义理解能力进行聚类，取代了基线中仅依赖语音重叠时长的启发式方法；(3) 采用模拟数据进行大规模预训练，以应对真实数据稀缺和重叠场景。
4.  主要实验结果：在CHiME-9 MCoRec开发集上，该系统将官方基线的词错误率从49.90%显著降低至33.69%（绝对降低16.21%），聚类F1分数从0.815提升至0.967（绝对提升0.152）。在评估集上排名第二，仅比最佳系统差0.16% WER和0.5% F1。

| 基线 | 49.90% | 0.815 | 0.355 |
| System 1 (论文最佳) | 33.87% | 0.967 | 0.185 |
| System 2 | 33.69% | 0.967 | 0.184 |

图3说明：该图表明，随着WER增加，聚类性能下降。122B模型鲁棒性最强，在WER高达30%时，F1分数仍能保持在90%以上。性能下降与模型大小不完全成比例，说明较小的LLM也能有效完成主题相似度估计任务。

5.  实际意义：为解决现实世界中复杂重叠语音的转录和说话人分组问题提供了一个有效且性能强大的技术框架，其开源代码有助于相关研究。
6.  主要局限性：系统性能高度依赖于预训练模型的质量和模拟数据的有效性，存在领域失配问题（如论文中提到的AMI与MCoRec数据差异）。聚类方法对LLM的语义理解能力依赖性强，且在推理时需要较长的转录文本输入，计算成本可能较高。

### 🏗️ 模型架构

论文的整体流程如图1所示，主要包括两个核心模块：音视频目标说话人ASR（AV-TS-ASR）和基于LLM的对话组聚类。

![图1：所提流水线概述](https://arxiv.org/html/2604.27436v1/chime_overview.png)

1. AV-TS-ASR模块（核心架构见图2）
![图2：所提AV-TS-ASR系统的结构图，描述了视觉条件化过程。不同的箭头颜色代表在AV-Hubert隐藏表示平均中使用的不同学习权重集合。$f_{l}$块对应公式4，$\sigma_{l}$块对应公式5。](https://arxiv.org/html/2604.27436v1/chime9_sys_diagram.drawio.png)
*   输入：混合音频信号 `a` 和目标说话人的视频流 `vs`（唇部区域）。
*   特征提取：
    *   声学分支：使用预训练的NVIDIA Parakeet-v2 (FastConformer编码器)的第 `l` 层输出 `e_a^l`。
    *   视觉分支：将视频流输入预训练的AV-HuBERT模型。为使其仅作为视觉编码器，音频输入被置零（zeroed out）。提取第 `k` 层的输出 `e_vs^k`。
*   视觉特征融合与对齐：
    1.  加权层聚合：对于声学编码器的每一层 `l`，使用可学习的、归一化的权重 `α_i^l`，对AV-HuBERT所有 `L_v` 层的视觉特征进行加权求和，得到聚合视觉特征 `f_vs^l`。这使得模型能为声学编码器的每一层自适应地选择最相关的视觉信息层次。
    2.  时空对齐：通过一个1D卷积（核大小5，步长2）和前馈网络（FFN）将视觉特征的时间分辨率（25 Hz）与声学特征（12.5 Hz）对齐，并将维度投影到与声学特征 `d_a` 相同的嵌入空间，得到对齐后的视觉特征 `~f_vs^l`。
*   模态融合：采用乘性门控机制。
    1.  将层归一化（LN）后的声学特征 `LN(e_a^l)` 与对齐的视觉特征 `~f_vs^l` 拼接。
    2.  通过一个线性层和sigmoid激活函数计算出一个门值 `g^l ∈ (0, 1)`。
    3.  最终融合输出 `e_out^l` 是声学特征和视觉特征的加权和：`g^l ⊙ e_a^l + (1 - g^l) ⊙ ~f_vs^l`。门控值 `g^l` 为每个时间帧动态决定模型依赖声学特征（混合音频）还是视觉特征（唇部动作）的程度。
*   解码与训练：最后一层的融合表示 `e_out^L` 被送入时间与持续时间转录器（TDT）解码器，进行转录文本 `ys` 的生成。训练目标为最小化负对数似然 `-log P(ys | a, vs)`。

2. 对话组聚类模块
*   输入：由AV-TS-ASR生成的每个说话人的转录文本。
*   流程：
    1.  话题检测：使用Qwen3.5 LLM对每个说话人的完整转录文本进行二分类，判断其是否在讨论某个话题（主动发言者），还是仅发出背景提示音（被动听众）。
    2.  语义聚类：对于所有主动发言者，使用LLM计算每对说话人之间的主题相似度分数（0-1）。基于相似度矩阵，使用层次聚类（AHC，阈值 `τ=0.7`）将主动发言者聚类为多个核心对话组。
    3.  基于时长的回退策略：对于被动听众，计算其与每个核心对话组（作为一个“伪说话人”）的平均语音重叠比例。然后使用AHC将被动听众分配到与之重叠最少的对话组中，以确保主动发言者聚类结果不变。

### 💡 核心创新点

1.  自适应多层视觉特征融合门控：不同于简单拼接或仅使用单层视觉特征，该方法通过可学习的权重和乘性门控机制，允许声学编码器的每一层根据当前声学上下文，动态地、有选择性地从视觉特征的不同层次中提取有用信息。这增强了模型处理复杂声学环境（如强重叠）的能力。
2.  LLM驱动的语义对话聚类：用基于大型语言模型（LLM）的主题相似度评估取代了基线系统中仅依赖语音重叠时长的启发式聚类方法。这利用了LLM强大的语义理解能力，能够更准确地根据对话内容判断说话人是否属于同一组，显著提升了聚类性能（F1分数从0.815提升到0.967）。
3.  大规模模拟数据预训练与长上下文处理：为了应对真实重叠对话数据稀缺的问题，系统利用AVYT、LRS3、AMI等数据集构建了大规模（1500小时）模拟重叠和“鸡尾酒会”场景数据进行预训练。同时，通过填充黑帧的方式，使模型能够处理长视频输入（单次解码），并在推理时表现出比短分段更好的性能。

### 🔬 细节详述

- 训练数据：
    - 第一阶段预训练：使用AVYT和LRS3数据集生成200k（2-3说话人）+ 100k（4说话人）个完全重叠的混合音频，约1500小时。并添加静音视频段以训练视觉说话人活动检测。
    - 第二阶段预训练：使用AMI单远场麦克风（SDM）音视频记录，随机叠加2-4个独立会话以模拟“鸡尾酒会”场景，约150小时。
    - 微调：使用CHiME-9 MCoRec训练集和模拟的AMI混合数据（System 1），或仅使用MCoRec训练集（System 2）。
    - 数据预处理：发现并移除了MCoRec数据集中部分标签错误的样本。
- 损失函数：转录部分使用负对数似然（NLL）损失 `-log P(ys | a, vs)`（公式7）。
- 训练策略：
    - 课程学习：分两阶段引入视觉条件化。第一阶段冻结Parakeet和AV-HuBERT编码器，仅训练新引入的参数（门控、对齐等）。第二阶段解冻Parakeet编码器进行联合优化。
    - 优化器：AdamW，权重衰减 `10^{-2}`。
    - 学习率调度：Noam调度器，1万步预热。预训练阶段新参数峰值学习率为 `2.5×10^{-5}`，Parakeet参数学习率为前者1/5。微调学习率再减半。
    - 数据采样：预训练使用桶采样最大化重叠；微调使用随机50秒片段。
- 关键超参数：
    - 视觉编码器：AV-HuBERT。
    - 声学编码器：NVIDIA Parakeet-v2 FastConformer（0.6B参数）。
    - 解码器：时间与持续时间转录器（TDT）。
    - 视觉融合层：可学习权重 `α_i^l`；1D卷积（核5，步长2）；FFN带SiLU激活、Dropout(p=0.1)和层归一化。
    - 聚类：LLM为Qwen3.5-122B；层次聚类阈值 `τ=0.7`。
- 训练硬件：NVIDIA A100和H100 GPU。具体数量和训练时长未说明。
- 推理细节：
    - 视觉特征提取：将视频切分为20秒不重叠的片段输入AV-HuBERT（因其不支持长序列推理）。
    - 长上下文处理：将视觉片段特征拼接，并将缺失面部检测帧填充为黑色图像后对应的视觉特征，与音频一起送入Parakeet进行单次解码。
    - 解码：使用贪心解码。
    - LLM推理：使用DSPy框架构建提示，解码温度设为0以保证可复现性。
- 数据增强（视觉）：随机裁剪（96x96到88x88）、高斯模糊、随机旋转、亮度变化（均值回归随机过程）、随机跨度掩码。

### 📊 实验结果

论文在CHiME-9 MCoRec数据集上进行了全面评估，主要关注词错误率（WER）和聚类F1分数。

1. 主要性能对比（开发集）
| 系统 | WER ↓ | F1 ↑ | 联合分数 ↓ |
| :--- | :--- | :--- | :--- |
| 官方基线 | 49.90% | 0.815 | 0.355 |
| System 1 | 33.87% | 0.967 | 0.185 |
| System 2 | 33.69% | 0.967 | 0.184 |
结论：所提系统在转录和聚类性能上均显著优于基线。System 2（仅用MCoRec微调）略优于System 1（用更多但领域不匹配的AMI数据微调）。

2. 推理策略对比（开发集，System 2）
| 推理模式 | WER ↓ |
| :--- | :--- |
| 完整长上下文 | 33.69% |
| 按轨道处理 | 33.93% |
| 按ASD分割 | 67.93% |
结论：长上下文推理略优于按轨道独立处理。基于活动说话人检测（ASD）的分割导致性能急剧下降，因为其产生的短片段（<5秒）与训练时的50秒片段不匹配。

3. 预训练数据消融研究（开发集，System 2变体）
| 训练数据 | WER ↓ |
| :--- | :--- |
| 模拟预训练 + MCoRec | 33.69% |
| 模拟预训练 + AMI混合数据 | 37.87% |
| AMI混合数据 + MCoRec | 39.85% |
| 仅MCoRec | 38.20% |
结论：1500小时模拟数据预训练至关重要。仅用模拟数据训练的模型（第2行）在未见过的MCoRec上仍能达到37.87% WER，展示了强大的零样本泛化能力。去除预训练阶段（第3行）性能下降。

4. 聚类方法消融研究（使用真实转录文本）
| 系统 | 训练集 F1 ↑ | 开发集 F1 ↑ |
| :--- | :--- | :--- |
| 基线（基于ASD时间跨度） | 85.87 | 81.53 |
| 基线*（基于真实转录时间跨度） | 73.75 | 79.14 |
| 联合LLM聚类 | 91.13 | 86.04 |
| 成对主题相似度聚类 | 97.94 | 98.46 |
| 成对主题相似度 + 回退 | 97.94 | 98.46 |
结论：基于主题相似度的成对LLM聚类效果最佳，显著优于基线。基线*结果表明，ASD提供的时间区间比真实转录时间区间更适合聚类。

5. LLM鲁棒性分析
![图3: 不同Qwen模型大小下，成对主题得分F1分数与转录错误率的关系](https://arxiv.org/html/2604.27436v1/wer_analysis_plot.png)
图3说明：该图表明，随着WER增加，聚类性能下降。122B模型鲁棒性最强，在WER高达30%时，F1分数仍能保持在90%以上。性能下降与模型大小不完全成比例，说明较小的LLM也能有效完成主题相似度估计任务。
