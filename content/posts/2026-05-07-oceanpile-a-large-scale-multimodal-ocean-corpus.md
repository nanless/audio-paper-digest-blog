### 📌 核心摘要

1. 问题：海洋科学领域因数据高度碎片化、多模态、高噪声且弱标注，缺乏统一的语义对齐，导致通用多模态大模型难以有效应用，存在根本性的数据瓶颈。
2. 方法核心：构建了OceanPile，一个面向海洋基础模型的多模态语料库，包含三个组件：1）OceanCorpus，整合了教材、论文、网页、声呐、水下图像等多源异构数据；2）OceanInstruction，基于海洋概念知识图谱合成的高质量指令数据集；3）OceanBenchmark，人工策划的文本与多模态评估基准。
3. 新意：首次系统性地整合跨学科的海洋多源异构数据，并设计了知识引导的指令数据生成流程与专家验证的评估基准，为海洋领域MLLM的开发提供了从预训练到微调评估的完整基础设施。
4. 主要结果：使用OceanInstruction微调后，Qwen3系列模型在OceanBenchmark上性能显著提升。在多模态基准上，微调后的Qwen3-VL-8B（总体32.59%）超越了Gemini-3-Flash（31.21%）、GPT-4o（14.35%）和GPT-5（9.67%）。在海生生物识别子任务上，提升尤为明显（从9.96%到48.52%）。
5. 实际意义：为海洋科学研究、水下感知、生物多样性监测等应用提供了关键的多模态AI基础设施，有望加速“海洋智能”的发展。
6. 主要局限性：指令数据与评估基准主要聚焦英文场景；数据处理中依赖GPT-4o进行知识提取和指令生成，可能存在对闭源模型的依赖性；评估任务相对传统（如VQA、QA），未充分探索更复杂的海洋科学推理任务。

### 🏗️ 模型架构

本文并非提出一个新的端到端模型架构，而是描述了一个为构建海洋多模态基础模型而设计的数据处理与生成框架。其核心流程如下：

![OceanPile总览](https://arxiv.org/html/2605.00877v2/x1.png)
图1：OceanPile总体架构。数据流从多源数据（教科书、论文、网页、声呐数据集、水下图像集、实采数据）流入，经过特定的预处理管线，汇聚成OceanCorpus（用于预训练）。随后，在海洋概念知识图谱（OCG）的指导下，从OceanCorpus中生成OceanInstruction（用于微调），并人工构建OceanBenchmark（用于评估）。

![指令生成与质量控制框架](https://arxiv.org/html/2605.00877v2/x2.png)
图2：指令数据生成与质量控制框架。展示了如何从输入数据（文档/图像）出发，通过知识图谱检索相关上下文，利用大模型（GPT-4o）合成指令对，并经过多轮MLLM验证和人工专家审核的流程。

主要组件与流程：
1.  数据收集与预处理管线：针对不同数据源（结构化文档如LaTeX/PDF、网页、声呐/水下图像数据集）设计独立的清洗、转换和标准化流程。例如，对目标检测数据进行标注格式统一和类别合并。
2.  海洋概念知识图谱（OCG）构建：这是一个分层结构，由主学科（如海洋生物、物理海洋学）及其子类别构成。通过GPT-4o从教材语料中提取并融合生成。
3.  指令数据合成：以OCG为知识骨架，结合输入数据（文本或图像）和检索到的相关知识，利用GPT-4o生成问题-答案对。支持文本、视觉和任务特定三类指令生成。
4.  多级质量控制：采用“MLLM验证代理打分 -> 阈值过滤 -> 领域专家人工抽样审核”的流程，确保指令数据的质量和科学性（专家间一致性IAA=0.86）。

### 💡 核心创新点

1.  系统性多源海洋多模态数据整合：与现有局限于单一模态（如纯文本或纯图像）的海洋数据集不同，OceanPile首次将科学文献、声呐信号、水下光学影像、科学图表及领域网页内容系统性整合进一个统一语料库（OceanCorpus），覆盖了“文本-图像-声学信号”多种模态，为训练真正的多模态海洋模型奠定了基础。
2.  知识图谱引导的领域指令生成：为克服通用指令数据缺乏海洋科学深度的问题，提出了基于构建的“海洋概念知识图谱”（OCG）来指导指令合成的流程。该流程确保生成的指令数据覆盖了海洋科学的关键概念与层次关系，提升了指令的专业性和教学价值。
3.  专家驱动的多任务评估基准：构建了OceanBenchmark，包含文本理解（Ocean Science QA）和多模态推理（海洋科学VQA、声呐VQA、海生生物识别VQA）等多个子任务。其构建过程采用“专家出题-多数投票验证”的策略，为海洋MLLM提供了标准化、高质量的评估套件。

### 🔬 细节详述

- 训练数据：
    - 来源：海洋学教科书、开放获取论文（如arXiv）、海洋相关网页、公开声呐数据集、公开水下图像数据集、以及使用自主水下航行器（AUV）在中国舟山海域采集的实测数据。

### 📊 实验结果

主要实验在OceanBenchmark上进行，对比了微调前后的基座模型及闭源商业模型。

表1：不同模型在OceanBenchmark上的性能对比

| :--- | :--- | :--- | :--- | :--- | :--- |
| | | 海洋科学VQA (%) | 声呐VQA (%) | 海生生物识别VQA (%) | 总体 (%) |
| Qwen3-30B | 25.49 | - | - | - | - |
| Qwen3-30B (with OceanPile) | 26.47 ↑0.98 | - | - | - | - |
| Qwen3-VL-8B | - | 21.21 | 8.04 | 9.96 | 13.07 |
| Qwen3-VL-8B (with OceanPile) | - | 29.29 ↑8.08 | 19.97 ↑11.93 | 48.52 ↑38.56 | 32.59 ↑19.52 |
| GPT-5 | 16.67 | 19.19 | 0.71 | 9.11 | 9.67 |

| Gemini-3-Flash | 24.51 | 32.32 | 11.11 | 50.21 | 31.21 |

关键结论：
1.  使用OceanPile进行微调，显著提升了 Qwen3系列模型在各项海洋任务上的性能。
2.  在多模态总体任务上，微调后的Qwen3-VL-8B（32.59%）超越了所有对比的闭源模型，包括Gemini-3-Flash（31.21%）。
3.  提升幅度最大的子任务是海生生物识别VQA（从9.96%飙升至48.52%），表明该数据集在视觉细粒度识别任务上效果卓著。
4.  微调对声呐VQA任务也有明显提升（从8.04%到19.97%），但与Gemini-3-Flash（11.11%）相比已拉开差距，显示了领域数据的价值。
5.  GPT-4o和GPT-5在这些专门的海洋任务上表现不佳，说明通用模型在垂直领域的局限性。
