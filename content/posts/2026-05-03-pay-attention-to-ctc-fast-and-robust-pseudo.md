**亮点**：本文将CTC的“快速而稳健”与注意力的“高精度”在伪标记阶段巧妙地“各取所需”，用CTC输出硬“喂”给注意力解码器作为目标，既绕过了自回归解码的慢，又通过联合预测传递了CTC的鲁棒性，是“螺蛳壳里做道场”的典范。**短板**：CTC驱动的教师强制生成的注意力目标在序列级上缺乏全局连贯性（如附录图7所示），虽然不影响训练，但这也暗示了该方法依赖于“师生同源”的强假设，其泛化能力在更复杂的分布外任务中（如口型变化极大的WildVSR）是否完全可靠，仍需更严苛场景的检验。

### 📌 核心摘要

本文针对统一语音识别（USR）框架中**自回归伪标记（PL）计算慢**和**CTC与注意力分支解耦监督导致分布外鲁棒性差**两大痛点，提出了**USR 2.0**。
1. **要解决的问题**：原USR方法需要在每个训练步通过缓慢的自回归解码生成注意力PL，成为训练瓶颈；同时CTC和注意力PL分开监督学生模型，使得注意力分支在长语音、噪声等分布外（OOD）场景下易受教师错误级联影响，鲁棒性不足。
2. **方法核心**：提出**CTC驱动的教师强制**（CTC-driven teacher forcing）：教师模型用CTC头快速贪心解码出伪标签，经合并去重后，直接作为输入“强迫”教师注意力解码器在单次前向中生成对应的注意力PL，彻底消除了自回归瓶颈。由于CTC和注意力PL长度对齐，学生解码器可在一个前向中同时预测两者。为缓解由此引入的训练-测试不匹配（暴露偏差），进一步采用**混合采样**策略，在训练中交替使用CTC驱动模式和标准自回归模式。
3. **新意**：改变了传统自回归生成注意力PL的范式，利用CTC的稳健性为注意力解码器提供强引导目标，并在学生侧进行耦合监督。
4. **主要实验结果**：
   - **效率**：训练时间减少约50%（图5）。
   - **鲁棒性**：在长语音（VoxCeleb2）、噪声（LRS3加噪）、OOD数据集（LibriSpeech, WildVSR, AVSpeech）上显著优于原USR及AV-HuBERT等自监督基线。例如，在LRS3测试集上，当输入长度>400帧时，USR 2.0的AVSR WER（贪婪解码）保持稳定，而USR急剧上升（图3a）；在-5dB噪声下，AVSR WER为14.1%，优于USR的15.4%（表1）。
   - **性能**：在LRS3、LRS2、WildVSR多个任务上达到SOTA。例如，在LRS3低资源设置下，AVSR WER为2.9%，优于USR的3.0%（表2）；Huge模型在LRS3上AVSR WER达0.8%。
5. **实际意义**：使得高效、鲁棒地训练统一多任务语音识别模型成为可能，降低了对大规模无标签数据和计算资源的需求。
6. **主要局限性**：
   - 对**ASR/AVSR**任务，由于其本身WER较低，通过增加无标签数据和伪标记带来的提升幅度有限，性能可能受伪标签质量而非数量制约。
   - CTC驱动的教师强制主要用于**迭代自训练**场景，在非迭代的离线伪标记或实时推理中，自回归或束搜索解码仍是更合适的选择。

### 🏗️ 模型架构

论文中的模型架构基于Transformer编码器-解码器，并针对多模态输入进行了扩展。以下是详细描述（结合图2）：

![图2：伪标记流程对比](/audio-paper-digest-blog/images/iclr-2026/2026-05-03/sSbEEHNEsL-1.png)

**图2说明**：左图为原USR流程，中图为USR 2.0的CTC驱动模式，右图为USR 2.0的AR模式。

1.  **整体结构**：共享的**Transformer编码器**接收来自音频、视频或音频视觉（AV）的特征。编码器输出连接到两个并行的输出头：一个**CTC层**和一个**Transformer解码器（注意力分支）**。
2.  **特征提取与融合**：
    - **音频前端**：使用ResNet-18骨干网络处理原始音频，输出特征后经下采样以匹配25fps的视觉帧率。
    - **视频前端**：同样使用ResNet-18处理灰度视频帧（96x96，居中于嘴部）。
    - **融合**：音频和视频特征分别通过线性层投影到共享的Transformer维度。AV特征通过拼接后接独立投影层形成。
3.  **编码器**：共享的Transformer编码器，采用相对位置嵌入，处理融合后的多模态特征序列。
4.  **双输出头与联合监督**：
    - **CTC头**：从编码器输出映射到词汇表概率，用于CTC损失计算。
    - **注意力解码器（学生）**：在训练时，根据模式（CTC驱动或AR）接收不同的输入。它预测注意力PL，并计算交叉熵损失。
    - **关键交互**：在**CTC驱动模式**下，解码器的输入是**教师CTC头输出的伪标签序列**（经合并去重）。学生解码器被训练同时预测**教师注意力PL**和**CTC PL**。这建立了CTC输出与注意力解码器之间的直接耦合，是传递鲁棒性的关键。

### 💡 核心创新点

1.  **CTC驱动的教师强制（伪标记生成）**：
    - **局限**：传统自回归解码速度慢，且错误会累积。
    - **作用**：教师模型使用CTC头快速生成伪标签，作为固定输入条件喂给教师解码器，**单次前向传播**生成全部注意力PL。
    - **收益**：将伪标记速度提升约40倍（图1右），彻底移除了训练瓶颈。生成的注意力PL虽然序列级可能不连贯，但在师生条件匹配的伪标记场景下有效。
2.  **耦合的CTC-注意力联合预测（学生训练）**：
    - **局限**：原USR中CTC和注意力分支独立监督，导致学生注意力分支脆弱。
    - **作用**：学生解码器在一个前向中，被训练同时预测CTC PL和注意力PL（损失公式5）。
    - **收益**：使解码器从CTC PL中继承了**单调对齐的鲁棒性**，同时从注意力PL中学习**序列建模能力**。实验证明这对提升OOD性能至关重要（表4）。
3.  **混合采样训练策略**：
    - **局限**：CTC驱动训练引入了训练-测试不匹配（暴露偏差）。
    - **作用**：训练时以50%概率交替使用CTC驱动模式和标准AR模式。
    - **收益**：在保持鲁棒性的同时，提升了模型在ID数据上的精度，并控制了训练时间的增长（图4）。

### 🔬 细节详述

- **训练数据**：
    - **有标签**：LRS3（30h低资源/433h高资源），LRS2（223h）。
    - **无标签**：LRS3剩余部分，VoxCeleb2（英文子集，1326h），AVSpeech（英文子集，1323h）。
    - **预处理**：视频帧稳定、裁剪、灰度化。音频未预处理。
    - **增强**：视频随机裁剪和翻转；学生输入使用时域掩码（音频0.6s，视频0.4s）模拟缺失。
- **损失函数**：
    - **无标签损失（CTC驱动模式，公式5）**：`LAtt,m = 0.5 * CE(学生Att, 教师Att_PL) + 0.5 * CE(学生Att, 教师CTC_PL)`；`LCTC,m = CTC(学生CTC, 教师CTC_PL)`。
    - **无标签损失（AR模式，公式6）**：`LCTC,m = 0.5 * CTC(学生CTC, 教师CTC_PL) + 0.5 * CTC(学生CTC, 教师Att_PL)`；`LAtt,m = CE(学生Att, 教师Att_PL)`。
    - **有标签损失**：标准CTC+注意力联合损失。
    - **总损失**：模态权重（A/AV:0.7, V:0.3），有无标签损失比例（A/AV:0.75/0.25, V:0.97/0.03）。CTC损失权重0.1。
- **训练策略**：
    - **优化器**：AdamW (β1=0.9, β2=0.98)，权重衰减0.04。
    - **调度**：15 epoch线性warmup，之后余弦衰减。
    - **训练步数**：50 epochs。
    - **Batch Size**：具体帧数/GPU见表6。
    - **正则化**：Drop path（率见表6），梯度裁剪（阈值3.0），标签平滑（0.1）。
- **关键超参数**：模型尺寸见表5（Base: 86M参数，Huge: 953M）。阈值过滤τ=0.8。
- **训练硬件**：Base模型使用8张H200 GPU训练约1天；Huge模型使用64张GPU训练约4天。
- **推理细节**：默认使用ESPnet进行联合CTC-注意力束搜索（beam size 40，CTC权重0.1）。使用1000个子词的SentencePiece词汇表。

### 📊 实验结果

**主要Benchmark结果**：
1.  **LRS3（ID）性能（低资源，Base模型，表2）**：
    | 方法 | VSR WER | ASR WER | AVSR WER |
    | :--- | :--- | :--- | :--- |
    | AV-HuBERT | 51.8 | 4.9 | 4.7 |
    | BRAVEn | 43.4 | 4.0 | 4.0 |
    | USR | 36.0 | 3.2 | 3.0 |
    | **USR 2.0** | **36.2** | **3.0** | **2.9** |
    *结论*：USR 2.0在AVSR和ASR上超越USR，VSR基本持平。

2.  **OOD数据集性能（Base模型，贪婪解码，表3）**：
    | 方法 | LibriSpeech (ASR) | WildVSR (VSR) | AVSpeech (AVSR) |
    | :--- | :--- | :--- | :--- |
    | AV-HuBERT | 29.1 | 82.4 | 26.0 |
    | USR | 25.3 | 80.0 | 34.7 |
    | **USR 2.0** | **15.4** | **73.7** | **25.0** |
    *结论*：USR 2.0在所有OOD任务上大幅领先，尤其在LibriSpeech上WER降低约40%。

3.  **噪声鲁棒性（LRS3测试集，beam=30，表1）**：
    - 在-5dB SNR下，USR 2.0的ASR WER为39.3%，优于USR的43.3%；AVSR WER为14.1%，优于USR的15.4%。
    *结论*：在极端噪声下，USR 2.0展现出明显优势。
