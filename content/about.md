本站面向阅读语音、音乐与音频论文的中文研究者，提供每日速递、会议专题和单篇导读。你可以用它发现问题、理解方法和缩小阅读范围，再回到原论文确认关键结论。

## 怎样挑选与阅读论文

1. **先带着一个问题来。** 在[论文库](../papers/)检索中英文题目、摘要或 arXiv ID；需要跟踪某个会议时，进入[会议论文集](../conferences/)。论文库合并同一篇已核实论文的多份导读；身份待核实的页面单独保留。
2. **用分类缩小范围。** 在[研究方向](../tags/)先选任务，再搭配方法或研究条件。点击方向名称进入论文库，点击箭头展开下一级。父方向可包含下级；论文库中可切换包含下级或仅直接标注，并选择“所有相关标注”或“仅明确主任务 / 主方法”。
3. **先读速览，再读与你有关的证据。** 单篇页的“研究速览”帮助判断相关性；正文目录可带你跳到机制、实验、局限或复现资源。手机阅读时也可打开浮动章节目录。评分和相关推荐用于安排阅读顺序。
4. **回到原文做最后核对。** 打开“论文工具”中的官方论文页面或 PDF，检查方法定义、表格、数据划分、基线设置与成本条件。记录论文版本，以及支撑你判断的章节、页码或表号。

一次只留下少量真正准备读的论文。读完后补上一句“它解决了什么、对我的问题有什么用、还缺哪条证据”，比继续增加收藏更有价值。

## 内容、AI 与来源边界

本站的筛选、分析、中文导读和评分使用 AI 辅助生成，并结合结构、来源及发布检查；部分流程也有独立模型审核。**这些检查不等于作者确认、人工逐篇审定或同行评审。** 历史页面的分析流程与完整程度可能不同，请按页面实际展示的信息判断。

原论文是事实依据；本站导读是帮助理解的二次解读；个人备注是你的研究记录。正式引用、复现或工程决策，应回到原论文核对数字、公式和适用条件。能打开一个代码链接，也不等于已经复现结果或确认了许可证。

论文可能更新版本。页面中若提示使用历史版本、未绑定版本的 PDF 或替代来源，请先读完整提示，再打开对应链接；不要把不同版本的结论混在一起。arXiv 的版本标识规则可查看[官方说明](https://info.arxiv.org/help/arxiv_identifier.html)。

代码、模型、数据与 Demo 的可用状态是核查时的快照。是否可访问、是否允许你的用途、是否需要申请，仍要查看项目最新说明和许可证；未披露或未核实的资源不能视为已开源。

## 评分与研究分类怎么看

**评分是编辑性研究评价。** 它关注创新、技术严谨、实验充分、表达清晰、潜在影响、开源、可复现和工程价值，适合回答“先读哪篇”。比较分数时要同时看论文类型、实验条件和具体理由；缺少证据不等于已证明存在技术错误。

**分类回答“研究什么、怎样研究、在什么条件下研究”。** 任务、方法、条件等九个分面并列；例如“语音识别”和“参数高效微调”属于不同分面，不是人为拼接的一条父子链。单篇页优先展示显式主任务与主方法，路径末项才是直接分类，前面的名称用于说明上级方向。

方向目录使用当前分类；历史文章保留核验时的分类版本与上级路径。目录计数会按已核实论文身份合并，身份待核实页面单列；兄弟方向可能重叠，不能把各方向数量直接相加。未标注的历史论文仍可通过关键词搜索找到。

遇到“**只补研究分类**”提示，表示补充的是来源核验后的分类，**导读正文未重写或重新审核**。分类可信范围不能替代正文事实核查；旧扁平标签也不等同于已核实的多级分类。

## 收藏、笔记与导出

- **保存阅读线索：** 在单篇或论文库点击“收藏”，设置“待读 / 阅读中 / 已读”。展开“阅读笔记”，写下你的问题并点击“保存笔记”；每条笔记最多 2,000 字符。进入[我的收藏](../papers/?saved=saved)集中查看。
- **留下导读摘录：** 先在导读正文中选择文字，再点击“收录正文选段”，可将摘录、章节标题与本站章节链接追加到笔记。它明确标为本站导读摘录，不是原论文逐字引文。点击“导出当前笔记”可下载 Markdown，包括当前编辑内容、本篇导读和可靠来源链接；尚未保存的修改也会进入这份导出。
- **接着读：** 章节进度保存在当前浏览器。再次打开文章会提示“继续阅读”，由你决定是否恢复；论文库也可提供对应导读的继续阅读链接。
- **带走清单：** 在论文库选择条目，展开批量导出区域，选择 Markdown、CSV、BibTeX 或 RIS。Markdown / CSV 适合保留阅读状态、备注及来源线索；引用格式仅使用已有可验证字段，正式写作前请核对缺失作者、日期或 DOI。
- **引用与单篇资料：** 身份及官方来源已核实的论文可使用“复制引用”。展开“引用文件与研究资料”，可下载可得的 BibTeX / RIS，或“导出研究资料包”。资料包包含本篇导读的可见内容、链接与单独列出的个人笔记，并保留版本和来源提示；它不会自动读取原论文全文。引用文件可导入你选择的文献管理软件，具体操作见[资源指南](../links/#整理阅读资料)。
- **跨设备与恢复：** 在论文库展开“我的阅读资料与备份”，先“导出本机备份”，再到同一站点的另一浏览器导入 JSON。备份包含收藏、状态、备注与最多 200 页章节进度；导入文件上限为 5 MiB。默认合并较新记录，并保留冲突备注。资料损坏时先导出“原始恢复档案”，再按页面提示使用有效备份恢复。

这些个人资料只存于当前浏览器，本站不自动跨设备同步。清理站点数据、使用另一浏览器或更换设备前，请先备份；Markdown 阅读清单与完整 JSON 备份用途不同，清单不能替代恢复备份。

## 与 AI agent 一起研究

从一个具体问题开始，选一至三篇论文，把官方来源与版本交给 agent。确认它实际取得了全文，再要求它逐条引用证据；只提供摘要时，就把任务限制在摘要可以支持的范围。

可以把自己的研究问题、阅读笔记和已取得的原论文交给外部 agent。若同时使用本站导读摘录，要明确标注它属于二次解读；正式证据仍应指向原论文。本站不提供站内 AI 调用；导出的资料只有在你交给外部工具后，才进入该工具的处理流程。

可以这样提出一个可核查的任务：

> 围绕我的研究问题，比较这些论文的方法与实验条件。每条关键结论给出原文章节、页码或表号及支持它的短句；区分作者结论、你的推断和待核查项。没有找到证据就明确写“未找到”，不要补造数字、引用或资源链接。最后列出我需要亲自核对的三件事。

让 agent 把比较草稿放在临时工作目录，把你确认过的结论、反例和下一步实验写入自己的笔记。原论文与引用数据保留在资料库中，用 DOI、arXiv ID 或官方页面链接关联。更多工具选择和具体路线见[研究资源指南](../links/#一条可执行的-ai-agent-研究路线)。
